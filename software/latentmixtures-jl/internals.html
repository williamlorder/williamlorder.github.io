Internals

Documented internal functions and types: data layout, EM kernels (E- and M-steps), forward–backward recursions, the standard-error and scaling-factor machinery and the boundary handling. They are not part of the public API and may change.

Overview

  • Data (data.jl): indicator columns → CategoricalData (one-hot, response patterns collapsed) or ContinuousData (standardised); rows with every indicator missing dropped.
  • Emission kernels: CPU kernels (CatKernel, GaussKernel, FullGaussKernel, GrowthKernel; fused loops, cpu.jl, fullcov.jl, growth.jl) and the array/GPU formulation (CategoricalEmission, GaussianDiagEmission; matrix products, emissions.jl). Each implements init_params, the log-density (add_loglik! / loglik), mstep and nparams.
  • EM (em.jl, cpu.jl): estep/estep!, mstep_all, run_em, and the two-stage random starts multistart. Covariates (covariates.jl) replace the class proportions by a multinomial logit (CovState) updated by Newton steps inside the M-step.
  • LTA (lta.jl, lta_continuous.jl): forward–backward E-step _lta_estep, M-steps for transitions and measurement (ECM for partial invariance).
  • Standard errors (stderrors.jl, covariates.jl): the unconstrained internal parameterisation (_pack_measurement, _case_logf, _case_ll), the sandwich _internal_vcov by automatic differentiation, and the delta method to the reported parameters (_param_spec).
  • Scaling factor (compare.jl): _polish (Newton steps to the maximum, boundary parameters fixed) and _scaling.
  • Complex survey designs (survey.jl): SurveyDesign (PSUs nested in strata, built from the analysed rows), _kernel_map (kernel rows such as compressed response patterns → the cases they hold) and _design_meat, the stratified PSU-total meat that replaces Σ w² s sᵀ in _internal_vcov, _ll_parts (scaling factor), r3step, bch, dcat and lmr.
LatentMixtures.CatKernel — Type
CatKernel <: CPUEmission

CPU kernel of categorical indicators over P rows (distinct response patterns for LCA, cases for covariate models): cidx[j, p] is the row of the stacked L × K probability matrix ρ (all categories of all items) observed for item j in row p, or 0 if missing; item[l] is the item of category row l; ncat the categories per item; floor the lower bound of the probabilities in the M-step.

LatentMixtures.CategoricalData — Type

Categorical indicator data in one-hot form, on the host.

  • Z N×L one-hot matrix (L = total number of categories; all-zero block for a missing item)
  • O N×J observed-item indicator
  • G L×J category-to-item membership
LatentMixtures.ContinuousData — Type

Continuous indicator data, standardised per column on the host.

Missing cells are 0 in X (and X2) and 0 in the mask M. The original location/scale are kept to report parameters and the log-likelihood on the raw scale.

LatentMixtures.CovState — Type

EM state for covariate models: coefficients (P×K, last column 0) and per-case log π.

LatentMixtures.CovStateArr — Type

EM state for covariate models on device arrays: B (host P×K), X (device N×P), log π (N×K).

LatentMixtures.FitData — Type
FitData

Host-side data and internal estimates kept with a fitted LatentMixtureModel, so that standard errors, scaling factors, likelihood-ratio tests and the three-step methods can be computed after the fit without refitting.

"Internal" means: classes in the order EM produced them (reported class k is internal class perm[k]), continuous indicators on the standardised scale ((x - center) / scale), and LCA data collapsed to distinct response patterns (rows of kernel).

Fields

  • kernel: the CPU emission kernel holding the data (CatKernel over response patterns for LCA; GaussKernel, FullGaussKernel or GrowthKernel over analysed rows).
  • w, w2: per kernel row, the sum of the case weights and of their squares (pattern frequencies for unweighted LCA). w2 enters the meat of the sandwich, B = Σᵢ w2ᵢ sᵢ sᵢ'.
  • Xt: P × N covariate design (intercept first), or nothing without covariates.
  • perm: reported class k is internal class perm[k].
  • θ: internal measurement parameters (L × K item-response probabilities for LCA; (μ, σ2), (μ, Σ) or (α, Θ, Ψ) NamedTuples otherwise).
  • B: P × K multinomial-logit coefficients (last internal class = reference, column 0), or nothing without covariates.
  • logπ: internal class log-proportions (empty with covariates).
  • center, scale: per-indicator standardisation of LPA indicators (empty for LCA).
  • caseweights: per analysed row, the case weight rescaled to sum to n (ones without weights).
  • weighted: whether sampling weights were given.
  • pattern: analysed row i is kernel row pattern[i].
  • starts: the (stage 1, stage 2) random starts of the fit (reused by blrt).
  • design: the complex survey design of the analysed rows (SurveyDesign, from the cluster / strata keywords), or nothing. With a design the meat is built from the PSU totals of the weighted case scores instead of w2 (see src/survey.jl).
LatentMixtures.FixedKernel — Type
FixedKernel <: CPUEmission

Emission kernel with fixed log-densities F[k, i] = log f(yᵢ | class k) (K × rows): no free measurement parameters. Used by twostep and the two-level r3step.

LatentMixtures.FullGaussKernel — Type
FullGaussKernel <: CPUEmission

CPU kernel of continuous indicators with full within-class covariance matrices: Xt (J × N, standardised, missing 0), mask Mt, the rows grouped by missing-data pattern (pats: observed items, rows), equal (one matrix for all classes) and the ridge reg. Parameters (μ = J × K, Σ = J × J × K).

LatentMixtures.GaussKernel — Type
GaussKernel <: CPUEmission

CPU kernel of continuous indicators with diagonal within-class covariance: Xt (J × N, standardised, missing cells 0), observed mask Mt, equal (variances equal across classes) and the ridge reg added to every variance. Parameters (μ, σ2), both J × K.

LatentMixtures.GaussianDiagEmission — Type

Gaussian indicators, conditionally independent within class (diagonal covariance). equal = true: variances equal across classes (Mplus default; mclust EEI). equal = false: class-specific variances (mclust VVI).

LatentMixtures.MixedKernel — Type
MixedKernel <: CPUEmission

Emission kernel of a model with indicators of several types: blocks is a tuple of kernels over the same analysed rows (CatKernel over rows, not patterns; GaussKernel on the standardised scale; PoissonKernel, NegBinKernel, ZIPKernel), types[b] the type of block b (:categorical, :continuous, :poisson, :negbin, :zip) and names[b] its indicator names. Parameters are a tuple, one entry per block, in the parameterisation of the block's kernel.

LatentMixtures.NegBinKernel — Type
NegBinKernel <: CPUEmission

Negative binomial (NB2) count indicators: mean μ[j, k], dispersion α[j, k] (Var = μ + αμ²), with α equal across classes when equal. uidx[j, i] indexes the distinct observed values uvals[j] (0 = missing), so the dispersion M-step runs over distinct counts.

LatentMixtures.PoissonKernel — Type
PoissonKernel <: CPUEmission

Poisson count indicators, conditionally independent within class, rate λ[j, k].

LatentMixtures.SurveyDesign — Type
SurveyDesign

Complex sampling design of the analysed rows of a fitted model (Mplus TYPE = COMPLEX): the primary sampling units (PSUs) and strata given by the cluster and strata keywords of lca, lpa, growth and lta.

Fields

  • psu::Vector{Int}: PSU (1, …, C) of every analysed row; without cluster each row is its own PSU.
  • stratum::Vector{Int}: stratum (1, …, H) of every PSU (all 1 without strata).
  • strata_psus::Vector{Vector{Int}}: the PSUs of each stratum.
  • clustered::Bool, stratified::Bool: whether cluster / strata were given.

Notes

A PSU is a (stratum, cluster) pair, so cluster codes may repeat across strata. Strata with a single PSU are kept (see parameters and the manual section "Complex survey data").

LatentMixtures.ZIPKernel — Type
ZIPKernel <: CPUEmission

Zero-inflated Poisson count indicators: class-specific rate λ[j, k] and inflation probability π[j, k] (of a structural zero), equal across classes when equal (the Mplus default).

LatentMixtures._internal_vcov — Method
_internal_vcov(fd::FitData; blocksize = 2048, keep_scores = false) -> NamedTuple

Robust (sandwich, Mplus MLR) covariance of the internal parameter vector v = [measurement; vec(B[:, 1:K-1])] at the EM estimates.

With ℓᵢ(v) the log-likelihood of kernel row i (_case_ll), wᵢ its weight (pattern frequency × case weight) and w2ᵢ the sum of the squared case weights it represents:

H = Σᵢ wᵢ ∂²ℓᵢ/∂v∂v'        (observed-information Hessian, negative definite)
M = Σᵢ w2ᵢ sᵢ sᵢ',  sᵢ = ∂ℓᵢ/∂v   (meat: outer products of the case scores)
V = (−H)⁻¹ M (−H)⁻¹

With a complex survey design (fd.design, Mplus TYPE = COMPLEX) the meat is instead Σ_h n_h/(n_h−1) Σ_c (z_hc − z̄_h)(z_hc − z̄_h)' over the PSU totals z_hc = Σ_{cases i in PSU c} cwᵢ s_{pattern[i]} (_design_meat, src/survey.jl).

Both derivatives are by forward-mode automatic differentiation (ForwardDiff, fixed chunk size _CHUNK). Rows are processed in blocks (in parallel on threads), so memory is bounded for large n. Fixed boundary thresholds (tmap entries with index 0) are not part of v.

Returns (v, V, nm, tmap, ll, H, S): the parameter vector, its sandwich covariance, the number of measurement parameters, the threshold map of _pack_measurement, the log-likelihood reproduced from v (internal scale; must equal the EM value), the Hessian, and with keep_scores = true the nrow × d matrix of unweighted scores S (else empty).

Throws SingularException/PosDefException if −H cannot be inverted (empty classes, non-identified parameters).

LatentMixtures._lta_estep — Method
_lta_estep(kernels, ρs, logπ1, logA, w) -> (ll, γ, Ξ)

E-step of the LTA (Baum–Welch / forward–backward), in log space, for every pattern p. With Fₜ[k, p] = log f(yₚₜ | Cₜ = k) (0 for a missing wave, so missing waves are integrated out), log π₁ and log Aₜ[j, k] = log P(Cₜ₊₁ = k | Cₜ = j):

αₜ(k) = log P(y₁…yₜ, Cₜ = k)          α₁ = log π₁ + F₁,
                                       αₜ(k) = lse_j(αₜ₋₁(j) + log Aₜ₋₁[j, k]) + Fₜ(k)
βₜ(j) = log P(yₜ₊₁…y_T | Cₜ = j)       β_T = 0,
                                       βₜ(j) = lse_k(log Aₜ[j, k] + Fₜ₊₁(k) + βₜ₊₁(k))
log Lₚ = lse_k α_T(k)
γₜ[k, p] = exp(αₜ(k) + βₜ(k) − log Lₚ) = P(Cₜ = k | yₚ)
Ξₜ[j, k] = Σₚ wₚ exp(αₜ(j) + log Aₜ[j, k] + Fₜ₊₁(k) + βₜ₊₁(k) − log Lₚ)

Returns the weighted log-likelihood Σₚ wₚ log Lₚ, the marginal posteriors γ (one K × P matrix per wave, columns sum to 1) and the expected transition counts Ξ (one K × K matrix per transition, weighted by the pattern frequencies w). Invariant: Σ_k Ξₜ[j, k] = Σₚ wₚ γₜ[j, p].

LatentMixtures._lta_vcov — Function
_lta_vcov(m::LTAModel, ref = m.K, order = 1:m.K; meat = nothing, keep_scores = false)

Robust (sandwich, MLR) covariance V = H⁻¹ M H⁻¹ of the LTA parameter vector v of _lta_layout(m, ref, order) (free parameters; boundary ones get 0), with H the observed-information Hessian of the weighted log-likelihood and M the meat.

  • meat = nothing: M = Σᵢ w²ᵢ sᵢsᵢ' (case weights wᵢ; frequencies for compressed patterns), as Mplus MLR, or with a complex survey design (cluster / strata) the stratified PSU meat of _design_meat (Mplus TYPE = MIXTURE COMPLEX). Otherwise a function meat(S, rows) -> M of the per-case weighted score matrix S (n × d, row i = wᵢ ∂ℓᵢ/∂v of analysed case i, columns the free parameters) and the input rows rows = m.rows of the cases, e.g. a complex-survey (cluster/stratum) meat.
  • keep_scores = true: also return S (n × d) and free.

Returns (L, v, X, V, free, gradient, S). Cached per (ref, order) for the default meat.

LatentMixtures._ltac_mstep_diag — Method
_ltac_mstep_diag(st, kernels, γ, θold) -> per-wave (μ, σ2)

Measurement M-step of a continuous-indicator LTA with diagonal covariances. From the posterior-weighted sufficient statistics per wave, class and item (observed cells only), Wₜₖⱼ = Σᵢ γₜₖᵢ, S1ₜₖⱼ = Σᵢ γₜₖᵢ yᵢₜⱼ, S2ₜₖⱼ = Σᵢ γₜₖᵢ yᵢₜⱼ²:

  • a mean parameter μₖₚ shared by the waves {t : mcol[t, j] = p} is the precision-weighted average Σₜ S1ₜₖⱼ / σ²ₜₖⱼ / Σₜ Wₜₖⱼ / σ²ₜₖⱼ with the previous variances (exact when those waves share the variance; otherwise a conditional maximisation step, ECM);
  • a variance parameter v is the residual sum of squares about the new wave-specific means, Σ (S2 − 2μS1 + μ²W) / Σ W over the waves (and, if equal, the classes) that share it, floored at 0, plus reg.

Each step maximises the expected complete-data log-likelihood given the other block, so the observed log-likelihood never decreases.

LatentMixtures._ltac_mstep_full — Method
_ltac_mstep_full(st, kernels, γ, θold) -> per-wave (μ, Σ)

Measurement M-step of a continuous-indicator LTA with full within-class covariance matrices (ECM). For every wave, class and missing-data pattern (o observed, m missing items) the expected sufficient statistics use the conditional distribution of the missing block under the previous parameters,

x̂ₘ = μₘ + Σₘₒ Σₒₒ⁻¹ (yₒ − μₒ),    Cov(xₘ | yₒ) = Σₘₘ − Σₘₒ Σₒₒ⁻¹ Σₒₘ,

giving Rₜₖ = Σᵢ γ, s1ₜₖ = Σᵢ γ x̂ᵢ and Sxₜₖ = Σᵢ γ (x̂ᵢx̂ᵢ' + Cov). Then

  1. means by generalised least squares given the previous Σₜₖ: with Dₜ selecting the mean parameters of wave t, μₖ = (Σₜ Rₜₖ Dₜ'Σₜₖ⁻¹Dₜ)⁻¹ Σₜ Dₜ'Σₜₖ⁻¹ s1ₜₖ (a 10⁻¹² ridge guards empty classes);
  2. covariance matrices about the new means, pooled over the waves of a covariance group (sg) and, if equal, over classes; reg is added to the diagonal and the result symmetrised.
LatentMixtures._ltacov_estep — Method
_ltacov_estep(F, L1, LA) -> (llᵢ, γ, ξ)

Forward–backward recursions of an LTA in which every case has its own initial and transition probabilities: F[t] (K × N) are the log densities of the wave-t data (measurement and distal outcomes; 0 for a missing wave), L1 (K × N) the log initial probabilities log P(C₁ = k | xᵢ) and LA[t] (K × K × N) the log transition probabilities log P(Cₜ₊₁ = l | Cₜ = k, xᵢ). Returns the log-likelihood Σᵢ log Lᵢ, the marginal posteriors γ[t] (K × N) and the pairwise posteriors ξ[t][k, l, i] = P(Cₜ = k, Cₜ₊₁ = l | yᵢ, xᵢ). (ll is returned per case.)

LatentMixtures._mg_fit — Method
_mg_fit(kernels, ws, K, items_free, n; starts, stage1_iter, maxiter, tol, seed)

Multistart EM for a multigroup model. kernels[g], ws[g] are the data and row weights of group g; classes 1:K share labels across groups through the invariant parameters.

E-step: within each group, pᵢₖ ∝ π_gk f(yᵢ | θ_g, k) (estep!), and the log-likelihood is the sum over groups. M-step: log π_g from the weighted posterior means of group g; the measurement parameters are estimated on the data of all groups pooled (mstep on the concatenated kernel, which is the exact M-step for parameters that are equal across groups) and, for the non-invariant items_free, replaced by the estimates on the group's own data (_merge_params). Convergence and starts as in multistart.

Returns the best stage-2 run (θs, logπs, ll, iterations, converged, posteriors) and the sorted StartResults. The known-group term and the standardisation Jacobian are added by the caller.

LatentMixtures._ml_estep! — Method
_ml_estep!(ws, b, θ, logπB, logW, bounds) -> Float64

E-step of the two-level model (upward–downward, log space). bounds[j] is the range of kernel rows of cluster j (rows are sorted by cluster). Upward: H[m, i] = log Σ_k W[k,m] f(yᵢ|k) and log L_jm = log π_m + Σ_{i∈j} H[m, i]; downward: PB[m, j] = P(CB_j = m | y_j) and the within posterior post[k, i] = Σ_m PB[m, j] W[k,m] f(yᵢ|k) / exp(H[m, i]); Nkm accumulates the expected joint (CW, CB) counts. W and π may depend on the individual and the cluster (covariates; see _ml_arrays). Returns Σ_j log L_j.

LatentMixtures._ml_fit — Method
_ml_fit(b, K, M, bounds, d; starts, stage1_iter, maxiter, tol, seed, threaded = true, ids = nothing)

Mplus-style two-stage random starts for the two-level model (as multistart): stage 1 runs starts[1] random starts (_ml_init, stream (seed, s)) for stage1_iter EM iterations, stage 2 the starts[2] best to convergence; starts run on threads. Returns (θ, p, ll, converged, best, finals, ws) with ws the E-step buffers evaluated at the returned estimates.

LatentMixtures._ml_vcov — Method
_ml_vcov(m::MultilevelModel) -> NamedTuple

Robust covariance of the internal vector (see the top of src/multilevel_se.jl) at the fitted (Newton-finished) estimates: (v, V, H, M, free, nm, tmap); H and M are over the free parameters free (thresholds at the boundary are fixed: zero rows/columns of V).

LatentMixtures._polish — Method
_polish(P::_LLBlocks, v, free, bound; maxit = 30) -> (v, free, parts, ll0, steps)

Safeguarded Newton–Raphson on the free parameters, started at the EM estimates v. Each step solves (−H) d = g and halves the step length (up to 30 times) until the log-likelihood does not decrease by more than a relative 10⁻⁹; it stops when the step is below 10⁻⁷, the Newton direction is below 10⁻⁹, −H is singular, or no step is accepted. Before every step, parameters for which bound(v, i) holds (a threshold beyond _TAU_MAX, or an LTA logit below log 10⁻⁵) are removed from free and fixed at their current value.

Returns the polished vector, the final free set, _ll_parts at the final point (ll, H, g, M), the log-likelihood at the start and the number of accepted steps. Used only to evaluate the scaling factor at the maximum; the fitted model is not changed.

LatentMixtures._ri_cluster_ll — Method
_ri_cluster_ll(F, X, Wb, lb, js, φ, P, K, Pb, z, lω, μ, σ) -> Vector

LatentMixtures.estep! — Method
estep!(A, blocks, θs, logπ, w) -> Float64

Fused CPU E-step. Fills the K × P workspace A with A[k, p] = log πₖ(p) + Σ_b log f_b(yₚ | k), then replaces every column by the posterior exp(A[:, p] − lseₚ) with lseₚ = log Σₖ exp A[k, p] (stable log-sum-exp), and returns the weighted log-likelihood Σₚ wₚ lseₚ. Invariants: columns of A sum to 1 on return; no allocations proportional to P.

LatentMixtures.mstep — Method
mstep(b::GrowthKernel, post, w, θold) -> (α, Θ, Ψ)

M-step of a growth mixture model given the K × N posterior class probabilities post, row weights w and the previous parameters. With rᵢₖ = postₖᵢ wᵢ and o the observed waves of row i:

  • LCGA (Ψ = 0, an ECM step): αₖ by weighted GLS given the previous Θ, αₖ = (Σᵢ rᵢₖ Λₒ'Θₒ⁻¹Λₒ)⁻¹ Σᵢ rᵢₖ Λₒ'Θₒ⁻¹ yᵢₒ, then Θₜ = weighted mean squared residual at wave t over classes.
  • GMM (EM with the growth factors η as missing data): the posterior of η given yᵢ and class k has covariance V = (Ψ⁻¹ + Λₒ'Θₒ⁻¹Λₒ)⁻¹ (class-invariant) and mean mᵢₖ = V(Ψ⁻¹αₖ + Λₒ'Θₒ⁻¹yᵢₒ); then αₖ = Σᵢ rᵢₖ mᵢₖ / Σᵢ rᵢₖ, Ψ = Σᵢₖ rᵢₖ[(mᵢₖ − αₖ)(mᵢₖ − αₖ)' + V] / Σ r (equal across classes, Mplus default), Θₜ = Σ rᵢₖ[(yᵢₜ − λₜ'mᵢₖ)² + λₜ'Vλₜ] / Σ r over the rows observed at t.

Θ is floored at 10⁻⁸; Ψ is symmetrised with a 10⁻¹⁰ ridge.

LatentMixtures.multistart — Method
multistart(blocks, w, K, N, dev, T; starts, stage1_iter, maxiter, tol, seed,
           logπ_init = nothing, threaded = true, θ_init = nothing, ids = nothing) -> NamedTuple

Mplus-style two-stage random starts. Stage 1: starts[1] random starts (init_params of every block with the start's own stream, equal class sizes or logπ_init), each run for stage1_iter EM iterations. Stage 2: the starts[2] starts with the highest stage-1 log-likelihood are run to convergence (run_em). Starts run on Julia threads when threaded and the device allows it (BLAS is set to one thread meanwhile). Start s always uses the same random-number stream, so the result does not depend on the number of threads (up to BLAS rounding).

θ_init (a tuple of block parameters) replaces the random start values (user start values: run with starts = (1, 1)); ids (one start number per stage-1 start) replaces start numbers 1:starts[1] (optseed: ids = [id], starts = (1, 1)).

Returns (θs, logπ, post, ll, converged, best, finals): the best stage-2 solution, its posterior (N × K, host or device array), log-likelihood and convergence flag, its StartResult, and all stage-2 StartResults sorted by log-likelihood.
