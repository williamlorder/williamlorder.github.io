Example datasets

LatentMixtures ships five small simulated datasets, one for each family of models. Load them with dataset; datasets lists them (packages built on LatentMixtures add their own when loaded). The R package latentmixtures ships the same data (data(aces), …).

using LatentMixtures
datasets()

Source and licence. All data are simulated from the data-generating processes written in datasets/generate.jl (seeded) to mimic published findings; no real person is described. The data are dedicated to the public domain (CC0 1.0). The codebook lists every variable, the generating model and its true parameter values (class shares, item probabilities, trajectories, transition matrices), so that estimates can be checked against the truth.

Missing values are missing. Raw files that code them as -999 need converting first; see "Your own data" in the enumeration tutorial.
