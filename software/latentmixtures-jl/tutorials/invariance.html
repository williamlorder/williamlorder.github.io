Measurement invariance and nested model comparison

Multigroup mixture models with known groups (Mplus KNOWNCLASS) let the class proportions differ by group and test whether the classes are measured the same way in every group. The same tools compare nested longitudinal models (invariance across waves, stationary transitions).

The examples use the aces data (see Example datasets): eight adverse childhood experiences of 1,500 adults, generated from four classes in which the sexual-abuse item is more often reported by women in every class (+0.9 on the logit scale) while the other seven items are measured the same way for men and women. The true model is therefore partial invariance with ace_sex_abuse group-specific.

using LatentMixtures
d = dataset("aces")
Y, g = d[:, r"^ace_"], d.female            # group: 0 = men, 1 = women
(men = count(==(0), g), women = count(==(1), g))
(men = 745, women = 755)

Full, partial and no invariance

full = lca(Y, 4; group = g)                                     # invariant
part = lca(Y, 4; group = g, invariance = [:ace_sex_abuse])      # one item group-specific
none = lca(Y, 4; group = g, invariance = :none)

invariance takes :full, :none, or a vector of indicators (names or column indices). For multigroup models a listed indicator has all its parameters group-specific — the item-response probabilities in LCA, the mean and the variance in LPA.

Same keyword, different meaning in `lta`

In lta(...; indicators = :continuous, invariance = [items]) a plain item list frees only the means of those items across waves. Use invariance = (means = items, variances = items) there for the multigroup behaviour.

Likelihood-ratio and scaled difference tests

lrtest is the ML likelihood-ratio test. Under robust ML (Mplus ESTIMATOR = MLR, the default for mixtures) nested models are compared with the Satorra–Bentler scaled difference test, which needs the scaling correction factor of each model (scaling_factor, Mplus "H0 Scaling Correction Factor for MLR"):

lrtest(full, part)
(chisq = 43.615263776719075, df = 4, p = 7.711626772712389e-9, delta_bic = -14.36238222835891)
scaling_factor(full), scaling_factor(part)
(1.0374137481671828, 1.0381499333685256)
compare_models(full, part)
(ll0 = -6285.70866355187, ll1 = -6263.90103166351, npar0 = 39, npar1 = 43, c0 = 1.0374137481671828, c1 = 1.0381499333685256, df = 4, chisq = 43.615263776719075, p = 7.711626772712389e-9, cd = 1.0453277390816176, chisq_scaled = 41.72400879272339, p_scaled = 1.902990352279407e-8, delta_aic = -35.615263776719075, delta_bic = -14.36238222835891, delta_sabic = -27.069267768814825, warning = "")

comparison_table runs the test of every model against the previous row:

tb = comparison_table(full, part, none)
(npar = tb.npar, ll = round.(tb.ll; digits = 3), c = round.(tb.scaling; digits = 4),
 bic = round.(tb.bic; digits = 3), chisq_scaled = round.(tb.chisq_scaled; digits = 2),
 df = tb.df, p_scaled = tb.p_scaled)
(npar = [39, 43, 71], ll = [-6285.709, -6263.901, -6248.025], c = [1.0374, 1.0381, 1.0573], bic = [12856.633, 12842.271, 13015.29], chisq_scaled = [NaN, 41.72, 29.21], df = [0, 4, 28], p_scaled = [NaN, 1.902990352279407e-8, 0.4016910720230006])

The difference test needs

cd  = (p₀c₀ − p₁c₁) / (p₀ − p₁),     TRd = 2(LL₁ − LL₀) / cd,

on p₁ − p₀ degrees of freedom. When cd ≤ 0 the scaled test is not available and a warning is returned. sb_difference applies the formula to printed values, e.g. to reproduce a test from Mplus output:

sb_difference(-6997.498, 23, 1.0520, -6959.644, 26, 1.0158)   # values printed by Mplus for a validation case
(cd = 0.7382666666666667, chisq = 102.54831135994046, df = 3, p = 4.400440880479601e-22)

Nested longitudinal models

The same functions apply to LTA models, for example invariance of the means across waves or stationarity of the transitions. In wellbeing_panel stress and loneliness were generated to be higher in 2020 (wave 2) in every profile:

p = dataset("wellbeing_panel")
W = [[:sleep_1, :activity_1, :stress_1, :lonely_1], [:sleep_2, :activity_2, :stress_2, :lonely_2],
     [:sleep_3, :activity_3, :stress_3, :lonely_3]]
inv   = lta(p, W, 3; indicators = :continuous)
shift = lta(p, W, 3; indicators = :continuous, invariance = [3 => 2, 4 => 2])
r = compare_models(inv, shift)
(df = r.df, chisq_scaled = r.chisq_scaled, p_scaled = r.p_scaled, delta_bic = r.delta_bic)
(df = 6, chisq_scaled = 439.7874294235548, p_scaled = 7.73960359420219e-92, delta_bic = -380.3414318099203)

Stationary transitions for the substance-use statuses (generated: time-specific, with more movement from Non-use between grades 10 and 12):

s = dataset("substance")
S = [[:alc_1, :binge_1, :cig_1, :mj_1], [:alc_2, :binge_2, :cig_2, :mj_2], [:alc_3, :binge_3, :cig_3, :mj_3]]
r = compare_models(lta(s, S, 3; transitions = :stationary), lta(s, S, 3))
(df = r.df, chisq_scaled = r.chisq_scaled, p_scaled = r.p_scaled, delta_bic = r.delta_bic)
(df = 6, chisq_scaled = 5.139803826591315, p_scaled = 0.5260115013047342, delta_bic = 38.48542727582935)

Caveats

  • The χ² reference distribution does not hold for models with different numbers of classes; compare_models and comparison_table warn, and lmr / blrt should be used instead.
  • Nesting is not checked. Fit both models to the same rows (same group, same missing data) and make sure the restricted model is a special case of the general one.
  • Standard errors of multigroup and LTA models are available through parameters (for an LTA in the Mplus parameterisation, see parameters(::LTAModel)).
