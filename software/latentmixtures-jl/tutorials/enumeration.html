LCA, LPA and class enumeration

This tutorial fits latent class and latent profile models to two of the example datasets (see Example datasets): retrospective reports of eight adverse childhood experiences (ACEs) by 1,500 adults, and six health-behaviour and wellbeing indicators of 1,000 adults. Both were simulated from known models, so the estimates can be compared with the truth. Every block is executed when the documentation is built, with the default random starts (starts = (100, 20)).

Choosing the number of classes

Fit a sequence of models and compare information criteria. Models with more classes than the data support have flat likelihoods with many local maxima, so the enumeration uses more random starts than the default (with starts = (100, 20) the best log-likelihoods of the 5- and 6-class models are not replicated, and the fit warns). fittable returns a column table (convert with DataFrame(fittable(fits)) if DataFrames is loaded).

fits = [lca(Y, k; starts = (400, 80)) for k in 1:6]
ft = fittable(fits)
@printf("%2s %5s %11s %11s %11s %8s %5s\n", "K", "npar", "LL", "BIC", "saBIC", "entropy", "rep")
for i in eachindex(ft.K)
    @printf("%2d %5d %11.3f %11.3f %11.3f %8.3f %5d\n", ft.K[i], ft.npar[i], ft.ll[i],
            ft.bic[i], ft.sabic[i], ft.entropy[i], ft.replicated[i])
end

BIC and saBIC are smallest at four classes, the generating number. The likelihood-ratio χ² is not valid for comparing K − 1 with K classes. The Vuong–Lo–Mendell–Rubin test (lmr, Mplus TECH11) and the parametric bootstrap test (blrt, Mplus TECH14) compare each model with one class fewer:

The LMR test rejects three classes in favour of four and does not reject four in favour of five. The bootstrap test refits both models to every bootstrap sample; it is the most expensive call in the package:

blrt(fits[4]; reps = 100)       # 3 vs 4 classes

  H0 log-likelihood                       -5316.153

The H0 log-likelihood, the statistic and the LMR adjustment agree with Mplus TECH11; the reference distribution (mean, SD) and p-values follow Vuong (1989) and Lo, Mendell & Rubin (2001) and differ from Mplus, which does not document its computation. See the Validation page.

Latent profile analysis

lpa fits Gaussian mixtures to continuous indicators. Within-profile variances are equal across profiles by default (Mplus default, mclust EEI); variances = :varying makes them profile-specific (VVI), and covariances = :equal / :varying adds within-profile covariances (EEE / VVV).

The wellbeing data were generated from four profiles — Thriving (24%), Typical (44%), Stressed short sleepers (23%) and Isolated and inactive (10%) — with profile-specific variances:

w = dataset("wellbeing")
X = w[:, [:sleep, :activity, :fruitveg, :stress, :lonely, :lifesat]]
eei = [lpa(X, k; starts = (400, 80)) for k in 1:6]
vvi = [lpa(X, k; variances = :varying, starts = (400, 80)) for k in 1:6]
(K = 1:6, bic_EEI = round.(bic.(eei); digits = 1), bic_VVI = round.(bic.(vvi); digits = 1))
(K = 1:6, bic_EEI = [23062.3, 21433.3, 20973.2, 20558.7, 20516.6, 20504.0], bic_VVI = [23062.3, 21036.6, 20559.0, 20343.7, 20356.4, 20357.4])

The log-likelihood and the parameters are on the original scale of the data, although the EM runs on standardised indicators; models fitted to rescaled data differ only by the Jacobian of the rescaling.

Your own data

Raw survey files and Mplus data files often code missing values as -999. Convert the code to missing before fitting; here a whitespace-delimited Mplus file shipped with the package (validation/data/lca_bin.dat, eight binary items):

path = joinpath(pkgdir(LatentMixtures), "validation", "data", "lca_bin.dat")
A = reduce(vcat, [permutedims(parse.(Float64, split(l))) for l in eachline(path)])
Yraw = [x == -999 ? missing : Int(x) for x in A]    # -999 → missing
count(ismissing, Yraw), size(Yraw)
(916, (1500, 8))

With CSV.jl the same is CSV.read(path, DataFrame; delim = ' ', ignorerepeated = true, header = false, missingstring = "-999").

Checklist

  • Run convergence on every model you interpret; increase starts until bestll_replicated is at least 2 (the summary flags a non-replicated best log-likelihood with ⚠).
  • Inspect the smallest class (fitstats(m).smallest) and the classification tables (classification_table) before interpreting a solution.
  • BIC and the bootstrap LRT performed best in the simulations of Nylund, Asparouhov & Muthén (2007).
