LatentMixtures.jl

Finite mixture models for the social and health sciences — latent class and latent profile analysis, multigroup models with measurement invariance, latent transition analysis and growth mixture models — estimated by maximum likelihood with the EM algorithm, with robust (MLR) standard errors, three-step auxiliary-variable methods, tests for the number of classes and scaled difference tests. Every feature is checked against Mplus 8 (see Validation).

Missing indicator values are handled by full-information maximum likelihood. Mplus-style two-stage random starts run in parallel on Julia threads, with one random-number stream per start, so the solution does not depend on the number of threads.

Installation

The package is not registered. Install it from a local clone (Julia ≥ 1.12):

using Pkg
Pkg.develop(path = "path/to/LatentMixtures.jl")

For GPU support also add CUDA.jl (a weak dependency, loaded by using CUDA).

part = lca(Y, 4; group = d.female, invariance = [:ace_sex_abuse])
r = compare_models(full, part)

Conventions

  • Class order: classes are ordered by estimated size, largest first (LTA: at wave 1; multigroup: overall). The reference class of logits and regressions is the last class unless ref is given.
  • Rows: rows with every indicator missing are not analysed. posterior(m) and predict(m) are aligned with the analysed rows m.rows; classify(m) with the input rows.
  • Scale: continuous indicators are standardised internally; every reported parameter and the log-likelihood are on the original scale.
  • Parameter counts (dof) follow Mplus, so AIC, BIC and likelihood-ratio statistics are comparable with Mplus output.

One inconsistency to know about

The invariance keyword with a plain list of items means different things in two places:

  • multigroup lca/lpa(...; group, invariance = [items]) frees all parameters of the listed items across groups (LCA: their item-response probabilities; LPA: means and variances);
  • lta(...; indicators = :continuous, invariance = [items]) frees only the means of the listed items across waves; use invariance = (means = items, variances = items) to free their variances too.

Not yet implemented

Covariates and sampling weights in multigroup models; categorical outcomes in growth models; class-specific Ψ or Θ in GMM; within-profile covariances on the GPU; covariates combined with LMR/BLRT; BLRT with sampling weights or a survey design; the finite population correction, replicate weights and SUBPOPULATION; Mplus TECH11 p-values exactly; and, of the two-level models: more than one random factor (K − 1 separate or correlated random class intercepts) and random slopes, random intercepts combined with between classes (KB), weights or survey designs, a categorical distal outcome (DCAT), stepwise (two-/three-step) estimation for the random-intercept model, and multilevel LTA or growth mixtures.
