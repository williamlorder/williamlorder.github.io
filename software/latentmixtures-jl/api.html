LatentMixtures.LatentMixtures — Module
LatentMixtures

Finite mixture models for categorical, continuous and count indicators, estimated by maximum likelihood with the EM algorithm and checked against Mplus 8:

  • lca: latent class analysis (binary and polytomous indicators);
  • lpa: latent profile analysis (diagonal or full within-profile covariances, equal or profile-specific);
  • multigroup LCA/LPA with full, partial or no measurement invariance (group keyword, Mplus KNOWNCLASS);
  • two-level (multilevel) LCA with a between-level latent class (level2, KB keywords; Mplus TYPE = TWOLEVEL MIXTURE, Vermunt 2003; MultilevelModel), and LCA with random class intercepts on a between factor (random = :factor; MultilevelRandomModel);
  • lta: latent transition analysis (categorical or continuous indicators, invariance incl. partial by item and wave, time-specific or stationary transitions);
  • mixture: mixed indicator types in one model — categorical, continuous and count indicators (Poisson, negative binomial, zero-inflated Poisson);
  • growth: LCGA and growth mixture models, including parallel processes;
  • covariates (one-step c ON x), three-step r3step, bch, dcat; sampling weights; robust (MLR) standard errors (parameters);
  • class enumeration: fittable, lmr (TECH11), blrt (TECH14);
  • nested models: scaling_factor, compare_models, comparison_table (Satorra–Bentler scaled difference test);
  • extension API: measurement_estimates, posterior_at, posterior(m, newdata);
  • plots (profileplot, enumerationplot, trajectoryplot, …) with any Makie backend (using CairoMakie; package extension LatentMixturesMakieExt).

Missing indicator values are handled by full-information maximum likelihood. Random starts run in parallel on Julia threads (julia -t auto) with one random-number stream per start, so the solution does not depend on the number of threads. With using CUDA, device = :cuda runs the E- and M-steps of LCA/LPA on an NVIDIA GPU (package extension LatentMixturesCUDAExt).

LatentMixtures.growth — Method
growth(data, K; model = :lcga, times = nothing, degree = 1, processes = nothing,
       starts = (100, 20), stage1_iter = 20, maxiter = 5000, tol = 1e-10,
       seed = 20261119, covariates = nothing, ref = K, weights = nothing, cluster = nothing,
       strata = nothing)
    -> LatentMixtureModel

Growth mixture models for repeated continuous measures: latent class growth analysis (LCGA) and growth mixture models (GMM) with polynomial trajectories, for one outcome or several parallel processes, by ML with the EM algorithm from two-stage random starts.

Within class k, the measures of case i follow

yᵢ = Λ ηᵢ + εᵢ,   ηᵢ ~ N(αₖ, Ψ),   εᵢ ~ N(0, diag Θ),

with Λ the polynomial design in the time scores, αₖ the class-specific growth-factor means (intercept, slope, …), Ψ the growth-factor covariance matrix (Ψ = 0 for LCGA) and Θ wave-specific residual variances. Ψ and Θ are equal across classes, as the Mplus defaults.

Arguments

  • data: matrix or Tables.jl table of numeric measures; by default every column is one wave of a single outcome, in time order. missing/NaN = missing wave (FIML); rows with every measure missing are dropped.
  • K::Integer: number of classes, K ≥ 1.

Model:

  • model = :lcga: latent class growth analysis (group-based trajectories; no within-class variation of the growth factors; Mplus i s | y1@0 y2@1 …; i@0 s@0;), or :gmm: growth mixture model (normal growth factors within class, Ψ free and equal across classes).
  • times = nothing: time scores of the waves (e.g. ages, or 0, 1, 2, …); default 0:T-1. With several processes, either one vector used for all or a vector of vectors (one per process).
  • degree = 1: degree of the polynomial trajectory (1 linear, 2 quadratic, …, at most 4 and below the number of waves); an integer or one integer per process.
  • processes = nothing: parallel-process models: the columns of each outcome, e.g. [[:dep1, :dep2, :dep3], [:anx1, :anx2, :anx3]] or [1:4, 5:8] (names or indices). Each class has a trajectory for every outcome; for :gmm the growth factors of all outcomes are correlated within class (Ψ is their joint covariance matrix), so the processes depend on each other through the shared classes and through Ψ. Columns not listed are ignored.

Estimation, covariates and weights (as in lca):

  • starts = (100, 20), stage1_iter = 20, maxiter = 5000, tol = 1e-10, seed = 20261119. A start sets the class means αₖ to the OLS growth factors of K random rows. start (user start values) and optseed (one random start) as in lca.
  • covariates = nothing, ref = K: one-step multinomial logit of class membership (Mplus c ON x).
  • weights = nothing: sampling weights (rescaled to sum to the number of analysed rows).
  • cluster = nothing, strata = nothing: complex survey design (Mplus TYPE = COMPLEX): design-based standard errors and scaling factor; see lca.

Returns

A LatentMixtureModel with kind = :LCGA or :GMM. m.means holds the model-implied means of the measures (T × K), m.covs the implied covariance ΛΨΛ' + Θ; growthparams returns α, Θ, Ψ.

Examples

using LatentMixtures
# Trajectories of depressive symptoms (CES-D, dep1–dep5 at ages 12–16) of 600 adolescents
g = dataset("depression")
dep = g[:, [:dep1, :dep2, :dep3, :dep4, :dep5]]
l = growth(dep, 4; model = :lcga, degree = 2, times = 0:4)   # group-based trajectories
m = growth(dep, 4; model = :gmm, degree = 2)                 # growth mixture model
convergence(m)          # check that the best LL is replicated and EM reached the maximum
classprobs(m)           # ≈ 0.54, 0.26, 0.11, 0.10: Low stable, Increasing, Decreasing, Chronic high
growthparams(m).α       # intercept, slope, quadratic by class (Increasing: 5.6, 2.2, -0.13)
parameters(m)           # every parameter with its robust SE

# parallel process: depression and anxiety (GAD-7, anx1–anx5) share the trajectory classes
pp = growth(g, 4; model = :gmm, processes = [[:dep1, :dep2, :dep3, :dep4, :dep5],
                                              [:anx1, :anx2, :anx3, :anx4, :anx5]])
growthparams(pp).Ψ      # 4 × 4, incl. the cross-process covariance of the intercepts (≈ 0.9)

Notes

  • Mirrors Mplus TYPE = MIXTURE with i s | y1@0 y2@1 y3@2 …; (and q for quadratic), i@0 s@0; for LCGA; GMM with Mplus defaults (Ψ and Θ class-invariant). Parallel processes: one i s | statement per outcome. LL, npar, BIC, entropy, Θ, Ψ and SEs agree with Mplus on the validation cases.
  • npar = (K − 1)·P + K·q + T + (GMM ? q(q + 1)/2 : 0), with q the number of growth factors (summed over processes) and P = 1 + number of covariates.
  • Standard errors (parameters), lmr, blrt, r3step, bch, dcat, classify and scaling_factor work as for lpa. lmr deletes one class's growth-factor means (Θ and Ψ are shared); its H0 log-likelihood, LR and adjusted LR agree with Mplus TECH11 for LCGA and GMM (validation/mplus/*_k3_lrt.out).
  • With random growth factors EM can converge very slowly (a growth-factor variance near zero). When it reaches maxiter, or stops with a large gradient, the fit is finished by Newton–Raphson as Mplus switches from EM to quasi-Newton (convergence(m) says so); the finish works on Ψ itself, so the maximum may have a negative growth-factor variance (an inadmissible solution that Mplus reports too, with a warning here and a problem in convergence).
  • Limitations: continuous outcomes only; class-specific Ψ or Θ are not available; CPU only (there is no device keyword).

lca(data, K; starts = (100, 20), stage1_iter = 20, maxiter = 5000, tol = 1e-10,

    weights = nothing, cluster = nothing, strata = nothing, start = nothing,
    optseed = nothing) -> LatentMixtureModel

lca(data, K; level2, KB, covariates = nothing, between_covariates = nothing, starts,
    stage1_iter, maxiter, tol, seed, floor) -> MultilevelModel
lca(data, K; level2, random = :factor, covariates = nothing, between_covariates = nothing,

Latent class analysis of categorical indicators with K classes, by maximum likelihood with the EM algorithm from Mplus-style two-stage random starts.

With classes k = 1, …, K of size πₖ and item-response probabilities ρⱼcₖ = P(yⱼ = c | class k), the likelihood of case i is

Lᵢ = Σₖ πₖ(xᵢ) ∏ⱼ ∏_c ρⱼcₖ^1[yᵢⱼ = c],

with πₖ(x) = softmax(x'B)ₖ when covariates are given and constant πₖ otherwise. Products run over the observed items of case i only (full-information ML under MAR).

Arguments

  • data: an AbstractMatrix or any Tables.jl table (e.g. a DataFrame) whose columns are the indicators. Any values can be category codes (integers, strings, symbols, …); the sorted distinct observed values of a column are its categories (at least two). missing or NaN marks a missing response. Rows with every indicator missing are dropped (m.rows lists the rows analysed).
  • K::Integer: number of classes, K ≥ 1 (K ≥ 2 with covariates).

Estimation:

  • starts = (100, 20): (n₁, n₂) random starts, as Mplus STARTS = n₁ n₂. Stage 1 draws n₁ starts (item-response probabilities from a flat Dirichlet per item and class, equal class sizes) and runs stage1_iter EM iterations from each; stage 2 runs the n₂ best to convergence. n₂ is clamped to 1:n₁.
  • stage1_iter = 20: EM iterations per stage-1 start (Mplus STITERATIONS, default 10 in Mplus).
  • maxiter = 5000: maximum EM iterations per stage-2 start (Mplus MITERATIONS).
  • tol = 1e-10: convergence when the change in the log-likelihood divided by the number of analysed rows falls below tol.
  • seed = 20261119: random seed. Start s uses its own stream derived from (seed, s), so the solution does not depend on the number of threads.
  • device = :cpu: :cuda runs every E- and M-step on an NVIDIA GPU (needs using CUDA and a functional device); see the GPU tutorial.
  • floor = 1e-12: lower bound for item-response probabilities (keeps log ρ finite at the boundary; probabilities are renormalised within item afterwards).
  • start = nothing: user start values, a fitted model of the same type and K or the NamedTuple of svalues. EM then runs from these values only, without random starts (Mplus starting values with STARTS = 0); m.starts == (1, 1). CPU only.
  • optseed = nothing: a start number (m.finals[i].id): run only that random start, stage 1 and stage 2, as it ran in the multistart (Mplus OPTSEED; see refit_start).

Covariates and weights:

  • covariates = nothing: a vector, matrix or table of numeric covariates with one row per row of data. Class membership is then a multinomial logistic regression on the covariates, estimated jointly with the measurement model (one-step; Mplus c ON x). Rows with a missing covariate are deleted listwise. Dummy-code categorical covariates yourself.
  • ref = K: reference class of the regression coefficients in m.regression and coeftable(m) (Mplus: the last class). Ignored without covariates.
  • weights = nothing: sampling weights, one non-negative number per row of data (Mplus WEIGHT). They are rescaled to sum to the number of analysed rows; the log-likelihood, class proportions, classification tables and robust standard errors are weighted.

Complex survey design (Mplus TYPE = COMPLEX; see the manual section "Complex survey data"):

  • cluster = nothing: primary sampling unit (PSU) of every row of data (any codes; Mplus CLUSTER). Standard errors, the scaling correction factor and the tests built on them are then computed from PSU totals of the weighted scores (cases in a PSU are not independent). Estimates and the log-likelihood do not change.
  • strata = nothing: stratum of every row (Mplus STRATIFICATION). PSUs are nested in strata (equal cluster codes in different strata are different PSUs); without cluster every row is its own PSU. Combine with weights for Mplus WEIGHT. Analysed rows may not have a missing cluster or strata.

Multigroup (known-class) models:

  • group = nothing: a vector with one group label per row of data (Mplus KNOWNCLASS). Class proportions are then group-specific and a MultiGroupModel is returned. Rows with a missing group are dropped. cluster, strata, weights and covariates are allowed (not device ≠ :cpu).
  • With covariates (Mplus c ON cg; c ON x with KNOWNCLASS): class logits with group-specific intercepts and covariate slopes slopes = :equal across groups (Mplus c ON x in %OVERALL%) or :group (group-specific; the same model as Mplus c ON x x·g with the interaction). Rows with a missing covariate are deleted listwise; invariance = :none is not available with covariates (the classes would be relabelled per group).
  • invariance = :full: measurement model across groups: :full (invariant item-response probabilities), :none (group-specific), or a vector of indicators (column names as strings/symbols, or column indices) whose item-response probabilities are all group-specific (partial invariance); see the Notes for how this differs from lta.

Direct effects of covariates on indicators (DIF; Mplus u ON x):

  • direct = nothing, classspecific = []: item => covariate pairs and the items with class-specific slopes, as in mixture (which lca then calls with every column categorical); the covariates must be among covariates. Returns a kind = :MIXED model; combinable with weights, cluster, strata, not with group or level2.

Local dependence: pairs = [(:u4, :u5)] models pairs of items jointly within class, with the log-linear association association = :varying (class-specific; the pair as one joint item) or :equal across classes, as in mixture; bvr finds candidate pairs.

Two-level (multilevel) models (Mplus TYPE = TWOLEVEL MIXTURE with a between-level latent class variable; Vermunt 2003):

  • level2 = nothing: the cluster (level-2 unit) of every row of data, any codes; rows with a missing id are dropped. Requires KB.

  • KB = nothing: number of between classes M (Mplus CB). Each cluster belongs to one between class (probabilities π_m); the within-class probabilities depend on it, P(CW = k | CB = m) (Mplus cw ON cb); the item-response probabilities do not:

    L_j = Σ_m π_m ∏_{i ∈ j} Σ_k P(CW = k | CB = m) ∏ⱼ ρⱼ(yᵢⱼ | k).

    Estimated by EM with the upward–downward algorithm (in log space), Mplus-style random starts (each start draws P(CW | CB = m) per between class from a flat Dirichlet) and a Newton finish; returns a MultilevelModel. npar = (M − 1)(1 + Pz) + M(K − 1) + Px(K − 1) + K·Σⱼ(Cⱼ − 1); BIC uses the number of individuals, as Mplus. Not combinable with weights, group, cluster, strata, start, optseed or device ≠ :cpu. KB = 1 is the single-level model.

  • covariates (with KB): within covariates x of the within class, log W[k, m](x) = Γ[k, m] + x'bₖ (Mplus cw ON x in %WITHIN% %OVERALL%: intercepts specific to the between class, slopes common to all between classes); between_covariates: cluster-level covariates z of the between class, log π_m(z) ∝ c_m + z'd_m (Mplus cb ON z), constant within each cluster. Rows with a missing covariate are deleted listwise (a cluster with a missing z entirely). The class model is then estimated by Newton steps within EM.

Two-level models with random class intercepts (parametric; Mplus TYPE = TWOLEVEL MIXTURE with f BY c#1 … c#(K−1) on the between level, User's Guide example 10.6):

  • random = :factor (with level2, without KB): the class log-odds against class K are xᵢ'bₖ + λₖ fⱼ with a normal between-level factor fⱼ = wⱼ'γ + ζⱼ, ζⱼ ~ N(0, ψ), loadings λ₁ = 1 and λ₂ … λ_{K−1} free (K = 2: one random intercept).
  • covariates: within (individual-level) covariates x of the class (c ON x); between_covariates: cluster-level covariates w of the factor (f ON w), constant within each cluster. Rows with a missing covariate are deleted listwise.
  • integration = 15: Gauss–Hermite points for the integral over f; adaptive = true centres and scales them at each cluster's posterior mean and SD of f (adaptive quadrature), which makes 15 points accurate to about 10⁻⁵ in the log-likelihood here. Mplus's default (INTEGRATION = STANDARD(15), adaptive rectangular) is less accurate; see the Validation page.
  • Estimated by EM over the quadrature nodes (exact M-step for the item parameters, Newton steps for the class model) from random starts, then Newton–Raphson on the marginal log-likelihood; returns a MultilevelRandomModel. npar = K·Σⱼ(Cⱼ − 1) + (K − 1)(1 + P) + (K − 2) + Pb + 1.

Returns

A LatentMixtureModel (kind = :LCA), a MultiGroupModel when group is given, a MultilevelModel with level2 and KB, or a MultilevelRandomModel with level2 and random. Classes are ordered by estimated size (largest first).

Examples

using LatentMixtures
# Latent classes of eight adverse childhood experiences (aces: 1,500 adults, items ace_*,
# 2% missing each, handled by FIML)
d = dataset("aces")
Y = d[:, r"^ace_"]
m = lca(Y, 4)
convergence(m)                # check that the best LL is replicated and EM reached the maximum
classprobs(m)                 # ≈ 0.56, 0.19, 0.16, 0.10 (generated 0.52, 0.20, 0.17, 0.11)
fitstats(m)                   # LL, npar, AIC, BIC, saBIC, CAIC, entropy, replication
itemprobs(m)[1].probs         # P(emotional abuse = 0, 1 | class): 0.79 "yes" in class 2
parameters(m)                 # every parameter with its robust SE

lca(Y, 4; covariates = d[:, [:female, :age, :low_parent_edu]])   # one-step c ON x
lca(Y, 4; weights = d.weight)                                    # sampling weights
lca(Y, 4; group = d.female, invariance = [:ace_sex_abuse])       # partial invariance by sex

# 4 within classes, 5 between classes
using DelimitedFiles
A = readdlm(joinpath(pkgdir(LatentMixtures), "validation", "data", "ex10_7.dat"))
ml = lca(A[:, 1:10], 4; level2 = A[:, 13], KB = 5, starts = (100, 10))
conditionalprobs(ml)          # P(within class | between class)

# Random class intercepts, Mplus User's Guide ex10.6: c ON x within, f ON w between
B = readdlm(joinpath(pkgdir(LatentMixtures), "validation", "data", "ex10_6.dat"))
ri = lca(B[:, 1:6], 3; level2 = B[:, 10], random = :factor, covariates = B[:, 7],
         between_covariates = B[:, 8])
coeftable(ri)

Notes

  • Mirrors Mplus CATEGORICAL = …; CLASSES = c(K); ANALYSIS: TYPE = MIXTURE; ESTIMATOR = MLR; STARTS = 100 20; STITERATIONS = 20 (the Mplus default STARTS is 20 4). The log-likelihood, number of parameters, information criteria, entropy and every parameter agree with Mplus 8 on the cases in validation/ (see the Validation page).
  • npar = (K - 1)·P + K·Σⱼ(Cⱼ - 1), with P = 1 + number of covariates.
  • Identical response patterns are collapsed and weighted (without covariates), so the cost of an EM iteration grows with the number of distinct patterns, not with n.
  • Standard errors are not computed by lca; parameters computes them on first use (robust sandwich as Mplus MLR; thresholds whose cumulative probability is within 10⁻⁵ of 0 or 1 are held fixed, as Mplus fixes thresholds at ±15).
  • A best log-likelihood that is replicated by only one stage-2 start (bestll_replicated) suggests a local maximum: increase starts.
  • Partial invariance, multigroup versus LTA: here a listed item has all its parameters group-specific. In lta(...; indicators = :continuous, invariance = [items]) a plain item list frees only the item means across waves (variances stay invariant); see lta.
  • Multigroup models run on the CPU; with covariates, start values (start) are not available.

LatentMixtures.lpa — Method
lpa(data, K; variances = :equal, covariances = :zero, starts = (100, 20),
    stage1_iter = 20, maxiter = 5000, tol = 1e-10, seed = 20261119, device = :cpu,
    reg = 1e-6, covariates = nothing, ref = K, weights = nothing, cluster = nothing,
    strata = nothing) -> LatentMixtureModel
lpa(data, K; group, invariance = :full, variances = :equal, starts, stage1_iter,
    maxiter, tol, seed, reg, cluster, strata) -> MultiGroupModel
lpa(data, K; level2, KB, variances = :equal, covariates = nothing,
    between_covariates = nothing, starts, stage1_iter, maxiter, tol, seed, reg)
    -> MultilevelModel

Latent profile analysis (a finite mixture of multivariate normal distributions) of continuous indicators with K profiles, by maximum likelihood with the EM algorithm from Mplus-style two-stage random starts.

Within profile k the indicators are normal with means μₖ and covariance matrix Σₖ:

Lᵢ = Σₖ πₖ(xᵢ) φ(yᵢ,obs; μₖ,obs, Σₖ,obs),

where Σₖ is diagonal (local independence, the default) or full, equal across profiles or profile-specific (see variances and covariances), and only the observed indicators of case i enter (full-information ML under MAR).

Arguments

  • data: an AbstractMatrix or Tables.jl table of numeric indicators (columns). missing or NaN marks a missing value; rows with every indicator missing are dropped.
  • K::Integer: number of profiles, K ≥ 1 (K ≥ 2 with covariates).

Model:

  • variances = :equal: within-profile variances equal across profiles (Mplus default; mclust EEI; tidyLPA model 1), or :varying: profile-specific (mclust VVI; tidyLPA model 2).
  • covariances = :zero: indicators uncorrelated within profile. :equal (requires variances = :equal): one full covariance matrix shared by all profiles (mclust EEE; tidyLPA model 3; Mplus y1-y5 WITH y1-y5; in %OVERALL%). :varying (requires variances = :varying): a full covariance matrix per profile (mclust VVV; tidyLPA model 6; the WITH statements repeated in every class). CPU only.
  • reg = 1e-6: ridge added to every variance on the standardised scale, so the likelihood is bounded (a profile cannot collapse onto a single point).

Estimation (as in lca):

  • starts = (100, 20): stage-1 and stage-2 random starts (Mplus STARTS). A start sets the profile means to K distinct randomly chosen rows and all variances to 1 on the standardised scale.
  • stage1_iter = 20: EM iterations per stage-1 start (Mplus STITERATIONS).
  • maxiter = 5000: maximum EM iterations per stage-2 start.
  • tol = 1e-10: convergence when the change in the log-likelihood per analysed row falls below tol.
  • seed = 20261119: random seed (per-start streams; thread-count independent).
  • device = :cpu: or :cuda (after using CUDA) for diagonal models.
  • start = nothing, optseed = nothing: user start values / one random start, as in lca.

Covariates, weights, groups (as in lca):

  • covariates = nothing, ref = K: one-step multinomial logit of profile membership (Mplus c ON x); listwise deletion of rows with a missing covariate.
  • weights = nothing: sampling weights, rescaled to sum to the number of analysed rows.
  • cluster = nothing, strata = nothing: complex survey design (Mplus TYPE = COMPLEX with CLUSTER and STRATIFICATION): design-based standard errors and scaling factor from PSU totals of the weighted scores; estimates unchanged.
  • group = nothing: known groups (Mplus KNOWNCLASS); returns a MultiGroupModel (diagonal covariances, CPU); covariates with slopes = :equal or :group and weights as in lca.
  • invariance = :full: :full, :none, or a vector of indicators whose means and variances are group-specific (partial invariance; compare lta, where a plain item list frees only the means).

Returns

A LatentMixtureModel (kind = :LPA) whose means, variances and covariances (profilemeans, profilevariances, profilecovariances) and log-likelihood are on the original scale of the data; a MultiGroupModel with group; a MultilevelModel (kind = :LPA) with level2 and KB.

Direct effects of covariates on indicators (Mplus y ON x): direct, classspecific as in mixture (y | k, x ~ N(αₖ + x'β, σ²); lpa then calls mixture with every column continuous; diagonal covariances, no group or level2). Within-class covariances of selected pairs (Mplus y1 WITH y2): with = [(:y1, :y2)], equal across classes with variances = :equal, class-specific with :varying (see mixture).

Two-level (multilevel) LPA: level2 (cluster id of every row) and KB (number of between classes) as in lca: clusters belong to between classes that shift the within-profile probabilities P(CW = k | CB = m); the profile means and variances do not depend on the between class (Mplus TYPE = TWOLEVEL MIXTURE with WITHIN = y1-y5, BETWEEN = cb, cw ON cb). Diagonal covariances (variances = :equal or :varying); covariates (cw ON x) and between_covariates (cb ON z) as in lca; no weights, groups or survey design. npar = (M − 1) + M(K − 1) + K·J + (equal ? 1 : K)·J.

lta(data, waves, K; indicators = :categorical, invariance = :full,

    maxiter = 5000, tol = 1e-10, seed = 20261119, cluster = nothing,

lta(data, waves, K; indicators = :continuous, variances = :equal,
    covariances = :zero, invariance = :full, transitions = :timevarying,
    reg = 1e-6, starts, stage1_iter, maxiter, tol, seed, cluster, strata) -> LTAModel
lta(data, waves, K; covariates, covariates_on = :all, interaction = false,
    distal = nothing, distal_categorical = nothing, distal_wave = T,
    distal_variances = :equal, …) -> LTAModel

Latent transition analysis: K latent classes at each of T waves, first-order Markov transitions between consecutive waves, and a latent class (categorical indicators) or latent profile (continuous indicators) measurement model at every wave, estimated by ML with the EM (Baum–Welch, forward–backward) algorithm from two-stage random starts.

P(yᵢ) = Σ_{c₁…c_T} π_{c₁} ∏_{t=2}^{T} A_{t-1}[c_{t-1}, c_t] ∏_{t=1}^{T} f(yᵢₜ | Cₜ = c_t)

Arguments

  • data: matrix or Tables.jl table holding the indicators of all waves.
  • waves: the indicator columns of each wave, as a vector of index ranges/vectors or of column names (strings or symbols), with the same items in the same order at every wave, e.g. [1:6, 7:12, 13:18] or [[:a1, :b1], [:a2, :b2]]. T = length(waves) ≥ 2.
  • K::Integer: classes per wave, K ≥ 2.

Measurement model:

  • indicators = :categorical: item-response probabilities per class (any category codes, as in lca); or :continuous: normal indicators with class-specific means (a latent profile model at every wave).
  • variances = :equal (continuous only): within-class variances equal across classes (Mplus default) or :varying.
  • covariances = :zero (continuous only): local independence; :equal (with variances = :equal) one full within-class covariance matrix; :varying (with variances = :varying) one per class.
  • reg = 1e-6 (continuous only): ridge added to every variance (standardised scale).
  • invariance = :full: measurement parameters equal across waves (the usual LTA, Mplus equality labels across waves). :none: estimated separately at every wave. For continuous indicators also partial invariance, wave 1 being the reference:
    • a vector of item positions or names, e.g. [2, 4]: the means only of these items are wave-specific at every wave t ≥ 2; their variances (and every other parameter) stay invariant;
    • a vector of pairs item => waves, e.g. [2 => 3, 4 => 3] or [2 => [2, 3]]: the mean of the item has its own parameter at each listed wave; the other waves share the wave-1 mean;
    • (means = spec, variances = spec) with specs of either form (or :full/:none): frees means and variances separately (variances only with covariances = :zero).
    Categorical indicators accept :full and :none only.

Structural model:

  • transitions = :timevarying: a transition matrix per pair of consecutive waves (Mplus default), or :stationary: one matrix for all transitions.

Covariates and distal outcomes (one step, estimated jointly with the measurement model):

  • covariates: columns of data (names or indices) with numeric covariates, e.g. [:female, :ses], used at every wave; or one list per wave for time-varying covariates, e.g. [[:x_1], [:x_2], [:x_3]] (wave t's columns enter the initial classes at t = 1 and the transition into wave t). Rows with a missing covariate are deleted (Mplus). The model is log P(C₁ = k | x)/P(C₁ = K | x) = β₀ₖ + x'βₖ and log P(Cₜ = l | Cₜ₋₁ = k, x)/P(Cₜ = K | Cₜ₋₁ = k, x) = aₗ + bₗₖ + x'gₗ (Mplus c1 ON x; c2 ON c1 x;).
  • covariates_on = :all: covariates on the initial classes and the transitions, :initial (only c1 ON x) or :transitions.
  • interaction = false: with true the covariate effects on a transition depend on the class at the previous wave, gₗ(k) (Mplus c2 ON x within MODEL c1:, User's Guide Ex. 8.14).
  • distal: columns of distal outcomes of the class at wave distal_wave (default T), class-specific means (normal, variances distal_variances = :equal or :varying) or, for the columns also listed in distal_categorical, class-specific category probabilities (Mplus: the outcome in the class-specific part of MODEL cT:). Missing outcomes are handled by FIML.
  • weights = nothing: sampling weights, one non-negative number per row of data, rescaled to sum to the number of analysed rows (Mplus WEIGHT); the likelihood, the M-steps and the three-step classification errors are weighted, and the robust SEs use the squared weights in the score outer products (MLR). Usable with or without covariates.

The model without covariates and distal outcomes is fitted first and its solution used as an extra start. Results: parameters and coeftable (robust SEs, Mplus parameterisation), transitions(m; at = x) for probabilities at covariate values; transitions(m) and classprobs(m) are then averaged over the sample (trans[t][k, l] = Σᵢ P(Cₜ = k | xᵢ) P(Cₜ₊₁ = l | k, xᵢ) / Σᵢ P(Cₜ = k | xᵢ)). Three-step alternatives that keep the measurement model fixed: lta3step, r3step and bch.

Estimation (as in lca):

  • starts = (100, 20), stage1_iter = 20, maxiter = 5000, tol = 1e-10, seed = 20261119. Starts draw item-response probabilities from a flat Dirichlet (categorical) or the means from K random fully observed wave records (continuous), equal initial class sizes and diagonally dominant random transition matrices. start (a fitted LTAModel or its svalues) and optseed (one random start) as in lca.

Complex survey design:

  • cluster = nothing, strata = nothing: PSU and stratum of every row (Mplus TYPE = MIXTURE COMPLEX with CLUSTER / STRATIFICATION). The estimates do not change; scaling_factor and compare_models become design-based (see lca); with them parameters gives design-based standard errors. Combine with weights (Mplus WEIGHT) for weighted designs.

Returns

An LTAModel.

Notes

  • Mirrors Mplus CLASSES = c1(K) c2(K) c3(K); ANALYSIS: TYPE = MIXTURE; with c2 ON c1; c3 ON c2; and equality labels on the measurement parameters of the waves. Stationary transitions correspond to equal cₜ₊₁ ON cₜ slopes and intercepts.
  • Partial invariance and the multigroup API differ: in lta(...; indicators = :continuous, invariance = [items]) a plain item list frees only the means of those items across waves, whereas in multigroup lca/lpa(...; group, invariance = [items]) a plain item list frees all parameters of those items across groups. The LTA equivalent of the multigroup behaviour is invariance = (means = items, variances = items) (with covariances = :zero).
  • Missing items and entirely missing waves (dropout) are handled by FIML: a missing wave contributes f = 1 in the forward–backward recursions. Rows with no observed indicator at any wave are dropped.
  • Continuous indicators are standardised with one centre and scale per item position, pooled over the waves (so invariant parameters are on one scale); parameters and the log-likelihood are reported on the raw scale (Jacobian term as in lpa). With partial invariance the measurement M-step is an ECM step (means by weighted least squares given the previous variances, then variances given the means), which still increases the likelihood at every iteration.
  • Entropy is computed over all K^T class paths, which is costly for large K^T.
  • Standard errors: parameters(m) (sandwich, MLR) for every LTA. Covariate models do not compress response patterns (each case has its own structural probabilities), so they take longer on large data.
  • Limitations: no GPU, or higher-order (lag > 1) transitions; categorical indicators cannot be partially invariant; distal outcomes depend on the class of one wave (for class patterns use bch with waves).

LatentMixtures.mixture — Method
mixture(data, K; categorical = nothing, continuous = nothing, count = nothing,
        negbin = nothing, zip = nothing, variances = :equal, dispersion = :equal,
        inflation = :equal, starts = (100, 20), stage1_iter = 20, maxiter = 5000,
        tol = 1e-10, seed = 20261119, floor = 1e-12, reg = 1e-6, covariates = nothing,
        ref = K, weights = nothing, cluster = nothing, strata = nothing, start = nothing,
        optseed = nothing, direct = nothing, classspecific = Symbol[], pairs = nothing,
        association = :varying, with = nothing) -> LatentMixtureModel

Latent class (mixture) model with indicators of several types in one model: categorical (binary or polytomous), continuous (normal), and count indicators (Poisson, negative binomial, zero-inflated Poisson), estimated by maximum likelihood with the EM algorithm from Mplus-style random starts.

Indicators are independent within class (local independence, across and within types), so the likelihood of case i is

Lᵢ = Σₖ πₖ(xᵢ) ∏_categorical ρⱼ(yᵢⱼ | k) ∏_continuous φ(yᵢⱼ; μⱼₖ, σ²ⱼₖ) ∏_count fⱼ(yᵢⱼ | k),

with products over the observed indicators of case i only (full-information ML under MAR), and πₖ(x) = softmax(x'B)ₖ with covariates. Count models have class-specific means on the log scale (log link):

  • Poisson (count): f(y) = λʸ e^{−λ} / y!;
  • negative binomial (negbin, NB2): mean μ, variance μ + αμ², dispersion α;
  • zero-inflated Poisson (zip): f(0) = π + (1 − π)e^{−λ}, f(y) = (1 − π) λʸ e^{−λ}/y! for y > 0, with π the probability of a structural zero.

Arguments

  • data: an AbstractMatrix or a Tables.jl table (e.g. a DataFrame) holding the indicators (other columns are ignored). missing/NaN mark missing values; rows with every indicator missing are dropped (m.rows lists the analysed rows).
  • K::Integer: number of classes (K ≥ 2 with covariates).

Indicators (at least one type; a column may appear in one type only). Each is a column name (String/Symbol), a column index, a Regex matched against the names, or a vector of these:

  • categorical: categorical indicators; any category codes, the sorted distinct values of a column are its categories (Mplus CATEGORICAL).
  • continuous: normal indicators (Mplus default for unlisted variables).
  • count: Poisson counts (Mplus COUNT = u (p)); values must be non-negative integers.
  • negbin: negative binomial counts (Mplus COUNT = u (nb)).
  • zip: zero-inflated Poisson counts (Mplus COUNT = u (pi)).

Measurement model:

  • variances = :equal: within-class variances of the continuous indicators, :equal across classes (Mplus default) or :varying.
  • dispersion = :equal: negative binomial dispersions :equal across classes (Mplus default) or :varying.
  • inflation = :equal: zero-inflation probabilities :equal across classes (Mplus default) or :varying.

Direct effects of covariates on indicators (differential item functioning; Mplus u ON x / y ON x):

  • direct = nothing: item => covariate pairs (or item => [covariates]), e.g. direct = [:u3 => :x1, :u6 => [:x1, :x2]]; the covariates must be among covariates. A categorical item then follows a cumulative logit (Mplus's ordered model for CATEGORICAL items) P(u ≤ c | k, x) = logistic(τₖ꜀ − x'β); a continuous item y | k, x ~ N(αₖ + x'β, σ²ₖ). The slope β is equal across classes (Mplus u ON x in %OVERALL%) unless the item is listed in
  • classspecific = []: items whose direct effects are class-specific, βₖ (Mplus u ON x repeated in every %c#k%); true for all items with direct effects.
  • Only categorical and continuous indicators can have direct effects; with them the fit is finished by Newton–Raphson, start values (start) are not available, and itemprobs / profilemeans cover only the indicators without direct effects (parameters lists thresholds or intercepts, "direct effect" slopes and residual variances for the others).

Local dependence (residual association within class):

  • pairs = nothing: pairs of categorical indicators modelled jointly within class, e.g. pairs = [(:u4, :u5)] (an indicator in one pair only). The pair's cells follow the log-linear model P(a, b | k) ∝ exp(αₖₐ + βₖ_b + λ_(k)ab) (Hagenaars 1988; Latent GOLD's "direct effects between indicators"); a row with one item of the pair missing contributes the margin of the other (FIML).
  • association = :varying: λ class-specific (the saturated table of the pair: the pair as one joint nominal item, Mplus NOMINAL = u45 with u45 = C₂(u4 − 1) + u5) or :equal across classes. parameters lists the "joint logit"s (log odds of every cell against the last, Mplus [u45#c]) and the "association" λ (for a binary pair the within-class log odds ratio).
  • with = nothing: pairs of continuous indicators with a within-class covariance (Mplus y1 WITH y2), e.g. with = [(:y3, :y4)]. Connected pairs form blocks with a full covariance matrix (list every pair inside a block); the block's covariance matrix is equal across classes with variances = :equal (WITH in %OVERALL%) and class-specific with variances = :varying (WITH and the variances in every %c#k%). parameters adds "covariance" rows.
  • bvr gives bivariate residuals of the categorical indicators of a fitted model to find locally dependent pairs.

Estimation, covariates and weights as in lca and lpa: starts, stage1_iter, maxiter, tol, seed, floor (lower bound of item-response probabilities), reg (ridge added to the standardised variances), covariates (one-step multinomial logit of class membership, Mplus c ON x), ref, weights (sampling weights, Mplus WEIGHT), and the complex survey design cluster / strata (Mplus TYPE = MIXTURE COMPLEX with CLUSTER / STRATIFICATION: design-based standard errors and scaling factors, as in lca). start (a fitted mixture model with the same indicators, or its svalues) runs EM from those values only; optseed reruns a single random start (m.finals[i].id; Mplus OPTSEED, see refit_start).

Returns

A LatentMixtureModel with kind = :MIXED. m.names lists the indicators by type (categorical, continuous, Poisson, negative binomial, zero-inflated) and, within type, in the order given. Accessors: itemprobs (categorical indicators), profilemeans / profilevariances (continuous indicators, raw scale), countparams (count indicators), and every model-agnostic function (parameters, fitstats, posterior, classify, r3step, bch, dcat, lmr, blrt, …).

LatentMixtures.convergence — Method
convergence(m; newton = true) -> ConvergenceReport

Check whether a fitted model reached a trustworthy maximum of the likelihood.

The checks are those Mplus reports for mixture models:

  1. the best random start met the EM convergence criterion (|ΔLL|/N < tol) within maxiter;
  2. the best log-likelihood is replicated by at least two stage-2 starts; otherwise the solution may be a local maximum (Mplus: "THE BEST LOGLIKELIHOOD VALUE WAS NOT REPLICATED");
  3. with newton = true, safeguarded Newton steps from the EM estimates raise the log-likelihood by less than 10⁻³ and the gradient there is small (Mplus' derivative criterion), i.e. EM did not stop short of the maximum;
  4. the solution is not degenerate: growth factor covariance not nearly singular (GMM), no within-profile variance at zero (LPA); boundary item probabilities (LCA) and classes below 5% are reported as notes.

Checks 1, 2 and the growth-factor check also run automatically at the end of every fit and emit a warning when they fail.

lca, lpa and growth (CPU) finish a fit by Newton–Raphson when EM reached maxiter or stopped with a large gradient (as Mplus switches from EM to quasi-Newton); the report then has a note with the EM log-likelihood, the gain and the gradient before and after, and checks 1 and 3 refer to the finished solution. A standalone likelihood that does not reproduce the EM log-likelihood at the estimates is reported as a problem ("internal likelihood mismatch"; the Newton check and standard errors would be for another model).

Arguments

  • m: a fitted LatentMixtureModel, MultiGroupModel or LTAModel.

Keywords

  • newton::Bool = true: run check 3 (costs one Hessian of the log-likelihood).

Returns

A ConvergenceReport; report.ok is true when no problem was found.

Examples

  • m: the fitted model; the Mplus input must name the variables, classes and growth factors as to_mplus does (e.g. the output of to_mplus(m; …, run = true)).
  • outfile: the Mplus .out file.
  • categorical = :auto: :ordinal or :nominal coding of categorical items (:auto detects it from the output).
  • align = true: find the order of the Mplus classes that best matches the Julia classes (all K! orders for K ≤ 7); with false Mplus class c is Julia class c (the case after to_mplus(m; svalues = true)).

Returns

An MplusComparison. Julia standard errors are those of parameters (robust or design-based): every parameter of single-group models (class logits only when the reference class is the same), the measurement parameters and group logits of multigroup models, and every parameter of LTA models (the invariant ones at the first wave that uses them).

Examples

r = to_mplus(m; file = "aces4.inp", run = true)   # needs Mplus

c.max_diff, c.ll_diff

Notes

Mplus prints estimates with three decimals, so differences up to 5e-4 are rounding. Mplus fixes thresholds at ±15 at the boundary; the Julia values are clamped the same way.

LatentMixtures.refit_start — Method
refit_start(m, id) -> fitted model

Refit m from its random start number id only (the analogue of Mplus OPTSEED): the same data, options and seed, stage 1 (stage1_iter EM iterations from the start's own random-number stream) and stage 2 (EM to convergence), exactly as that start ran inside the multistart. id is the id of an entry of m.finals (Mplus prints the seeds of the best starts in the same way); the default start settings are starts = (100, 20), stage1_iter = 20 — draw 100 random starts, iterate each 20 times, and run the 20 best to convergence (Mplus STARTS = 100 20; STITERATIONS = 20).

The same is available when fitting: lca(data, K; optseed = id) (also lpa, growth, lta).

Arguments

  • m: a model fitted by lca, lpa, growth or lta (single- or multigroup).
  • id::Integer: the start number (m.finals[i].id).

Returns

A model of the same type with one start (m.starts == (1, 1)), whose log-likelihood is the ll of that start in m.finals.

Examples

using LatentMixtures
d = dataset("aces")
m = lca(d[:, r"^ace_"], 4)
second = m.finals[findfirst(f -> f.ll < m.finals[1].ll - 1e-3, m.finals)]   # a local maximum
r = refit_start(m, second.id)
loglikelihood(r) ≈ second.ll        # true: the local solution, for inspection

Notes

The model keeps a reference to the data it was fitted on (m.cache[:call]); if you modified the data since, refit with optseed instead. Up to floating-point rounding in multithreaded BLAS the result is the same whatever the number of threads.

LatentMixtures.svalues — Method
svalues(m) -> NamedTuple

The estimates of a fitted model as a set of start values (the analogue of Mplus OUTPUT: SVALUES), to pass as start to lca, lpa, growth or lta. Classes are in the reported order of m, continuous parameters on the original scale of the data.

Arguments

  • m: a LatentMixtureModel, MultiGroupModel or LTAModel.

Returns

A NamedTuple whose kind field names the model type, with

  • mixture models (kind = :MIXED): K, classprobs, B, types and names (indicator blocks), categorical levels and itemprobs, continuous means and vars (J × K), and counts (as countparams);
  • LatentMixtureModel (kind = :LCA, :LPA, :LCGA, :GMM): K, classprobs, B (P × K class logits against the last class with covariates, else nothing), LCA levels and itemprobs (ncat × K per item), LPA means (J × K) and covs (one J × J matrix per class), growth α (q × K), Θ and Ψ;
  • MultiGroupModel (kind = :MG): model (:LCA/:LPA), K, classprobs (per group) and params (per group, as in the model) and levels;
  • LTAModel (kind = :LTA): K, T, initial, trans, and itemprobs with levels (per wave and item; categorical indicators) or means/covs (per wave; continuous indicators); with covariates or distal outcomes also B1 (P₁ × K initial-class logits), G (per transition, P × K × K logits of the destination class given the origin, G[s][:, l, k]) and distal (per distal outcome: category probabilities C × K, or (μ, σ2) 1 × K), all against the last class.

You can edit the values (e.g. to start from a theory-driven solution) as long as the shapes stay the same; item probabilities are renormalised and floored before use.

Examples

using LatentMixtures
d = dataset("aces")
m = lca(d[:, r"^ace_"], 4)
sv = svalues(m)
m2 = lca(d[:, r"^ace_"], 4; start = sv)     # EM from m's estimates: one start, same solution
loglikelihood(m2) ≈ loglikelihood(m)         # true
lca(d[:, r"^ace_"], 4; start = m)            # a fitted model works as well

Notes

With start, no random starts are drawn (Mplus STARTS = 0 with user starting values): EM runs from the given values to convergence, m.starts == (1, 1) and the convergence check cannot test replication. For a local search around the values, fit with random starts instead and compare.

LatentMixtures.to_mplus — Method
to_mplus(m; file, datafile = splitext(file)[1] * ".dat", svalues = true,
         categorical = :ordinal, title = nothing, analysis = nothing,
         output = "SVALUES;", tight = true, run = false, mplus = nothing) -> NamedTuple

Write the data of a fitted model and an Mplus input file that specifies the same model, so the fit can be reproduced (or audited) in Mplus.

Arguments

  • m: a model fitted by lca, lpa, growth or lta: LCA (ordinal or nominal coding), LPA (equal or profile-specific variances, zero, equal or profile-specific covariances), covariates (c ON x), sampling weights (WEIGHT), multigroup models (KNOWNCLASS, full/partial/no invariance through equality labels), LTA (categorical or continuous indicators, any invariance, time-specific or stationary transitions; covariates c1 ON x; c2 ON c1 x, also time-varying, wave-specific (covariates_on) or class-specific (interaction, c2 ON x within MODEL c1:); distal outcomes in the class-specific part of MODEL cT:; sampling weights), LCGA, GMM and parallel-process growth models; mixture models with categorical, continuous and count indicators (COUNT = u (p), (nb), (pi), class-varying variances, dispersions and inflations); complex survey designs (cluster, strata: TYPE = MIXTURE COMPLEX with CLUSTER and STRATIFICATION, the PSU written as the (stratum, cluster) pair).
  • file: path of the .inp file to write.
  • datafile: path of the data file (free format, one row per analysed case, missing values coded with a flag that does not occur in the data, -999 by default); referenced from the input by its path relative to file (keep both in one folder).
  • svalues = true: give every free parameter the Julia estimate as its starting value (Mplus *value syntax, as OUTPUT: SVALUES prints them) and run no random starts (STARTS = 0), so Mplus converges to the same solution with the classes in the same order. With false, the input uses random starts (STARTS = n₁ n₂; STITERATIONS = … from the fit) and the classes may come out in another order (compare_mplus aligns them).
  • categorical = :ordinal: LCA/LTA items as CATEGORICAL (thresholds) or :nominal (NOMINAL, multinomial intercepts); both specify the same unrestricted model.
  • tight = true: tighter EM convergence criteria than the Mplus defaults (MCONVERGENCE = 1E-8; LOGCRITERION = 1E-9; RLOGCRITERION = 1E-12, close to the Julia default tol = 1e-10), so that weakly identified parameters agree as well; false keeps the Mplus defaults. With run = true, an Mplus run that does not terminate normally under the tight criteria is repeated with the defaults (with a warning).
  • title, analysis, output: the TITLE, extra ANALYSIS options (e.g. "PROCESSORS = 4;") and the OUTPUT command.
  • run = false: run Mplus on the written input (in the input's folder) and return the path of the output; mplus is the Mplus executable (default: ENV["MPLUS"], mplus on the PATH, or /Applications/Mplus/mplus).

Returns

(inp, dat, out, names): the paths written (out = nothing unless run), and the original → Mplus variable names (Mplus names must have at most 8 characters; other names are replaced by y1, y2, …, x1, … and listed as comments in the input).

Examples

using LatentMixtures

m = lca(d[:, r"^ace_"], 4; covariates = d[:, [:female, :age]])
r = to_mplus(m; file = "aces4.inp")       # aces4.inp + aces4.dat
# r = to_mplus(m; file = "aces4.inp", run = true); compare_mplus(m, r.out)

Notes

  • Categorical indicators are written as 0, 1, …, C − 1 (positions in the sorted categories, listed in the input).
  • The Julia estimator adds a ridge of reg (10⁻⁶ on the standardised scale) to the variances; differences from Mplus are far below its printed precision.
  • Not exported: the three-step and BCH/DCAT auxiliary models (r3step, bch, dcat) and bootstrap/LMR tests — they are post-estimation computations on the exported model.

LatentMixtures.LTAModel — Type
LTAModel <: StatsAPI.StatisticalModel

A fitted latent transition analysis: the result of lta. One categorical latent variable Cₜ with K classes per wave t = 1, …, T, first-order Markov transitions P(Cₜ₊₁ = l | Cₜ = k), and a latent class (categorical indicators) or latent profile (continuous indicators) measurement model at every wave.

Classes are labelled consistently across waves and ordered by their size at wave 1. Shared (invariant) measurement parameters tie the labels across waves; when a wave has no shared parameter (invariance = :none, or all means of a wave freed) its classes are matched to wave 1 by their profiles.

Fields

  • K::Int, T::Int: classes per wave, number of waves.
  • n::Int, ninput::Int, rows::Vector{Int}: analysed rows (at least one observed indicator at some wave), input rows, and the analysed input rows.
  • ll::Float64: log-likelihood (raw scale for continuous indicators).
  • npar::Int: free parameters as Mplus counts them: K − 1 initial logits, K(K − 1) transition logits per transition matrix (one matrix if stationary), and the measurement parameters.
  • initial::Vector{Float64}: P(C₁ = k).
  • trans::Vector{Matrix{Float64}}: T − 1 matrices, trans[t][k, l] = P(Cₜ₊₁ = l | Cₜ = k) (rows sum to 1; all equal when stationary).
  • itemprobs::Vector{Vector{Matrix{Float64}}}: categorical indicators: wave → item → ncat × K item-response probabilities (empty for continuous indicators).
  • levels::Vector{Vector{Any}}: categories per item position.
  • names::Vector{Vector{String}}: wave → indicator names.
  • posterior::Vector{Matrix{Float64}}: wave → n × K marginal posteriors P(Cₜ = k | yᵢ).
  • entropy_joint::Float64: relative entropy over the K^T class paths.
  • invariance::Symbol: :full, :none or :partial (continuous indicators).
  • transition_type::Symbol: :timevarying or :stationary.
  • starts, finals, converged: as in LatentMixtureModel.
  • indicators::Symbol: :categorical or :continuous.
  • means::Vector{Matrix{Float64}}: continuous: wave → J × K profile means (raw scale).
  • covs::Vector{Vector{Matrix{Float64}}}: continuous: wave → class → J × J within-class covariance matrix (raw scale).
  • variances::Symbol, covariances::Symbol: continuous: the variances/covariances options of the fit.
  • freemeans::Matrix{Bool}, freevars::Matrix{Bool}: T × J; true where the mean (variance) of item j at wave t has its own parameter instead of the wave-1 one (row 1 is always false).
  • cache::Dict{Symbol,Any}: internal estimates and data (:kernels, :w, :ρs, :logπ1, :logA, and for continuous indicators :shift, :struct, :center, :scale) used by scaling_factor, and cached results.

posterior(t; wave = 3)     # status probabilities of every student at grade 12

LatentMixtures.LatentMixtureModel — Type
LatentMixtureModel <: StatsAPI.StatisticalModel

A fitted single-group mixture model: the result of lca, lpa and growth (without group). Classes are ordered by estimated size, largest first; the last class is the reference for class logits unless ref was given.

Use the accessor functions rather than the fields where one exists (they are the stable interface): fitstats, parameters, posterior, classprobs, itemprobs, profilemeans, growthparams, classify, …, and the StatsAPI methods loglikelihood, nobs, dof, aic, bic, predict, vcov, stderror, coeftable.

  • kind::Symbol: :LCA, :LPA, :LCGA or :GMM.
  • K::Int: number of classes.
  • n::Int: number of analysed rows (rows with at least one observed indicator and, with covariates, no missing covariate).
  • ninput::Int: number of rows of the input data.
  • rows::Vector{Int}: the input rows that were analysed (row i of posterior(m) is input row rows[i]).
  • ll::Float64: maximised log-likelihood on the original scale of the data.
  • npar::Int: number of free parameters, counted as Mplus counts them.
  • classprobs::Vector{Float64}: estimated class proportions (weighted mean posterior).
  • posterior::Matrix{Float64}: n × K posterior class probabilities.
  • names::Vector{String}: indicator names (table column names, or Y1, Y2, … for a matrix).
  • levels::Vector{Vector{Any}}: LCA only; the sorted categories of each indicator.
  • itemprobs::Vector{Matrix{Float64}}: LCA only; for item j a ncat_j × K matrix of P(item j = levels[j][c] | class k).
  • variances::Symbol: LPA: :equal or :varying across profiles (:none for LCA, :equal for growth models).
  • means::Matrix{Float64}: LPA: J × K profile means; growth: T × K model-implied means of the measures (raw scale).
  • vars::Matrix{Float64}: J × K within-class variances (raw scale; growth models: residual variances Θ).
  • covariances::Symbol: :zero, :equal or :varying (LPA); :growth for GMM, :zero for LCGA, :none for LCA.
  • covs::Vector{Matrix{Float64}}: K within-class covariance matrices (raw scale; diagonal unless covariances ≠ :zero; for growth models the model-implied ΛΨΛ' + Θ).
  • regression::Union{Nothing,ClassRegression}: one-step latent class regression on covariates, or nothing.
  • starts::Tuple{Int,Int}: (stage-1 starts, stage-2 starts) requested.
  • finals::Vector{StartResult}: the stage-2 starts, best log-likelihood first.
  • converged::Bool: whether the best start met the convergence criterion within maxiter, or, when the fit was finished by Newton–Raphson (EM at maxiter or with a large gradient; see convergence and cache[:finish]), whether the Newton finish reached a zero gradient.
  • iterations::Int: EM iterations of the best start (both stages).
  • device::Symbol: device the EM ran on (:cpu, :cuda, or :array in tests).
  • eltype::DataType: floating-point type of the EM arrays (Float64).
  • fit::FitData: host data and internal estimates used by the post-estimation functions (see FitData).
  • cache::Dict{Symbol,Any}: lazily computed results (:parameters, :vcov, :scaling, …) and, for growth models, :growth (see growthparams).

LatentMixtures.MultiGroupModel — Type
MultiGroupModel <: StatsAPI.StatisticalModel

A fitted multigroup latent class or profile model with known groups: the result of lca(data, K; group = g, invariance = …) or lpa(data, K; group = g, invariance = …) (Mplus KNOWNCLASS). Class proportions are group-specific; the measurement model is invariant, group-specific, or partially invariant across groups.

Classes are labelled consistently across groups and ordered by overall size (largest first). Under full invariance the shared parameters tie the labels together. Whenever some indicators are group-specific (partial or no invariance), the classes of every group g ≥ 2 are additionally matched to group 1 by their indicator profiles: the permutation minimising the summed absolute differences of all item-response probabilities (LCA) or standardised means (LPA). Under partial invariance the shared items already tie the labels, so this match is expected to be the identity; if two classes have very similar profiles and a strongly non-invariant item, check itemprobs(m; group = g) for every group.

Fields

  • kind::Symbol: :LCA or :LPA.
  • K::Int: number of classes.
  • groups::Vector{Any}: the sorted group labels; group g below means groups[g].
  • ngroup::Vector{Int}: analysed rows per group.
  • n::Int, ninput::Int: analysed rows, rows of the input.
  • rows::Vector{Int}: the analysed input rows (non-missing group, at least one observed indicator).
  • groupof::Vector{Int}: group index of every analysed row.
  • ll::Float64: log-likelihood, including the known-group term Σ_g n_g log(n_g / n) as Mplus includes the KNOWNCLASS variable in the likelihood.
  • npar::Int: free parameters as Mplus counts them: G(K − 1) class logits, G − 1 group logits and the measurement parameters.
  • classprobs::Vector{Vector{Float64}}: class proportions within each group.
  • params::Vector{Any}: per group, the item-response probability matrices (LCA, one ncat × K matrix per item) or (means, vars) (LPA, J × K, raw scale).
  • names::Vector{String}: indicator names.
  • levels::Vector{Vector{Any}}: LCA categories per indicator (common to all groups).
  • noninvariant::Vector{Int}: indices of indicators with group-specific parameters (empty: full invariance; all: no invariance).
  • posterior::Matrix{Float64}: n × K posterior class probabilities within group.
  • entropy::Float64: relative entropy (see relative_entropy).
  • starts, finals, converged: as in LatentMixtureModel.
  • cache::Dict{Symbol,Any}: internal estimates and data (:kernels, :ws, :θs, :logπs, :shift) used by scaling_factor, and cached results.

LatentMixtures.MultilevelModel — Type
MultilevelModel <: StatsAPI.StatisticalModel

A fitted nonparametric two-level latent class or profile model: the result of lca(data, K; level2 = cluster_ids, KB = M) or lpa(data, K; level2, KB, variances) (Vermunt 2003; Mplus TYPE = TWOLEVEL MIXTURE with a between-level latent class variable, User's Guide example 10.7).

Clusters (level-2 units) belong to one of KB between classes (Mplus CB) with probabilities π_m; individuals belong to one of K within classes (Mplus CW) with probabilities P(CW = k | CB = m) that depend on their cluster's between class. The measurement model (item-response probabilities given the within class) does not depend on the between class (LCA: item-response probabilities; LPA: profile means and variances).

Within classes are ordered by their estimated size (largest first), between classes by π_m (largest first).

LatentMixtures.MultilevelRandomModel — Type
MultilevelRandomModel <: StatsAPI.StatisticalModel

Relative entropy of the posterior classification, the "Entropy" Mplus prints under MODEL FIT INFORMATION: 1 for perfectly separated classes, near 0 for no separation.

  • m: a fitted model.

Returns

For a LatentMixtureModel,

E = 1 - Σᵢ wᵢ Σₖ (-pᵢₖ log pᵢₖ) / (Σᵢ wᵢ · log K),

  • Standard errors are the sandwich V = I⁻¹ B I⁻¹ (I = observed information, B = outer products of the case scores, weighted by the squared sampling weights) of an unconstrained internal parameterisation — LCA: cumulative-logit thresholds per item and class; LPA: standardised means and log variances (or Cholesky factors with log diagonal); class logits against the last internal class — mapped to the reported parameters by the delta method (automatic differentiation). This is Mplus's MLR.
  • With cluster / strata (Mplus TYPE = COMPLEX), B is the design-based meat Σ_h n_h/(n_h−1) Σ_c (z_hc − z̄_h)(z_hc − z̄_h)ᵀ of the PSU totals z_hc of the weighted case scores (Asparouhov 2005); a stratum with a single PSU contributes z zᵀ. This reproduces Mplus TYPE = MIXTURE COMPLEX.
  • Thresholds whose cumulative probability is within 10⁻⁵ of 0 or 1 are held fixed (Mplus fixes them at ±15); they get se = 0 and z = NaN (as do probabilities that depend on fixed thresholds only). A middle category with zero probability ties its two thresholds into one parameter.
  • With variances = :equal the common variance is listed once per class (identical estimates and SEs). Without covariates class logits are against the last class (the ref keyword only applies to regressions).
  • Computed on first use and cached in m.cache; for large n the cost is dominated by the Hessian (forward-mode AD over d parameters, O(n·d²)), run in parallel on threads.
  • Multigroup and LTA models have their own methods (parameters(m::MultiGroupModel), parameters(m::LTAModel)).

It is evaluated after a few Newton steps from the EM estimates to the maximum (as for scaling_factor), with thresholds that reach the boundary fixed; the reported estimates are those of that maximum (EM can stop short along flat directions; the log-likelihood and posteriors are those of the EM fit, which differ from the maximum by less than the EM tolerance). A threshold that reaches the boundary has se = 0 (Mplus: fixed at ±15). B is the MLR meat, or with a survey design the stratified PSU-total meat (see the manual section "Complex survey data").
  • Mplus prints the class model as c ON cg: its intercepts [c#k] are the class logits of the last group and its slopes c#k ON cg#g differences of class logits between groups; both are linear in the "class logit" rows (use vcov).
  • Thresholds at the boundary are fixed (se = 0), as in Mplus.

Means of a distal outcome by the latent class at one wave, or by the class pattern at several waves, of an LTA by the BCH method with the joint class-path weights of bchweights (the Mplus approach for several latent class variables: step 1 saves the K^T BCH weights, step 3 uses them as TRAINING = … (BCH) weights). LatentMixtures.bch — Method
bch(m::LatentMixtureModel, y; name = "y") -> BCHResult

Means of a continuous distal outcome in each latent class by the BCH method (Bolck, Croon & Hagenaars 2004; Vermunt 2010; Bakk & Vermunt 2016), as Mplus AUXILIARY = y (BCH).

Each case gets the weights wᵢₖ = cwᵢ · (D⁻¹)[ĉᵢ, k], with D = classification_table(m).errors, ĉᵢ the most likely class and cwᵢ the sampling weight (1 without weights). Because E[Σⱼ 1(ĉ = j)(D⁻¹)[j, k] | c = l] = 1(k = l), the weighted means μₖ = Σᵢ wᵢₖ yᵢ / Σᵢ wᵢₖ are consistent for the class means without modelling y jointly with the indicators. The measurement model is not changed.

Arguments

  • m: a fitted model with K ≥ 2 classes.
  • y: the outcome, one numeric value per row of the data m was fitted to (m.ninput values, same order); rows with missing y are excluded.
  • name = "y": label used in the printed output.

Returns

A BCHResult with the class means, standard errors, their covariance and Wald χ² tests (overall and pairwise).

Examples

using LatentMixtures
# Do adults in the four ACE classes differ in depressive symptoms (depress, 0–24)?
d = dataset("aces")
m = lca(d[:, r"^ace_"], 4)
b = bch(m, d.depress; name = "depress")
b.means        # ≈ 4.8, 10.3, 7.0, 13.8: lowest in Low adversity, highest in High adversity
b.overall      # Wald test of equal means across classes (p < 0.001); b.se has the SEs

Notes

  • Standard errors are sandwich estimates from the influence functions ψᵢₖ = wᵢₖ(yᵢ − μₖ) / Σᵢ wᵢₖ, V = Ψ'Ψ, treating D as known; Wald tests use V. Means and SEs agree with Mplus BCH to 3 decimals and the Wald χ² within 0.01 % on the validation cases. With a complex survey design in m (cluster / strata), V is the design-based meat of the PSU totals of ψ (Mplus TYPE = MIXTURE COMPLEX).

LatentMixtures.dcat — Method
dcat(m::LatentMixtureModel, y; ref = m.K, name = "y", maxiter = 5000, tol = 1e-10)
    -> DCATResult

Probabilities of a categorical distal outcome in each latent class by the model-based method of Lanza, Tan & Bray (2013), as Mplus AUXILIARY = y (DCAT).

The latent class is regressed on dummy indicators of y's categories (a multinomial logit with C − 1 category effects), jointly with the measurement model, by EM started at the estimates of m; then P(y = c | class k) ∝ P(class k | y = c) P(y = c) by Bayes' theorem, with P(y = c) the sample proportions.

Arguments

  • m: a fitted model with K ≥ 2 classes and no covariates.
  • y: the outcome, one value per row of the data m was fitted to (m.ninput values; any category codes, at least two observed); rows with missing y are deleted.
  • ref = m.K: reference class of the odds ratios.
  • name = "y": label used in the printed output.
  • maxiter = 5000, tol = 1e-10: EM settings of the joint re-estimation (as in lca).

Returns

A DCATResult: probs (K × C), robust se, odds ratios, and Wald χ² tests of equal distributions (overall and pairwise).

Examples

using LatentMixtures
# Does self-rated health (srh: 1 excellent … 5 poor) differ across the ACE classes?
d = dataset("aces")
m = lca(d[:, r"^ace_"], 4)
r = dcat(m, d.srh; name = "srh")
round.(r.probs; digits = 2)  # rows = classes: P(fair or poor) is 0.11 in Low, 0.30 in High adversity
r.overall                    # Wald test of no association (p < 0.001)

Notes

  • Standard errors: joint sandwich over the model parameters and the marginal proportions P(y = c) (stacked estimating equations Σᵢ wᵢ sᵢ = 0 and Σᵢ wᵢ(1[yᵢ = c] − p_c) = 0), then the delta method (automatic differentiation).
  • Because the measurement model is re-estimated jointly with y, the classes can shift if y is strongly related to them (the usual caveat of one-step distal models); the estimate is started from m, so the class labels are kept.
  • If a category is (almost) absent in a class, the information matrix is singular: a warning is issued and SEs and tests are NaN.
  • With a complex survey design in m the sandwich is design-based (PSU totals of the stacked weighted estimating functions). Mplus refuses DCAT under TYPE = MIXTURE COMPLEX ("not available"), so this case has no Mplus reference.
  • Probabilities and odds ratios agree with Mplus DCAT to 3 decimals, SEs within 0.001 and Wald χ² within 1 % on the validation case.

LatentMixtures.r3step — Method
r3step(m::LatentMixtureModel, covariates; ref = m.K, se = :robust) -> R3StepResult

Multinomial logistic regression of latent class on covariates by the bias-adjusted three-step ML method of Vermunt (2010), as Mplus AUXILIARY = x1 x2 (R3STEP).

Step 1 is the fitted measurement model m; step 2 assigns each case to its most likely class ĉᵢ; step 3 maximises

Σᵢ wᵢ log Σₖ softmax(xᵢ'B)ₖ D[k, ĉᵢ]

over B, with the classification-error matrix D = classification_table(m).errors held fixed, so the modal assignment is treated as a single indicator of the latent class with known misclassification. The measurement model is not changed by the covariates.

Arguments

  • m: a fitted model with K ≥ 2 classes (typically without covariates).
  • covariates: a vector, matrix or table of numeric covariates with one row per row of the data m was fitted to (same order, m.ninput rows). Dummy-code categorical covariates. Rows with a missing covariate are deleted listwise (as in Mplus).
  • ref = m.K: reference class (Mplus uses the last class).
  • se = :robust: sandwich standard errors (Mplus default with MLR), or :ml (inverse observed information).

Returns

An R3StepResult; coeftable tabulates it with z, p and odds ratios.

Examples

using LatentMixtures
# Do sex, age and parental education predict membership in the ACE classes? (aces: 8 ACE
# items; covariates female, age, low_parent_edu)
d = dataset("aces")
m = lca(d[:, r"^ace_"], 4)               # step 1: measurement model of the ACE items only

# low_parent_edu has log-odds 0.7–1.0 (p ≤ 0.001) for every adversity class: children of
# less educated parents are more often in them; coeftable(r).oddsratio gives exp(estimate)

Notes

  • Estimated by Newton–Raphson with step halving (ForwardDiff gradient and Hessian), starting from intercepts at the log ratios of the class proportions.
  • D is computed from all analysed rows of m (also those later deleted for a missing covariate); on the validation case, with 92 of 1,500 rows deleted, this reproduces the Mplus R3STEP estimates and SEs. With sampling weights in m, the step-3 likelihood, D and the sandwich are weighted. With a complex survey design (cluster / strata in m) the sandwich is design-based (PSU totals of the weighted scores, as Mplus TYPE = MIXTURE COMPLEX); the rows with a missing covariate are dropped from the design.
  • Standard errors treat D as known (no correction for its sampling variability), as in Vermunt (2010) and Mplus.
  • Coefficients and SEs agree with Mplus R3STEP to 3 decimals on the validation cases.

LatentMixtures.blrt — Method
blrt(m::LatentMixtureModel; reps = 100, h0_starts = m.fit.starts,
     boot_starts = ((20, 4), (40, 8)), seed = 20261120, maxiter = 5000,
     tol = 1e-10, compress = true) -> BLRTResult

Parametric bootstrap likelihood-ratio test (McLachlan 1987; McLachlan & Peel 2000) of the fitted K-class model against K − 1 classes, as Mplus OUTPUT: TECH14.

The K − 1 class model is fitted to the data from h0_starts random starts; reps data sets of the same size are generated from it (keeping each case's missing-data pattern), and both the K − 1 and the K class model are fitted to each. The p-value is the share of bootstrap statistics 2(LL_K − LL_{K−1}) at least as large as the observed one.

Arguments

  • m: a fitted LatentMixtureModel with K ≥ 2 classes, no covariates and no sampling weights (LCA, LPA, growth).
  • reps = 100: number of bootstrap data sets.
  • h0_starts = m.fit.starts: (n₁, n₂) random starts for the K − 1 class model on the observed data (default: the starts used to fit m).
  • boot_starts = ((20, 4), (40, 8)): random starts for the K − 1 and the K class model in every bootstrap data set. Mplus's default LRTSTARTS = 0 0 40 8 uses 40 8 for the K class model and, for the K − 1 class model, a single run from the H0 estimates; random starts for the K − 1 model here are a (more expensive) safeguard.
  • seed = 20261120: random seed of the data generation and of the bootstrap starts; each replication has its own stream.
  • maxiter = 5000, tol = 1e-10: EM settings, as in lca.
  • compress = true: fit each bootstrap data set of categorical indicators (LCA) on its distinct response patterns with frequency weights, as lca does (the cost of an EM iteration then grows with the number of patterns, not with n). false fits every simulated row: the EM iterations agree to rounding (≈ 10⁻¹³ relative), so the statistics agree up to where the |ΔLL|/n < tol rule stops EM (in flat bootstrap likelihoods with large n, ≈ 10⁻⁴ relative); for checking.

Returns

A BLRTResult: the K − 1 class log-likelihood, the observed statistic, the difference in parameters, the bootstrap p-value and statistics.

LatentMixtures.lmr — Method
lmr(m::LatentMixtureModel) -> LMRResult

Vuong–Lo–Mendell–Rubin likelihood-ratio test (Lo, Mendell & Rubin 2001) of the fitted K-class model against K − 1 classes, as Mplus OUTPUT: TECH11.

The K − 1 class model is re-estimated from the K-class solution with one class deleted (Mplus deletes its first class; here each of the K deletions is tried and the best K − 1 solution kept). Under the null the statistic LR = 2(LL_K − LL_{K−1}) is asymptotically distributed as Σⱼ λⱼ χ²₁, with λ the eigenvalues of

W = [ −B₁A₁⁻¹    −B₁₀A₀⁻¹ ]
    [ B₁₀'A₁⁻¹    B₀A₀⁻¹  ]

(Aₘ = average Hessian, Bₘ = average outer product of the case scores of model m, B₁₀ = cross-products of the scores of both models; Vuong 1989), evaluated by Imhof's (1961) method.

Arguments

  • m: a fitted LatentMixtureModel with K ≥ 2 classes and no covariates (LCA, LPA or growth; weights allowed).

Returns

An LMRResult: the K − 1 class log-likelihood, LR, the difference in parameters, the mean and SD of the reference distribution, its p-value, and the LMR-adjusted statistic LR / (1 + 1/(Δnpar · log n)) with its p-value.

Examples

[lmr(m).p_adjusted for m in fits]   # p < 0.001 up to K = 4, then 0.12 and 0.24: four classes,
                                    # the number that generated the data

Notes

  • H0 log-likelihood, LR, Δnpar and the adjusted statistic agree with Mplus TECH11. The mean, SD and p-values differ from Mplus: they follow Vuong (1989) as described by Lo, Mendell & Rubin (2001); Mplus does not document its computation (e.g. binary LCA 3 vs 4 classes: p = 0.028 here, 0.139 in Mplus). Prefer blrt or BIC when the two disagree (Nylund et al. 2007).
  • The H0 model is found by deletion rather than by new random starts; if it is not the global K − 1 maximum, compare h0_ll with a separate K − 1 fit.
  • Not available with covariates, nor for multigroup and LTA models.
  • With a complex survey design (cluster / strata) the score cross-products B are the design-based PSU-total versions (Mplus TECH11 also changes under TYPE = MIXTURE COMPLEX); H0 log-likelihood, LR and the adjusted statistic do not depend on the design.

bvr(m::LatentMixtureModel) -> NamedTuple of vectors

Bivariate residual diagnostics of local independence for every pair of categorical indicators of a fitted latent class model: the Pearson and likelihood-ratio χ² comparing the observed two-way table of the pair with the table the model implies (Mplus TECH10 "Bivariate Pearson / Log-Likelihood Chi-Square"), and the bivariate residual BVR = Pearson / df of Vermunt & Magidson (Latent GOLD).

For a pair (a, b) the observed counts O_cd are taken over the rows where both items are observed, and the expected counts are E_cd = Σᵢ Σₖ πₖ(xᵢ) P(a = c | k) P(b = d | k) over the same rows (with sampling weights, weighted); Pearson = Σ (O − E)²/E, LR = 2 Σ O log(O / E), df = (C_a − 1)(C_b − 1).

Arguments

  • m: a fitted lca (with or without covariates or weights) or a mixture model with categorical indicators (its categorical indicators without direct effects).

Returns

A column table sorted by bvr (largest first) with item1, item2, pearson, lr, df, bvr.

Examples

using LatentMixtures
d = dataset("aces")
m = lca(d[:, r"^ace_"], 3)
b = bvr(m)
b.item1[1], b.item2[1], b.bvr[1]      # the pair with the largest bivariate residual

Notes

  • A diagnostic, not a test: the χ² reference distribution does not hold (the cells are not independent of the fitted parameters). Latent GOLD flags BVRs above about 3.84 (the 5 % χ²₁ point) as a sign of local dependence; large values suggest freeing the association of the pair (lca(...; pairs = …)), adding a class, or a direct effect. Oberski, van Kollenburg & Vermunt (2013) propose a score test with a proper reference distribution, not implemented here.
  • Agrees with Mplus TECH10 (bivariate Pearson and log-likelihood χ²) on the validation case.

References

  • Vermunt, J. K., & Magidson, J. (2005). Latent GOLD 4.0 user's guide. Statistical Innovations.
  • Oberski, D. L., van Kollenburg, G. H., & Vermunt, J. K. (2013). A Monte Carlo evaluation of three methods to detect local dependence in binary data latent class models. Advances in Data Analysis and Classification, 7, 267–279.
  • Muthén, L. K., & Muthén, B. O. (1998–2017). Mplus User's Guide (8th ed.). (TECH10.)
LatentMixtures.compare_models — Method
compare_models(m0, m1) -> NamedTuple

Compare a model m0 nested in a more general model m1 under robust ML: the naive likelihood-ratio test, the Satorra–Bentler scaled difference test that Mplus uses with ESTIMATOR = MLR, and differences in information criteria. Typical uses: full against partial measurement invariance (multigroup or LTA), stationary against time-specific transitions, equal against profile-specific variances.

Arguments

  • m0: the nested model (LatentMixtureModel, MultiGroupModel or LTAModel).
  • m1: the more general model; must have more free parameters than m0.

Returns

A NamedTuple:

  • ll0, ll1, npar0, npar1, c0, c1: log-likelihoods, free parameters and scaling factors (scaling_factor);
  • df = npar1 − npar0;
  • chisq, p: naive likelihood-ratio test 2(LL1 − LL0) (valid under ML);
  • cd, chisq_scaled, p_scaled: the Satorra–Bentler (2001) scaled difference test (see sb_difference); NaN when cd ≤ 0;
  • delta_aic, delta_bic, delta_sabic: criterion(m1) − criterion(m0) (negative favours m1);
  • warning::String: empty, or a description of problems (cd ≤ 0, LL1 < LL0, different numbers of classes, different numbers of observations).

Examples

using LatentMixtures
# Is the sexual-abuse item measured equally for men and women? (aces, group = female)
d = dataset("aces")
full = lca(d[:, r"^ace_"], 4; group = d.female)                                  # invariant
part = lca(d[:, r"^ace_"], 4; group = d.female, invariance = [:ace_sex_abuse])   # item free
r = compare_models(full, part)
r.chisq_scaled, r.df, r.p_scaled   # ≈ 42 on 4 df, p < 0.001: the item is non-invariant,
                                   # as generated (higher for women in every class)

Notes

  • Nesting is not checked; only the parameter counts, sample sizes and numbers of classes are compared. The two models must be fitted to the same rows.
  • With different numbers of classes the χ² reference distribution does not hold (the nested model lies on the boundary of the parameter space); a warning is returned — use lmr or blrt.
  • The scaled statistic agrees with the Satorra–Bentler formula applied to the Mplus-printed log-likelihoods, parameters and scaling factors (Validation page).

References

  • Satorra, A., & Bentler, P. M. (2001). A scaled difference chi-square test statistic for moment structure analysis. Psychometrika, 66(4), 507–514. https://doi.org/10.1007/BF02296192
  • Asparouhov, T., & Muthén, B. Chi-square difference testing using the Satorra–Bentler scaled chi-square. Mplus website. https://www.statmodel.com/chidiff.shtml
LatentMixtures.comparison_table — Method
comparison_table(models...) -> NamedTuple of vectors
comparison_table(models::AbstractVector) -> NamedTuple of vectors

A model-comparison table: fit statistics of every model and the scaled difference test of each model against the previous row, e.g. for a sequence of increasingly constrained invariance models.

Arguments

  • models: LatentMixtureModels, MultiGroupModels and/or LTAModels, as separate arguments or a vector, in the order of the rows.

Returns

A column table with one row per model: model (position), K, npar, ll, scaling (MLR scaling correction factor), aic, bic, sabic, entropy, and the test against the previous row, taking the model with fewer parameters as the nested one: df, chisq (naive 2ΔLL), cd, chisq_scaled, p_scaled, warning (see compare_models). The test columns are NaN (and df = 0) on the first row, and NaN with a warning when two consecutive models have the same number of parameters or cd ≤ 0. Any Tables.jl sink accepts it, e.g. DataFrame(comparison_table(m1, m2, m3)).

Examples

using LatentMixtures
# Full, partial (sexual-abuse item) and no measurement invariance of the ACE classes by sex
d = dataset("aces")
Y = d[:, r"^ace_"]
full = lca(Y, 4; group = d.female)
part = lca(Y, 4; group = d.female, invariance = [:ace_sex_abuse])
none = lca(Y, 4; group = d.female, invariance = :none)
comparison_table(full, part, none)   # row 2 improves on row 1 (p < 0.001, lower BIC);
                                     # row 3 adds 28 parameters, higher BIC: keep partial invariance

Notes

Rows with different numbers of classes get a warning (use lmr/blrt for class enumeration). Every model's scaling factor is computed (and cached).

References

  • Satorra, A., & Bentler, P. M. (2001). A scaled difference chi-square test statistic for moment structure analysis. Psychometrika, 66(4), 507–514. https://doi.org/10.1007/BF02296192
LatentMixtures.lrtest — Method
lrtest(restricted, full) -> NamedTuple

Naive (ML) likelihood-ratio test of a restricted model nested in a more general one with the same number of classes, e.g. full against partial or no measurement invariance.

Arguments

  • restricted::StatisticalModel: the nested model (fewer free parameters).
  • full::StatisticalModel: the more general model; must have more free parameters. Any models with loglikelihood, dof and bic methods work (LatentMixtureModel, MultiGroupModel, LTAModel).

Returns

(chisq, df, p, delta_bic): chisq = 2(LL_full − LL_restricted), df = npar_full − npar_restricted, the upper-tail χ² p-value (computed at max(chisq, 0)), and delta_bic = BIC(full) − BIC(restricted) (negative favours full).

Examples

using LatentMixtures
# Likelihood-ratio test of full against partial measurement invariance by sex (ACE items)
d = dataset("aces")
full = lca(d[:, r"^ace_"], 4; group = d.female)
part = lca(d[:, r"^ace_"], 4; group = d.female, invariance = [:ace_sex_abuse])
lrtest(full, part)     # χ²(4) ≈ 43.6, p < 0.001, and delta_bic < 0: partial invariance

Notes

  • This is the ML test (Mplus: "Loglikelihood difference testing" without scaling). With robust (MLR) standard errors Mplus compares nested models with the Satorra–Bentler scaled difference test, which compare_models computes.
  • The χ² reference distribution does not hold for models with different numbers of classes (the restricted model lies on the boundary of the parameter space); use lmr or blrt. lrtest does not check K, nesting or that both models were fitted to the same rows.

References

  • Wilks, S. S. (1938). The large-sample distribution of the likelihood ratio for testing composite hypotheses. The Annals of Mathematical Statistics, 9(1), 60–62. https://doi.org/10.1214/aoms/1177732360
  • McLachlan, G., & Peel, D. (2000). Finite Mixture Models (ch. 6). Wiley. https://doi.org/10.1002/0471721182
LatentMixtures.sb_difference — Method
sb_difference(ll0, npar0, c0, ll1, npar1, c1) -> NamedTuple

Satorra–Bentler (2001) scaled likelihood-ratio difference test from printed results: the log-likelihoods, numbers of free parameters and MLR scaling correction factors of a nested model (0) and the more general model (1), following the Mplus recipe for MLR:

cd  = (p₀c₀ − p₁c₁) / (p₀ − p₁),
TRd = −2(LL₀ − LL₁) / cd,   df = p₁ − p₀.

Arguments

  • ll0::Real, npar0::Integer, c0::Real: log-likelihood, free parameters and scaling factor of the nested model.
  • ll1::Real, npar1::Integer, c1::Real: the same for the comparison model; npar1 > npar0 is required.

Returns

(cd, chisq, df, p): the difference-test scaling correction, TRd, its degrees of freedom and the upper-tail χ² p-value. chisq and p are NaN when cd ≤ 0.

Examples

using LatentMixtures
# Scaled difference test from printed output: LL, free parameters and scaling factor of
# a fully invariant multigroup LCA (23 parameters) and of its partially invariant version (26)
r = sb_difference(-6997.498, 23, 1.0520, -6959.644, 26, 1.0158)
r.chisq, r.df, r.p        # TRd ≈ 52 on 3 df, p < 0.001: reject full invariance

Notes

Useful to reproduce a test from Mplus output or to combine models fitted elsewhere; for fitted models use compare_models. cd can be negative in small samples or with misspecified nested models; then the test is not available (Satorra & Bentler 2010 give a strictly positive alternative, not implemented here).

References

  • Satorra, A., & Bentler, P. M. (2001). A scaled difference chi-square test statistic for moment structure analysis. Psychometrika, 66(4), 507–514. https://doi.org/10.1007/BF02296192
  • Satorra, A., & Bentler, P. M. (2010). Ensuring positiveness of the scaled difference chi-square test statistic. Psychometrika, 75(2), 243–248. https://doi.org/10.1007/s11336-009-9135-y
  • Asparouhov, T., & Muthén, B. Chi-square difference testing using the Satorra–Bentler scaled chi-square. Mplus website. https://www.statmodel.com/chidiff.shtml
LatentMixtures.scaling_factor — Method
scaling_factor(m::MultilevelModel) -> Float64

MLR scaling correction factor of a two-level model, tr((−H)⁻¹M) / npar with the cluster-score meat (Mplus "H0 Scaling Correction Factor for MLR").

LatentMixtures.scaling_factor — Method
scaling_factor(m) -> Float64

MLR scaling correction factor of the log-likelihood, as Mplus prints it ("H0 Scaling Correction Factor for MLR"):

c = (tr(I⁻¹B) + n_fixed) / p,

with I the observed information (minus the Hessian of the log-likelihood), B = Σᵢ wᵢ² sᵢsᵢ' the outer products of the case scores (wᵢ = sampling weights; 1 without weights), p the number of free parameters and n_fixed the parameters fixed at the boundary of the parameter space (counted in p, as Mplus does). With a complex survey design (cluster / strata, Mplus TYPE = MIXTURE COMPLEX) B is the design-based meat of the PSU totals of the weighted scores (see the manual section "Complex survey data"), so c and compare_models account for the design.

Arguments

  • m: a LatentMixtureModel (lca, lpa, growth; with or without covariates and weights), a MultiGroupModel or an LTAModel.

Returns

The factor c (c ≈ 1 when the model is correctly specified, since then B ≈ I).

Examples

using LatentMixtures
# MLR scaling factor of the ACE model fitted separately to men and women (full invariance)
d = dataset("aces")
full = lca(d[:, r"^ace_"], 4; group = d.female)
scaling_factor(full)       # ≈ 1.04; Mplus prints it as "H0 Scaling Correction Factor for MLR"

Notes

  • It is evaluated at the maximum: EM stops slightly short of it in flat likelihoods, which moves c in the fourth decimal, so a few safeguarded Newton steps from the EM estimates are taken first (thresholds that reach the boundary in these steps are fixed, as in Mplus). The model itself is not changed.
  • Agrees with the Mplus value (4 decimals) for every validation case listed on the Validation page.
  • c enters the Satorra–Bentler scaled difference test of compare_models and sb_difference. See scaling_info for the pieces.

References

  • Satorra, A., & Bentler, P. M. (2001). A scaled difference chi-square test statistic for moment structure analysis. Psychometrika, 66(4), 507–514. https://doi.org/10.1007/BF02296192
  • Yuan, K.-H., & Bentler, P. M. (2000). Three likelihood-based methods for mean and covariance structure analysis with nonnormal missing data. Sociological Methodology, 30, 165–200. https://doi.org/10.1111/0081-1750.00078
  • Asparouhov, T., & Muthén, B. Chi-square difference testing using the Satorra–Bentler scaled chi-square. Mplus website. https://www.statmodel.com/chidiff.shtml
LatentMixtures.scaling_info — Method
scaling_info(m) -> NamedTuple

Details of the MLR scaling correction factor of a model (see scaling_factor).

Arguments

  • m: a LatentMixtureModel (lca, lpa, growth; with or without covariates and weights), a MultiGroupModel or an LTAModel.

Returns

(c, npar, nfree, nfixed, trace, ll, ll_polished, newton_steps, gradient):

  • c: the scaling correction factor;
  • npar: free parameters as Mplus counts them (dof(m));
  • nfree: parameters in the information matrix;
  • nfixed = npar − nfree: parameters fixed at the boundary (e.g. logit thresholds whose probability is within 10⁻⁵ of 0 or 1, Mplus ±15); each adds 1 to the trace;
  • trace: tr(I⁻¹B) over the free parameters;
  • ll: log-likelihood of the EM estimates on the internal scale (standardised data for continuous indicators); ll_polished: after the Newton steps (≥ ll);
  • newton_steps: accepted Newton steps;
  • gradient: largest absolute score at the final point (should be ≈ 0).

Examples

using LatentMixtures
# The pieces of the MLR scaling correction of the four-class ACE model
d = dataset("aces")
m = lca(d[:, r"^ace_"], 4)
s = scaling_info(m)
s.c, s.nfixed, s.gradient     # c ≈ 1.02 (close to 1: ML and robust information agree),
                              # no parameter at the boundary, gradient ≈ 0 at the maximum

Notes

Computed on first use and cached in m.cache. A warning is issued if the likelihood function used for the derivatives does not reproduce the EM log-likelihood.

References

  • Asparouhov, T., & Muthén, B. Chi-square difference testing using the Satorra–Bentler scaled chi-square. Mplus website. https://www.statmodel.com/chidiff.shtml

LatentMixtures.measurement_estimates — Method
measurement_estimates(m::LatentMixtureModel) -> NamedTuple

The internal (unconstrained) parameter vector of a fitted model together with the case scores, the observed information and the influence functions: the ingredients needed by extension packages that propagate measurement-model uncertainty into a second-stage estimator (e.g. causal effects of latent classes estimated from posterior probabilities).

Arguments

  • m: a LatentMixtureModel without covariates (LCA, LPA or growth).

Returns

(v, scores, information, influence):

  • v::Vector{Float64}: d internal parameters — measurement parameters (LCA: cumulative-logit thresholds per item and class, free ones only; LPA: standardised means and log variances or Cholesky factors; growth: α, log Θ, Cholesky of Ψ), then the K − 1 class log-odds against the last internal class;
  • scores::Matrix{Float64}: n × d, row i = ∂ log Lᵢ / ∂v for analysed row i (unweighted);
  • information::Matrix{Float64}: d × d observed information −Σᵢ wᵢ ∂² log Lᵢ / ∂v∂v';
  • influence::Matrix{Float64}: n × d influence functions in mean form, row i = n · information⁻¹ · wᵢ sᵢ, so that v̂ − v₀ ≈ (1/n) Σᵢ influenceᵢ and influence' * influence / n² is the sandwich covariance of v.

Rows are aligned with m.rows, like posterior(m).

Examples

using LatentMixtures, ForwardDiff
# Derivatives of the ACE-class posteriors with respect to the measurement parameters, the
# building block of a new three-step estimator
d = dataset("aces")
m = lca(d[:, r"^ace_"], 4)
e = measurement_estimates(m)
P = posterior_at(m, e.v)                       # == posterior(m)
dP = ForwardDiff.jacobian(v -> vec(posterior_at(m, v)), e.v)   # ∂ posteriors / ∂v
size(dP)                                       # (1500 × 4 posteriors, 35 free parameters)

Notes

  • The internal class order differs from the reported one; only posterior_at and the reported results map it (m.fit.perm). The parameterisation is the one of parameters; fixed boundary thresholds are not in v.
  • wᵢ are the rescaled sampling weights (1 without weights).
  • Computed on first use and cached.

References

  • White, H. (1982). Maximum likelihood estimation of misspecified models. Econometrica, 50(1), 1–25. https://doi.org/10.2307/1912526
  • Bakk, Z., Oberski, D. L., & Vermunt, J. K. (2014). Relating latent class assignments to external variables: Standard errors for correct inference. Political Analysis, 22(4), 520–540. https://doi.org/10.1093/pan/mpu003
