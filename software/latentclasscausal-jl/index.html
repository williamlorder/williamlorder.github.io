LatentClassCausal.jl

Causal inference for latent class and latent profile models fitted with LatentMixtures.jl. Latent classes are patterns across several indicators, not single variables, so the standard causal toolkit leaves open how a treatment moves people between classes, for whom an intervention on some indicators matters, and whether the latent pattern itself confounds an effect. The package answers these questions about latent classes:

Question about latent classesFunction
Does a treatment change latent class membership? $\Delta_k = P\{C(1) = k\} - P\{C(0) = k\}$intervene_membership
Does an intervention on exposures change membership in a latent class outcome?intervene_latent_outcome
For whom? How large is the effect within each latent class of the exposures?intervene_within
Could the latent class itself confound the effect, and how strongly would it have to?intervene_latent_sensitivity
Unmeasured confounding of treatment and class membership: how strong would it have to be?intervene_membership_sensitivity (E-values, additive bias)
Measurement non-invariance by treatment (DIF)?intervene_dif
Heterogeneity across observed subgroups: Δₖ within a subgroupintervene_subgroup
Adjust for the latent pattern of the other exposures instead of each oneintervene_effect(...; adjust = :classes)
How would the class model classify the post-intervention profiles? (descriptive)intervene_shares

intervene_membership estimates the effect of a treatment on class membership by augmented inverse probability weighting of bias-corrected (BCH) pseudo-outcomes, with cross-fitting and influence-function standard errors that include the measurement step (theory: Treatment effects on latent classes). The other methods start from the latent classes of a set of exposures, such as childhood adversities, and ask what an intervention on some of them implies for those classes (theory and worked examples: Latent classes and interventions).

Underneath, intervene_effect provides the estimators these methods are built on: the parametric g-formula, IPTW, AIPW and TMLE for static (setto), stochastic (shift), targeted (subgroup) and natural-course (natural) interventions on binary exposures, $\psi = E[Y^{g_1}] - E[Y^{g_0}]$. It can also be used on its own for an observed outcome (theory: Intervention estimators).

Installation

Not registered; requires Julia 1.12 or later. Install LatentMixtures.jl first:

using Pkg
Pkg.add(url = "https://github.com/williamlorder/LatentMixtures.jl")
Pkg.add(url = "https://github.com/williamlorder/LatentClassCausal.jl")

The repositories are private (read access and Git credentials for github.com are needed). For development, clone both side by side: Project.toml declares LatentMixtures.jl as a local source ([sources] LatentMixtures = {path = "../LatentMixtures.jl"}).

Quick start

using LatentMixtures, LatentClassCausal   # lca and convergence come from LatentMixtures

# 1. Did a school mental-health programme move students between latent wellbeing classes?
p = dataset("programme")
m = lca(p[:, [:low_mood, :worry, :sleep, :lonely, :hopeless, :enjoy, :confident, :friends]], 3)
convergence(m)           # check that the best LL is replicated and EM reached the maximum
X = Matrix{Float64}(p[:, [:female, :age, :low_ses, :distress, :belonging]])
r = intervene_membership(m, p.programme, X)             # AIPW, 5-fold cross-fitting
# Δ ≈ (+0.196, −0.055, −0.141): more Flourishing, fewer Distressed students (truth +0.18, −0.06, −0.12)

# 2. Eight childhood adversities form latent family contexts. Preventing abuse and neglect:
#    for whom does it matter, and could the latent context confound the effect?
a = dataset("ace_study")
A = Matrix{Int}(a[:, r"^ace"]); Xa = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
dep = Float64.(a.depressed); g = setto([0, 0])
sh = intervene_shares(A, Xa, [1, 2], g; K = 3)     # 3-class model of the adversities
intervene_within(dep, A, Xa, [1, 2], g; model = sh.model, family = :binomial)
intervene_latent_sensitivity(dep, A, Xa, [1, 2], g; model = sh.model, family = :binomial, target = 3)

# sensitivity analyses for example 1
intervene_membership_sensitivity(r; target = 1)                 # E-values and tipping points
intervene_dif(m, p[:, [:low_mood, :worry, :sleep, :lonely, :hopeless, :enjoy, :confident, :friends]],
        p.programme, X)                        # measurement non-invariance by treatment

# the intervention estimators on their own (observed outcome)
intervene_effect(dep, A, Xa, [1, 2], g; family = :binomial, estimator = :tmle)  # ≈ −0.0345 (truth −0.038)

The Tutorial runs these analyses end to end on simulated data with known truth, and Latent classes and interventions shows how the methods combine in one paper.

Sensitivity analyses

Each method rests on an assumption the data cannot check; each has a sensitivity or diagnostic tool.

ThreatApplies toToolWhat it reports
Unmeasured confounding of treatment and classintervene_membershipintervene_membership_sensitivityper class, E-values for the causal risk ratio $P\{C(1)=k\}/P\{C(0)=k\}$ (VanderWeele & Ding 2017) and tipping points of an additive bias model (biases sum to zero over classes)
Measurement non-invariance by treatment (DIF), which invalidates the BCH correctionintervene_membershipintervene_difscaled $\chi^2$ test of invariant vs treatment-specific measurement and $\Delta_k$ with treatment-specific classification errors
The latent class of the exposures affects the outcome directly (latent confounding)intervene_effect, intervene_withinintervene_latent_sensitivitytipping points of the direct class effect $\gamma$ (bias $\sum_k \gamma_k \Delta_k$, joint bootstrap)
Extreme weights from rare exposure profilesintervene_effectadjust = :classes / :boththe effect with the other exposures summarised by their latent class
Heterogeneity across observed subgroupsintervene_membershipintervene_subgroup$\Delta_k$ within a subgroup

Assumptions in brief

  • intervene_membership: consistency, positivity, no unmeasured confounding of $A$ given $X$, and a measurement model that holds and is invariant across $A$ and $X$ (no differential item functioning). Double robustness covers the propensity and class-regression models, not the measurement model.
  • intervene_effect: consistency, exchangeability of the intervened exposures given the other exposures and $X$, positivity, and the other exposures are not affected by the intervened ones. A latent variable that drives the indicators and also affects the outcome breaks exchangeability.
  • intervene_within, adjust = :classes: in addition, no direct effect of the exposure class on the outcome beyond the exposures and $X$ — what intervene_latent_sensitivity probes. intervene_shares is descriptive.
  • intervene_latent_outcome: those of intervene_effect, plus a measurement model of the outcome classes that does not depend on the exposures.

Method status

Each estimator is classed as Established (a published, peer-reviewed estimator implemented as published), Established-with-adaptation (a published method with a package-specific change, named in the table) or Experimental (the package's own construction, or a combination not validated in the literature; the package's own simulations do not count as such validation). Other utilities (align_classes, plots, result types, datasets) make no statistical claim and are not listed. Full references are on the Treatment effects on latent classes and Intervention estimators pages and in the docstrings.

intervene_withinExperimentalThe package's own class-specific effect (a posterior-weighted average of the intervention contributions); not doubly robust.

intervene_sharesExperimentalA descriptive functional (the class model's classification of post-intervention profiles), not a causal effect on class membership.

intervene_subgroupExperimentalSubgroup averages of the AIPW contributions (standard for doubly robust estimators), built on the experimental default of intervene_membership.
intervene_membership_sensitivityEstablished-with-adaptation (E-values); Experimental (additive bias model)E-values (VanderWeele & Ding 2017; Ding & VanderWeele 2016) for P(C(1) = k)/P(C(0) = k) estimated from pseudo-outcomes, valid only under measurement invariance; the sum-to-zero additive bias model is the package's own.
intervene_difExperimentalThe scaled (Satorra–Bentler) difference test and multigroup LCA are established; recomputing Δₖ with treatment-specific classification matrices is the package's own. Diagnostic only.

Package overview

LatentClassCausal — Module
LatentClassCausal

Causal inference for latent class and latent profile models fitted with LatentMixtures.jl: questions about how treatments and interventions relate to latent classes.

  • Treatment effects on latent class membership (intervene_membership): Δₖ = P(C(1) = k) − P(C(0) = k) for a binary treatment A, by augmented inverse probability weighting (AIPW) of bias-corrected (BCH) pseudo-outcomes, cross-fitted nuisance models and influence-function standard errors that include the uncertainty of the measurement model (LCCResult; align_classes matches classes). Extensions: intervene_subgroup, intervene_membership_sensitivity, intervene_dif.
  • Latent classes and interventions on exposures, for exposures that form latent classes (e.g. childhood adversities): the effect of an intervention on a latent class outcome (intervene_latent_outcome), effects within each latent class of the exposures (intervene_within), sensitivity to a direct effect of the latent class (intervene_latent_sensitivity), adjustment for the latent pattern of the other exposures (intervene_effect(...; adjust = :classes)), and the classification of post-intervention profiles (intervene_shares, descriptive).

These are built on intervene_effect: the parametric g-formula, IPTW, AIPW and TMLE of ψ = E[Y^{g1}] − E[Y^{g0}] for static (setto), stochastic (shift), targeted (subgroup) and natural-course (natural) Interventions on binary exposures (InterventionResult), which can also be used on its own for an observed outcome.

The estimators accept flexible machine-learning nuisance models (penalised GLMs, random forests, gradient boosting, a super learner) through their propensity and outcome keywords; see NuisanceLearner and the Machine-learning nuisance models page. Plots (effectplot, interventionplot) are available with any Makie backend (package extension LatentClassCausalMakieExt).

The documentation pages Latent classes and interventions, Treatment effects on latent classes and Intervention estimators give the estimands, assumptions, derivations and simulation evidence.
