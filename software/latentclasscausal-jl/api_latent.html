API reference: latent-class methods

Theory and worked examples: Latent classes and interventions; usage: Function guide.

LatentClassCausal.intervene_within — Function
intervene_within(Y, A, X, S, g1; g0 = natural(), K = nothing, model = nothing,
              estimator = :aipw, outcome = :linear, propensity = :linear,
              family = :gaussian, folds = 5, seed = 1, B = 200,
              lca_uncertainty = :bootstrap, starts = (100, 20), boot_starts = (30, 6))
    -> ClassEffectsResult

Class-specific effects of a hypothetical intervention on exposures, ψ_k = E[Y^{g1} − Y^{g0} | C = k], where C is the natural (pre-intervention) latent class of a latent class model of all exposures with the confounders as covariates, for example "how much would preventing abuse and neglect improve health among people in the high-adversity class?".

With τᵢₖ = P(C = k | Aᵢ, Xᵢ) the posterior class probabilities and φ1ᵢ, φ0ᵢ the per-observation contributions of intervene_effect,

ψ̂_k = Σᵢ τᵢₖ (φ1ᵢ − φ0ᵢ) / Σᵢ τᵢₖ.

How to use

  1. Fit the class model of all exposures with the confounders as covariates once, mA = lca(A, K; covariates = X), check convergence(mA) and name the classes from their item-response probabilities.
  2. Define the intervention (S, g1, g0) and estimate the population effect with intervene_effect first.
  3. Run intervene_within(Y, A, X, S, g1; model = mA, family) with the default bootstrap (lca_uncertainty = :bootstrap, B = 200); lca_uncertainty = :none only for a quick look.
  4. ψₖ is not doubly robust: rerun with a flexible outcome model (outcome = :quadratic or a learner) and compare.
  5. Probe the assumption of no direct class effect with intervene_latent_sensitivity (same model). See the Function guide page.

Arguments

As intervene_effect: outcome Y, n × J exposures A, confounders X, intervened columns S, intervention g1.

Keywords

  • K / model: number of classes of the LCA of all columns of A with covariates X (lca(A, K; covariates = X, starts)), or such a fitted model. Classes are labelled as in the model.
  • estimator::Symbol = :aipw: :aipw, :tmle or :gformula (:ipw is not available: its contributions do not have conditional mean E[Y^g | A, X]).
  • outcome, propensity, family, folds, seed, B, learners, bound: passed to intervene_effect (B is also the number of class-model bootstrap replicates). outcome and propensity accept machine-learning learners (see NuisanceLearner); note that ψ_k is not doubly robust, so it relies on the outcome learner.
  • lca_uncertainty::Symbol = :bootstrap: :bootstrap (default) — nonparametric bootstrap refitting the class model and the nuisance models (B replicates, threaded, the first alone); :none — influence-function standard errors τᵢₖ(φΔᵢ − ψ_k)/mean(τ_k) that hold the class model and the nuisance models fixed (median coverage 0.91, as low as 0.64 for small, poorly separated classes in the simulation).
  • starts = (100, 20): EM starts of the class model fitted when K is given; boot_starts = (30, 6): starts of each bootstrap refit, as in intervene_shares. With n = 2500, 8 exposures and K = 3, B = 200 takes about 80 s on 8 threads with :warm and about 390 s with (30, 6) (Nibi cluster node), against under a second for :none.

Returns

A ClassEffectsResult (with the population effect in overall).

Examples

using LatentClassCausal
# ace_study: 2,500 adults, 8 childhood adversities, confounders, adult self-rated health.
# Effect of preventing abuse and neglect (ace1, ace2) within each of 3 adversity classes:
a = dataset("ace_study")
A = Matrix{Int}(a[:, r"^ace"])
X = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
ce = intervene_within(Float64.(a.health), A, X, [1, 2], setto([0, 0]); K = 3)
ce.effect          # largest in the class where abuse and neglect are common
ce.overall.effect  # the population effect, Σ_k P(C = k) ψ_k

Notes

Identification needs the assumptions of intervene_effect and, in addition, Y^g ⫫ C | A, X: given the exposures and the confounders, the class carries no further information about the outcome (no direct class effect on Y; see intervene_latent_sensitivity for what happens otherwise). Then E[Y^g | C = k] = E[τk(A, X) E[Y^g | A, X]] / P(C = k). The estimator is consistent when the outcome model is correctly specified; unlike the population effect it is not doubly robust, because the residual term of AIPW/TMLE averages to zero against τ\k(A, X) only when the outcome model is right. The class model must be correctly specified (local independence, covariate effects on class membership only).

LatentClassCausal.intervene_shares — Function
intervene_shares(A, X, S, g1; g0 = natural(), K = nothing, model = nothing,
             lca_uncertainty = :bootstrap, B = 200, starts = (100, 20),
             boot_starts = (30, 6), seed = 1) -> ClassSharesResult

Post-intervention classification shares: how a latent class model of the exposures would classify the exposure profiles that the intervention produces.

The class model is a latent class analysis of all J columns of A with the confounders X as covariates of class membership (one-step; fitted with lca(A, K; covariates = X) when K is given, or passed as model). In this generative model the class C causes the exposures (C → A), so intervening on A_S does not change anybody's class. The quantity reported is therefore not a causal effect on C; it is the distribution of the model's classification of the post-intervention profiles,

π_k^g = (1/n) Σᵢ Σₛ q_g(s | A_S,i, i) · P(C = k | A_S = s, A_rest,i, Xᵢ),

with P(C = k | a, x) the model posterior at profile a. Under the natural course π_k is the mean posterior probability of class k. Δ_k = π_k^{g1} − π_k^{g0} is the shift in the class composition implied by the intervention, and it is the quantity that drives the bias of intervene_effect under a direct class effect on the outcome (intervene_latent_sensitivity). No outcome is needed.

How to use

  1. Fit the class model of all exposures with the confounders as covariates, mA = lca(A, K; covariates = X), and check convergence(mA) (or pass K to fit it here).
  2. Define the intervention (S, g1, g0) as for intervene_effect; no outcome is needed.
  3. Run sh = intervene_shares(A, X, S, g1; model = mA) and keep the default bootstrap standard errors for anything you report.
  4. Report Δₖ as the change in how the model would classify the post-intervention profiles, not as a causal change of class membership.
  5. Pass sh to intervene_latent_sensitivity ((result, shares) form) or use its Δₖ to choose the target class there. See the Function guide page.

Arguments

  • A::AbstractMatrix: n × J binary exposures, complete.
  • X::AbstractVecOrMat: confounders (n × p, may have 0 columns), complete.
  • S::AbstractVector{<:Integer}: intervened columns of A (1 to 6).
  • g1::Intervention: the intervention (setto, shift, a user rule Intervention, subgroup).

Keywords

  • g0::Intervention = natural(): comparison.
  • K = nothing / model = nothing: number of classes to fit, or a fitted LatentMixtureModel (LCA of the columns of A, in order, with covariates X, fitted to these n rows). Class labels are those of the model.
  • lca_uncertainty::Symbol = :bootstrap: :bootstrap (default) refits the class model on B nonparametric bootstrap resamples (classes aligned with align_classes; threaded, the first replicate runs alone); :none gives influence-function standard errors conditional on the class-model estimates, which are far too small (see Notes).
  • B::Integer = 200, seed::Integer = 1: bootstrap replicates and seed of the resamples.
  • starts = (100, 20): EM starts of the class model fitted when K is given (lca defaults).
  • boot_starts = (30, 6): starts of each bootstrap refit of the class model. (n1, n2) (default (30, 6)): random starts (stage 1, stage 2); the simulation coverage on the Latent classes: simulation page was obtained this way. :warm: one EM run from the full-sample estimates (lca(...; start = model)), about 5 times faster, but it understates the bootstrap variability when classes are weakly separated (coverage 0.71–0.95 against 0.86–0.98 for random starts at n = 500; see that page): use it only for quick exploration with well-separated classes. (:warm, n1, n2): the warm start plus n1/n2 random starts, keeping the higher log-likelihood.

Returns

A ClassSharesResult.

Examples

using LatentClassCausal
# ace_study: 8 childhood adversities (ace1 = abuse, ace2 = neglect, ...), confounders.
# If abuse and neglect were prevented, how would a 3-class adversity model classify people?
a = dataset("ace_study")
A = Matrix{Int}(a[:, r"^ace"])
X = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
sh = intervene_shares(A, X, [1, 2], setto([0, 0]); K = 3)       # bootstrap SEs (B = 200)
sh.pi0, sh.pi1      # natural course: the class sizes; after prevention: fewer in the high-adversity class

Notes

  • The standard errors with lca_uncertainty = :none treat the class model as known ((dᵢₖ − π_k) is the influence function of a mean) and understate the uncertainty severely: in the simulation of the Latent classes: simulation page their coverage was about 50% (SE about a third of the true SD), against about 95% for lca_uncertainty = :bootstrap; hence the bootstrap is the default (that coverage was obtained with the default random-start refits, boot_starts = (30, 6)). With n = 2500, 8 exposures and K = 3, B = 200 takes about 380 s on 8 threads (about 75 s with boot_starts = :warm, which understates the SEs when classes are weakly separated); use B = 50 for a quick look or :none only for exploration.
  • The latent class model must hold: local independence given C, covariates acting on class membership only (no direct X → A effects) and the right K.

LatentClassCausal.intervene_latent_sensitivity — Function
intervene_latent_sensitivity(Y, A, X, S, g1; g0 = natural(), K = nothing, model = nothing,
                   gamma = nothing, target = 1, grid = nothing, level = 0.95,
                   lca_uncertainty = :bootstrap, B = 200, estimator = :aipw, outcome,
                   propensity, family, folds, seed, starts, boot_starts)
intervene_latent_sensitivity(result::InterventionResult, shares::ClassSharesResult;
                   gamma = nothing, target = 1, grid = nothing, level = 0.95)
    -> LatentSensitivityResult

Sensitivity of an intervention effect to latent confounding by the exposure classes: what if the latent class C that generates the exposures also affects the outcome directly?

Model: E[Y | A_S, H, C] = μ*(A_S, H) + γ_C (additive class effect, no interaction, γ of a reference class = 0), with exchangeability given (H, C). Then the observed-data functional of intervene_effect is biased by

bias(ψ) = Σ_k γ_k Δ_k,    Δ_k = π_k^{g1} − π_k^{g0}  (intervene_shares),

and the corrected effect is ψ(γ) = ψ̂ − Σ_k γ_k Δ̂_k.

Standard errors. The data method (first form, the default) fits intervene_effect and intervene_shares and, with lca_uncertainty = :bootstrap, bootstraps ψ̂ and Δ̂ jointly (B resamples, refitting the class model and the nuisance models on each), so that Var(ψ̂ − tΔ̂v) = Var(ψ̂) − 2t Cov(ψ̂, Δ̂v) + t² Var(Δ̂v) comes from the bootstrap distribution. The second form takes the two results: if shares was bootstrapped, Var(Δ̂v) is taken from its bootstrap draws and Cov(ψ̂, Δ̂_v) from the influence functions φΔᵢ and δᵢₖ (:hybrid); if not, everything comes from the influence functions, which hold the class model fixed and are too optimistic (:conditional).

How to use

  1. Use the class model of all exposures with covariates (mA = lca(A, K; covariates = X)), the same one as for intervene_within and intervene_shares.
  2. Choose the class whose direct effect on Y is the worry (target), for example the class whose share the intervention reduces most, argmax(sh.pi0 .- sh.pi1), or give a vector gamma of class effects.
  3. Run the data method, intervene_latent_sensitivity(Y, A, X, S, g1; model = mA, family, target) (joint bootstrap); the (result, shares) form is fast but its interval-based tipping point is less reliable (:hybrid or :conditional standard errors).
  4. Report tipping_zero (the γ that explains ψ away) and tipping_ci (the γ at which the interval first includes 0), on the outcome scale, and compare them with plausible differences in Y between the classes. See the Function guide page.

Arguments

  • Data method: Y, A, X, S, g1 as in intervene_effect (estimator :aipw, :tmle or :ipw), with g0, K/model, outcome, propensity, family, folds, seed, starts, boot_starts, learners, bound as in intervene_shares and intervene_effect (learners accepted), and lca_uncertainty = :bootstrap, B = 200.
  • result: an InterventionResult (:aipw, :tmle or :ipw; not :gformula, whose contributions are not influence functions).
  • shares: the ClassSharesResult for the same data, rows, S, g1 and g0.

Keywords

  • gamma = nothing: a vector of K class effects on the outcome scale (mean difference; risk difference for family = :binomial); the reference class has γ = 0. The grid is then over multiples t·γ.
  • target::Integer = 1: without gamma, a scalar γ for class target versus all other classes.
  • grid = nothing: values of t (default: 101 points covering both tipping points).
  • level::Real = 0.95: confidence level.

Returns

A LatentSensitivityResult with the curve ψ(t), the tipping point at which ψ = 0 and the one at which the confidence interval first includes 0.

Examples

using LatentClassCausal
# ace_study: what if the high-adversity family context also lowered adult health directly?
a = dataset("ace_study")
A = Matrix{Int}(a[:, r"^ace"])
X = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
# joint bootstrap (B = 200) of the effect and the classification shares
s = intervene_latent_sensitivity(Float64.(a.health), A, X, [1, 2], setto([0, 0]); K = 3, target = 3)
s.tipping_zero, s.tipping_ci                   # how strong a direct class effect explains ψ away
# from results already computed (bootstrapped shares: :hybrid standard errors)
r  = intervene_effect(Float64.(a.health), A, X, [1, 2], setto([0, 0]))
intervene_latent_sensitivity(r, s.shares; gamma = [0, -1, -3])    # a specific vector of class effects

Notes

  • Assumptions: the bias model above (constant additive class effect, no class × exposure interaction); the latent class model of all exposures with covariates is correct, so that P(C = k | s, H) is its posterior at the counterfactual profile; the intervention does not change the class (C precedes and generates A).
  • γ is on the outcome scale: points of Y for a continuous outcome, a risk difference for a binary outcome (where the additive model is an approximation).
  • With :conditional standard errors the term γ·SE(Δ) uses the conditional SE of Δ, which is far too small (see intervene_shares), so intervals and tipping_ci are optimistic, increasingly so at large |γ|; use the bootstrap (the default of the data method). tipping_zero does not depend on the SE.
  • The correction removes the bias described by the formula; with a direct class effect the outcome regression μ(s, H) is no longer of the working form, so a misspecified outcome model leaves some bias of its own (see the simulation page).

  • delta::Vector{Float64}: classification-share shifts Δ_k (from intervene_shares).

LatentClassCausal.intervene_latent_outcome — Function
intervene_latent_outcome(m, A, X, S, g1; g0 = natural(), estimator = :aipw,
                          outcome = :linear, propensity = :linear, folds = 5, seed = 1)
    -> InterventionClassResult

Effect of a hypothetical intervention on binary exposures on membership in a latent class outcome, Δ_k^g = P(C^{g1} = k) − P(C^{g0} = k), where C is measured by a separate measurement model m (e.g. adult health-behaviour classes from their own indicators; not the latent class model of the exposures).

Each class indicator is replaced by its BCH pseudo-outcome Zᵢₖ = (D⁻¹)[ĉᵢ, k] (D the classification-error matrix of m, ĉ the modal class), as in intervene_membership, and the intervention estimator of intervene_effect is applied to each of the K columns (Gaussian working model, so the contributions are linear in Z). Standard errors come from the stacked influence function, including the estimation of D and of the measurement parameters exactly as in intervene_membership.

How to use

  1. Fit the outcome measurement model on its own indicators, without covariates (mo = lca(Y, K)), and check convergence(mo); the exposures and confounders do not enter it.
  2. Put the binary exposures in an integer matrix A (a single exposure as reshape(a, :, 1)) and the confounders in X, in the rows of mo.
  3. Choose S, g1 and g0: the default g0 = natural() gives "intervention vs the observed course"; g0 = setto(0) gives "everyone vs no one".
  4. Run intervene_latent_outcome(mo, A, X, S, g1; g0) and check the entropy, the pseudo-outcome range and the overlap (min_pi, max_weight) in the printout.
  5. Measurement invariance of mo across exposures and confounders is assumed; with one binary exposure, intervene_dif tests it. See the Function guide page.

Arguments

  • m::LatentMixtureModel: the outcome measurement model, fitted without covariates (and without weights) to the m.ninput rows of the data.
  • A::AbstractMatrix: m.ninput × J 0/1 exposures (complete on the analysed rows).
  • X::AbstractVecOrMat: confounders, m.ninput rows.
  • S, g1: intervened columns and intervention, as in intervene_effect (rules q(s, a, i) and subgroup masks index the input rows).

Keywords

  • g0 = natural(), estimator = :aipw (:aipw, :tmle, :ipw, :gformula; the g-formula has no standard errors here), outcome, propensity, folds, seed, learners, bound: as in intervene_effect. With a learner outcome model the contributions of the pseudo-outcomes are still U · D⁻¹, i.e. AIPW/TMLE with the outcome regression Σⱼ μ̂ⱼ (D⁻¹)[j, k] built from the fits of the modal indicators.

Returns

An InterventionClassResult.

Examples

using LatentClassCausal, LatentMixtures
# Would preventing abuse and neglect change membership in adult health classes?
# (illustration: outcome classes from depression, poor self-rated health and two items)
a = dataset("ace_study")
A = Matrix{Int}(a[:, [:ace1, :ace2, :ace3, :ace4, :ace5, :ace6]])
X = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
H = hcat(a.depressed, Int.(a.health .< 50), a.ace7, a.ace8)   # outcome indicators
mo = lca(H, 2)                                                 # outcome classes, no covariates
r = intervene_latent_outcome(mo, A, X, [1, 2], setto([0, 0]))
r.delta                                                        # change in each class's share

Notes

  • Identification: the assumptions of intervene_effect for the class indicator as outcome, plus a correctly specified, identified and measurement-invariant outcome model: the item-response probabilities given C do not depend on the exposures or the confounders (no differential item functioning). Under DIF the pseudo-outcomes are biased for the class indicators and so is every estimate; see intervene_dif for a diagnostic in the single-treatment case.
  • The pseudo-outcomes are not in [0, 1]; only their conditional means are probabilities.

LatentClassCausal.intervene_subgroup — Function
intervene_subgroup(m, A, X, mask; name = "subgroup", estimator = :aipw, propensity = :linear,
             outcome = :linear, folds = 5, trim = 0.0, seed = 1) -> LCCSubgroupResult

Effect of a binary treatment on latent class membership within a subgroup, Δ_k(G) = P(C(1) = k | G) − P(C(0) = k | G) (a conditional average effect), by weighting the per-observation contributions of intervene_membership with the subgroup indicator: nuisance models are fitted on the whole sample (cross-fitted), and the AIPW estimate is Σᵢ 1(i ∈ G) φᵢ / |G| (:ipw_bch: Hájek weights within G). Standard errors include the measurement model as in intervene_membership.

How to use

  1. Fit m and run intervene_membership on the whole sample first.
  2. Define the subgroup as a Bool vector over the input rows from pre-treatment variables only (e.g. d.female .== 1).
  3. Run intervene_subgroup(m, A, X, mask; name); the nuisance models still use the whole sample.
  4. Repeat for the complementary subgroup and compare; no test of the difference between subgroups is reported. See the Function guide page.

Arguments

  • m, A, X: as in intervene_membership.
  • mask::AbstractVector{Bool}: subgroup membership, one entry per input row (m.ninput). It must be defined by pre-treatment variables (e.g. confounders); a mask depending on the treatment or the indicators changes the estimand.

Keywords

  • name::AbstractString = "subgroup": label used in printing.
  • estimator::Symbol = :aipw: :aipw or :ipw_bch; the rest (including learners for propensity/outcome, learners, bound) as in intervene_membership.

Returns

An LCCSubgroupResult.

Examples

using LatentClassCausal, LatentMixtures
# programme: a school mental-health programme and 3 wellbeing classes (8 items)
d = dataset("programme")
Y = d[:, [:low_mood, :worry, :sleep, :lonely, :hopeless, :enjoy, :confident, :friends]]
X = Matrix{Float64}(d[:, [:female, :age, :low_ses, :distress, :belonging]])
m = lca(Y, 3)
intervene_subgroup(m, d.programme, X, d.female .== 1; name = "girls")

LatentClassCausal.intervene_membership_sensitivity — Function
intervene_membership_sensitivity(r::LCCResult; bias = nothing, target = 1, grid = nothing, level = 0.95)
    -> LCCSensitivityResult

Sensitivity of the treatment effects on latent class membership (intervene_membership) to unmeasured confounding.

Additive bias model. With an unmeasured confounder the estimate converges to Δ_k + bias_k, where bias_k (probability units) is the difference between the observed-data functional and the causal effect for class k; because both sum to zero over classes, Σ_k bias_k = 0. The corrected effect is Δ̂_k − bias_k with the same standard error. Reported per class: the tipping point bias_k = Δ̂_k at which the effect vanishes, and the bias Δ̂_k ∓ z·SE_k at which the interval first includes zero; and over a grid of biases b for class target, the curve Δ̂_target − b with its interval.

E-values. For each class, 1(C = k) is a binary outcome with risks P(C(1) = k) and P(C(0) = k), so the bounding argument of VanderWeele & Ding (2017) applies to the causal risk ratio RR_k = P(C(1) = k)/P(C(0) = k): an unmeasured confounder associated with both the treatment and membership in class k by risk ratios of at least E = RR + √(RR(RR − 1)) (with RR replaced by 1/RR when RR < 1) could explain the observed ratio away, conditional on X. The interval of log RR uses the delta method with Cov(ψ̂1, ψ̂0) recovered from se, se_psi1 and se_psi0.

How to use

  1. Estimate r = intervene_membership(m, A, X) with an estimator that has standard errors (:aipw, :ipw_bch or :aipw_posterior).
  2. Run intervene_membership_sensitivity(r; target = k) with k the class of main interest (the curve is drawn for it; the per-class results cover every class).
  3. Report the E-values of the estimate and of the confidence limit (evalue, evalue_ci) and the additive tipping biases (tipping_zero, tipping_ci; probability units).
  4. For a specific scenario, give bias (K values summing to zero) and read corrected.
  5. Both analyses assume measurement invariance: check it with intervene_dif. See the Function guide page.

Arguments

  • r::LCCResult: from an estimator with standard errors (:aipw, :ipw_bch, :aipw_posterior).

Keywords

  • bias = nothing: a vector of K biases summing to zero.
  • target::Integer = 1: class of the sensitivity curve.
  • grid = nothing: biases b for the curve (default: 101 points covering the tipping point).
  • level::Real = 0.95.

Returns

An LCCSensitivityResult.

Examples

using LatentClassCausal, LatentMixtures
d = dataset("programme")
Y = d[:, [:low_mood, :worry, :sleep, :lonely, :hopeless, :enjoy, :confident, :friends]]
m = lca(Y, 3)
r = intervene_membership(m, d.programme, Matrix{Float64}(d[:, [:female, :age, :low_ses, :distress, :belonging]]))
s = intervene_membership_sensitivity(r; target = 1)
s.tipping_ci, s.evalue
intervene_membership_sensitivity(r; bias = [0.03, -0.02, -0.01]).corrected

Notes

The E-value assumes the measurement model is valid (no DIF) so that P(C(a) = k) are genuine risks; it is computed from BCH-based estimates and is NaN when an estimated probability is not positive. Bias values are on the probability scale.

References

  • VanderWeele, T. J., & Ding, P. (2017). Sensitivity analysis in observational research: introducing the E-value. Annals of Internal Medicine, 167(4), 268–274. https://doi.org/10.7326/M16-2607
  • Ding, P., & VanderWeele, T. J. (2016). Sensitivity analysis without assumptions. Epidemiology, 27(3), 368–377. https://doi.org/10.1097/EDE.0000000000000457

LatentClassCausal.intervene_dif — Function
intervene_dif(m, Y, A, X; invariance = :none, estimator = :aipw, alpha = 0.05,
        starts = (100, 20), seed = 20261119, kwargs...) -> LCCDIFResult

Differential item functioning (DIF) by treatment in the measurement model of intervene_membership: measurement invariance is the assumption that makes the BCH correction valid, and it can be tested with known groups.

Fits two multigroup latent class models with group = A (Mplus KNOWNCLASS): full invariance and non-invariance of the items in invariance (default all items), compares them with the scaled χ² difference test (compare_models of LatentMixtures.jl), and reports how Δ_k changes when the measurement model is allowed to differ between treated and untreated: the non-invariant Δ_k uses BCH pseudo-outcomes Zᵢ = (D_{Aᵢ}⁻¹)[ĉᵢ, :] with modal classes and classification-error matrices D_a computed within each treatment group, plugged into the same estimator (:aipw: arm-specific linear regressions of Z on X as outcome model; :ipw_bch: Hájek). Classes of the multigroup model are aligned with m by the item-response probabilities of the untreated group.

How to use

  1. Pass the measurement model m of intervene_membership and the indicator data Y it was fitted to (same rows, same columns), with the treatment and confounders.
  2. Run intervene_dif(m, Y, A, X) (all items free across treatment groups), or invariance = [...] to free selected items only.
  3. Read the scaled χ² difference test first: if it does not reject, report it and keep the invariant Δₖ (the change is then noise).
  4. If it rejects, check in the free model that the classes keep their meaning in both groups, then compare the invariant and non-invariant Δₖ. See the Function guide page.

Arguments

  • m::LatentMixtureModel: the measurement model used in intervene_membership (no covariates).
  • Y: the indicator data m was fitted to (same rows, same columns).
  • A::AbstractVector, X: treatment (0/1, complete) and confounders.

Keywords

  • invariance = :none: items free across treatment groups in the non-invariant model (:none for all, or a vector of names/indices for partial invariance).
  • estimator::Symbol = :aipw (:aipw or :ipw_bch), alpha = 0.05, starts, seed; other keywords (propensity, outcome, folds, trim, learners, bound) as in intervene_membership; with a learner outcome the non-invariant Δ_k regresses each pseudo-outcome column on X with that learner within arms.

Returns

An LCCDIFResult; printing warns when DIF is significant.

Examples

using LatentClassCausal, LatentMixtures
d = dataset("programme")
Y = d[:, [:low_mood, :worry, :sleep, :lonely, :hopeless, :enjoy, :confident, :friends]]
m = lca(Y, 3)
intervene_dif(m, Y, d.programme, Matrix{Float64}(d[:, [:female, :age, :low_ses, :distress, :belonging]]))

Notes

The change is noisy (the non-invariant Δ_k is estimated with group-specific measurement); read it only when the test rejects. The non-invariant Δ_k is only meaningful when the classes keep the same substantive meaning in both groups (check the item-response probabilities of the free model); the test has the usual χ² caveats (sparse tables, boundary estimates).
