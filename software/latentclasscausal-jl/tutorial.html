Tutorial

This tutorial runs both methods on the two example datasets shipped with the package (see Datasets). They are simulated, so the true effects are known and the estimates can be checked against them. Every code block on this page is executed when the documentation is built; the output shown is what the code produces.

Part 1: the effect of a programme on latent wellbeing classes

The data

programme follows 2,000 students. Six months after a school-based mental-health promotion programme, eight binary items describe their wellbeing (low_mood, worry, sleep, lonely, hopeless, enjoy, confident, friends). About 41% took part (programme = 1). Participation was targeted at students who were distressed and poorly connected at baseline, so the baseline variables female, age, low_ses, distress and belonging confound the comparison of participants and non-participants.

using LatentMixtures, LatentClassCausal, Statistics

p = dataset("programme")
items = p[:, [:low_mood, :worry, :sleep, :lonely, :hopeless, :enjoy, :confident, :friends]]
X = Matrix{Float64}(p[:, [:female, :age, :low_ses, :distress, :belonging]])
A = p.programme
mean(A), mean(p.distress[A .== 1]) - mean(p.distress[A .== 0])   # participants: +0.6 SD distress
(0.412, 0.7161270721880987)

Fit the latent class model to the outcome items only. A and X must not enter the measurement model (intervene_membership refuses a model with covariates).

m = lca(items, 3)

Latent class labels are arbitrary. Here the generating item probabilities are known (see the codebook), so align_classes can check the labelling formally; in an application, label classes by their profiles as above:

truth_rho = [0.04 0.35 0.85; 0.10 0.45 0.85; 0.08 0.35 0.70; 0.04 0.30 0.70;
             0.01 0.12 0.60; 0.95 0.65 0.20; 0.90 0.50 0.15; 0.92 0.70 0.40]
est_rho = reduce(vcat, [ip.probs[2:2, :] for ip in itemprobs(m)])

Step 2: the causal effect

The default estimator is cross-fitted AIPW with BCH pseudo-outcomes:

r = intervene_membership(m, A, X)

  1           0.623      0.429      0.194    0.031     [0.134, 0.254]    0.000
  2           0.242      0.294     -0.052    0.037    [-0.123, 0.020]    0.160
  3           0.135      0.277     -0.143    0.021   [-0.185, -0.101]    0.000

The printed table reports, for each class, P(C(1) = k), P(C(0) = k), the effect Δₖ, its robust standard error, a Wald 95% interval and a p-value. The true effects are +0.179, −0.059, −0.120: the programme moves students from the Distressed (and Moderate) class into the Flourishing class. Estimates and truth, with standard errors:

Comparing estimators

The corrected estimators (:aipw, :ipw_bch, :or) agree closely. The uncorrected ones, which treat modal classes or posterior probabilities as if they were the true class (:ipw_modal, :aipw_posterior), are shrunk towards zero; across replications they are biased (see the simulation evidence on the theory page). :naive ignores confounding: because the programme recruited distressed students, it finds almost no effect at all.

ests = (:aipw, :ipw_bch, :or, :ipw_modal, :aipw_posterior, :naive)
[e => round.(intervene_membership(m, A, X; estimator = e).delta[perm]; digits = 3) for e in ests]
6-element Vector{Pair{Symbol, Vector{Float64}}}:
           :aipw => [0.194, -0.052, -0.143]
        :ipw_bch => [0.197, -0.051, -0.145]
             :or => [0.201, -0.057, -0.144]
      :ipw_modal => [0.17, -0.039, -0.131]
 :aipw_posterior => [0.145, -0.018, -0.127]
          :naive => [0.022, -0.02, -0.003]

Flexible nuisance models and propensity-score truncation are keyword options:

r2 = intervene_membership(m, A, X; propensity = :quadratic, outcome = :quadratic, trim = 0.01)
round.(r2.delta[perm]; digits = 3), r2.propensity_range
([0.206, -0.07, -0.136], (0.019147700808642098, 0.9344839853316287))

Part 2: interventions on childhood adversities (the estimators)

The data

ace_study has 2,500 adults with eight binary adverse childhood experiences (ace1 = abuse, ace2 = neglect, ace3 = sexual abuse, ace4 = domestic violence, ace5 = household substance misuse, ace6 = household mental illness, ace7 = parental separation, ace8 = an incarcerated household member), the confounders age, female and parent_edu (parents' years of education), self-rated health today (health, 0–100) and past-year depression (depressed). In the generating process a latent family context drives all eight adversities, but health depends only on ace1, ace2 (with an interaction), ace6 and the confounders. Intervening on ace1 and ace2 is therefore identified given the other adversities and the confounders, which intervene_effect adjusts for automatically.

using LatentClassCausal, Statistics

a = dataset("ace_study")
A = Matrix{Int}(a[:, r"^ace"])
X = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
health = Float64.(a.health)
n = length(health)
round.(vec(mean(A; dims = 1)); digits = 3)     # prevalences of ace1 … ace8
8-element Vector{Float64}:
 0.186
 0.142
 0.077
 0.197
 0.234
 0.196
 0.291
 0.081

The true effects (codebook) of preventing both abuse and neglect, compared with the natural course, are +2.00 points of self-rated health and −0.038 in the probability of depression; halving their prevalence gives +1.04 and −0.021.

Static intervention: prevent abuse and neglect

setto defines the static intervention; the comparison g0 defaults to the natural course.

r = intervene_effect(health, A, X, [1, 2], setto([0, 0]))
Effect of an intervention on indicators (aipw, 5-fold cross-fitting); n = 2500
  g1: set to [0, 0]
  g0: natural course
  E[Y^g1] = 78.9340 (0.3097)   E[Y^g0] = 76.7012 (0.2548)
  ψ = 2.2328   S.E. 0.2139   95% CI [1.8136, 2.6519]   p = 0.0000
  overlap: min P(A_S = s | H) = 0.0054, max weight = 8.8

ψ is the change in mean self-rated health if no one had experienced abuse or neglect. min_pi and max_weight summarise overlap. The four estimators side by side (the g-formula's standard error is a bootstrap with B replications):

res = [e => intervene_effect(health, A, X, [1, 2], setto([0, 0]); estimator = e, B = 100)
       for e in (:gformula, :ipw, :aipw, :tmle)]
[(e, round(x.effect; digits = 2), round(x.se; digits = 2)) for (e, x) in res]
4-element Vector{Tuple{Symbol, Float64, Float64}}:
 (:gformula, 2.28, 0.19)
 (:ipw, 2.25, 0.22)
 (:aipw, 2.23, 0.21)
 (:tmle, 2.24, 0.21)

Flexible nuisance models are keyword options. The default :linear outcome model omits the abuse × neglect interaction of the true model; :quadratic is saturated in the intervened exposures (so it contains the interaction) but also adds squares and products of the adjustment variables and their interactions with the exposures, which cost precision with n = 2,500. Both estimates should be read against their standard errors (truth +2.00):

intervene_effect(health, A, X, [1, 2], setto([0, 0]); outcome = :quadratic,
                    propensity = :quadratic).effect
1.6206461342643763

Stochastic intervention: halve the prevalence

shift(0.5) removes each present exposure with probability 0.5, a modified treatment policy that depends on the natural value (truth +1.04):

intervene_effect(health, A, X, [1, 2], shift(0.5); estimator = :tmle)
Effect of an intervention on indicators (tmle, 5-fold cross-fitting); n = 2500
  g1: shift 1→0 with probability 0.5
  g0: natural course
  E[Y^g1] = 77.8502 (0.2567)   E[Y^g0] = 76.7012 (0.2548)
  ψ = 1.1490   S.E. 0.0960   95% CI [0.9608, 1.3371]   p = 0.0000
  overlap: min P(A_S = s | H) = 0.0054, max weight = 3.7

Interventions can also be compared with each other rather than with the natural course (truth: +2.00 − 1.04 = +0.96):

x = intervene_effect(health, A, X, [1, 2], setto([0, 0]); g0 = shift(0.5))
x.effect, x.se
(1.0834856852312527, 0.12537539793343794)

Targeted and custom interventions

subgroup restricts an intervention to part of the population. Preventing abuse and neglect only in families where the parents had at most 10 years of education (28% of the sample) has a true population effect of +0.81 points — 40% of the effect of universal prevention:

low_edu = a.parent_edu .<= 10
intervene_effect(health, A, X, [1, 2], subgroup(setto([0, 0]), low_edu))
Effect of an intervention on indicators (aipw, 5-fold cross-fitting); n = 2500
  g1: set to [0, 0] (subgroup)
  g0: natural course
  E[Y^g1] = 77.5446 (0.2776)   E[Y^g0] = 76.7012 (0.2548)
  ψ = 0.8434   S.E. 0.1335   95% CI [0.5818, 1.1051]   p = 0.0000
  overlap: min P(A_S = s | H) = 0.0054, max weight = 8.5

Any other intervention can be written as a transition matrix over the exposure patterns [0,0], [0,1], [1,0], [1,1] (row = natural pattern, column = pattern under the intervention) or as a rule q(s, a). Preventing abuse only, with neglect unchanged (true effect +1.29):

M = [1 0 0 0;     # [0,0] stays [0,0]
     0 1 0 0;     # [0,1] stays [0,1]
     1 0 0 0;     # [1,0] becomes [0,0]
     0 1 0 0]     # [1,1] becomes [0,1]
intervene_effect(health, A, X, [1, 2], Intervention("prevent abuse only", M))
Effect of an intervention on indicators (aipw, 5-fold cross-fitting); n = 2500
  g1: prevent abuse only
  g0: natural course
  E[Y^g1] = 78.0635 (0.2728)   E[Y^g0] = 76.7012 (0.2548)
  ψ = 1.3623   S.E. 0.1441   95% CI [1.0799, 1.6446]   p = 0.0000
  overlap: min P(A_S = s | H) = 0.0054, max weight = 7.5

Binary outcomes

With family = :binomial the outcome and TMLE fluctuation models are logistic, and the effect is a risk difference (truth −0.038, from 0.167 to 0.129):

b = intervene_effect(Float64.(a.depressed), A, X, [1, 2], setto([0, 0]);
                        family = :binomial, estimator = :tmle)
b.psi1, b.psi0, b.effect
(0.12959599778419675, 0.1632, -0.03360400221580326)

Joint inference

The influence-function contributions phi1 and phi0 are returned, so contrasts can be combined. For example, the standard error of the difference between the effects of preventing abuse only and neglect only (truth +0.41):

r1 = intervene_effect(health, A, X, [1, 2], Intervention("prevent abuse", (s, a) -> Float64(s == [0, a[2]])))
r2 = intervene_effect(health, A, X, [1, 2], Intervention("prevent neglect", (s, a) -> Float64(s == [a[1], 0])))
d = (r1.phi1 .- r1.phi0) .- (r2.phi1 .- r2.phi0)
r1.effect - r2.effect, std(d) / sqrt(n)
(0.3601657468017123, 0.1897834719219853)

Both results use the same folds (the same seed), which is what makes their contributions comparable observation by observation.

Part 3: the latent classes of the adversities

Part 2 intervened on single adversities. The questions about the latent family contexts the adversities form — for whom prevention matters most (intervene_within), whether a direct effect of the latent context could explain the effect away (intervene_latent_sensitivity), adjustment for the latent pattern of the other adversities (adjust = :classes), how the class model would classify post-intervention profiles (intervene_shares) and the effect of an intervention on a latent class outcome (intervene_latent_outcome) — are worked through, with outputs and interpretations, on Latent classes and interventions. The sensitivity analyses for Part 1 are intervene_membership_sensitivity (E-values, additive bias) and intervene_dif (measurement non-invariance by treatment).
