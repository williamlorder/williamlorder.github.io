Latent classes and interventions

This page is the core of the package: causal questions about latent classes when the intervention targets observed variables. Exposures such as childhood adversities co-occur in latent patterns (classes), but an intervention can only change specific exposures, never assign people to a class. The methods below connect the two: the effect of an intervention on a latent class outcome (intervene_latent_outcome), its effect within each latent class of the exposures (intervene_within), sensitivity to a direct effect of the latent class (intervene_latent_sensitivity), adjustment for the latent pattern of the other exposures (adjust = :classes), and the classification of post-intervention profiles (intervene_shares, descriptive); plus three extensions of intervene_membership (subgroups, unmeasured confounding, DIF).

All of them reuse the intervention estimators of Intervention estimators, which intervene on observed binary exposures A and adjust for H = (A_rest, X), the non-intervened exposures and the confounders.

What these methods answer

The setting. Childhood adversities co-occur: abuse rarely comes alone, and latent class analyses of ACEs repeatedly find a few patterns (low adversity, household dysfunction, maltreatment, high adversity) that are read as a latent family context. An intervention, however, targets specific adversities, not a class. The five methods below answer the questions that arise when a study intervenes on adversities and still wants to speak to the latent patterns. All outputs are real: validation/overview_examples.jl on ace_study (2,500 adults; the true effect of preventing abuse and neglect on past-year depression is a risk difference of −0.038) and programme (true class effects +0.179, −0.059, −0.120), run on the Nibi cluster (Slurm job 28116951, Julia 1.12.5, 16 threads); the full text is in validation/results/overview_examples.txt. Each block shows the printed output of the call above it (bootstrap progress lines omitted).

The calls below share

using LatentClassCausal
a = dataset("ace_study")
A = Matrix{Int}(a[:, r"^ace"])                         # ace1 abuse, ace2 neglect, ace3–ace8
X = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
dep = Float64.(a.depressed)
g = setto([0, 0])                                      # prevent abuse and neglect
sh = intervene_shares(A, X, [1, 2], g; K = 3)              # fits the 3-class model sh.model; bootstrap SEs

The fitted classes (P(adversity | class)): class 1 (67%) low adversity, class 2 (23%) household dysfunction (domestic violence, substance misuse, mental illness, separation ≈ 0.5, abuse 0.23), class 3 (10%) high adversity with maltreatment (abuse 0.83, neglect 0.54).

1. Does the intervention change a latent class outcome? intervene_latent_outcome

Question. Would a programme (or preventing an adversity) change membership in a latent class outcome — e.g. adult health-behaviour or wellbeing classes measured by several indicators? Why LCA. The outcome is a pattern across indicators; analysing each indicator separately loses it, and plugging in modal classes attenuates the effect (classification error). The shipped ACE data have no multi-indicator adult outcome, so the real example uses programme: participation in a school mental-health programme (the exposure, adjusted for five confounders) and 3 wellbeing classes from 8 items (Flourishing, Moderate, Distressed).

d = dataset("programme")
Y = d[:, [:low_mood, :worry, :sleep, :lonely, :hopeless, :enjoy, :confident, :friends]]
Xp = Matrix{Float64}(d[:, [:female, :age, :low_ses, :distress, :belonging]])
m = lca(Y, 3)                                          # outcome classes, no covariates
intervene_latent_outcome(m, reshape(Int.(d.programme), :, 1), Xp, [1], setto(1); g0 = setto(0))

2. For whom? intervene_within

Question. Is preventing abuse and neglect worth more for children from high-adversity families? Why LCA. "High-adversity family" is not one exposure but a pattern; the latent class (here with the confounders as covariates of class membership) defines the subgroups, and posterior weights avoid misclassifying people with ambiguous profiles.

3. Is the effect explained by the family context? intervene_latent_sensitivity

Question. The other adversities are only proxies for the family context; if that context raised depression risk directly, part of the "effect" of abuse and neglect would be confounding. How strong would it have to be? Why LCA. The family context is the latent class; its direct effect γ enters the bias only through how the intervention shifts the model's classification (Δₖ from intervene_shares).

intervene_latent_sensitivity(dep, A, X, [1, 2], g; model = sh.model, family = :binomial, target = 3)
Sensitivity of an intervention effect to a direct effect of the exposure class on Y
  g1: set to [0, 0]
  g0: natural course
  uncorrected ψ = -0.0341 (S.E. 0.0059); Δ_k = [0.058, 0.017, -0.075]
  tipping points in γ (class 3 vs the rest): ψ = 0 at 0.4523; 95% CI includes 0 from 0.2416
  bias(ψ) = Σ_k γ_k Δ_k; γ on the outcome scale (risk difference for binary Y).
  S.E.: joint bootstrap of ψ and Δ (200 replicates, class model refitted)

Interpretation. Only a direct effect of the high-adversity context of +0.45 on the risk of depression (over and above all eight adversities and the confounders) would explain the effect away, and +0.24 would make it non-significant — larger than the whole difference in depression between the classes (0.35 vs 0.13), so the conclusion that prevention helps is robust to this form of latent confounding. The interval uses the joint bootstrap of ψ̂ and Δ̂ (the default); with influence functions that hold the class model fixed the second tipping point would be an optimistic 0.29.

4. Adjusting for patterns instead of items: adjust = :classes

Question. With eight adversities some profiles are rare and the weights of AIPW become large; can the other adversities be summarised by their latent class? Why LCA. The classes of the six non-intervened adversities are the low-dimensional confounder summary; the intervened ones are never part of that model.

mr = lca(A[:, 3:8], 3; covariates = X)
for adj in (:exposures, :classes, :both)
    ra = intervene_effect(dep, A, X, [1, 2], g; family = :binomial, adjust = adj, adjust_model = mr)
    println(rpad(string(adj, ":"), 11), "effect = ", round(ra.effect; digits = 4), " (SE ", round(ra.se; digits = 4),
            "), min_pi = ", round(ra.min_pi; digits = 4), ", max_weight = ", round(ra.max_weight; digits = 1))
end
exposures: effect = -0.0341 (SE 0.0066), min_pi = 0.005, max_weight = 10.1
classes:   effect = -0.0352 (SE 0.0056), min_pi = 0.0048, max_weight = 3.0

Interpretation. The estimate barely moves (−0.034 to −0.035) while the largest weight falls from 10 to 3 and the SE by 15%: an appendix robustness check showing that the result does not hinge on extreme weights from rare adversity profiles. :classes assumes the classes carry all the confounding information of the other adversities; :both does not.

5. Connecting to the LCA literature: intervene_shares

Question. LCA papers report class sizes; what does the intervention imply for them? Why LCA, and what it is not. In the latent class model the family context generates the adversities, so preventing abuse does not change anybody's class. intervene_shares reports how the fitted model would classify the post-intervention adversity profiles.

intervene_shares(A, X, [1, 2], g; model = sh.model)        # bootstrap SEs (the default), B = 200

  1           0.733      0.674      0.058    0.007     [0.045, 0.072]
  2           0.247      0.230      0.017    0.024    [-0.030, 0.064]
  3           0.020      0.096     -0.075    0.025   [-0.125, -0.026]

  Shares of the model's classification of post-intervention profiles, not a causal
  effect on the latent class (the class generates the exposures). S.E.: bootstrap (200 replicates, class model refitted)

Interpretation. After prevention only 2% of profiles would look like the high-adversity pattern (now 9.6%), most moving to the low-adversity class: in the language of the ACE class literature the intervention would nearly empty the maltreatment-dominated class. This is a statement about classification, not about changing families. With lca_uncertainty = :none the standard errors would be conditional on the LCA estimates and between a half and an eighth of these bootstrap ones; that is why the bootstrap is the default.

How they combine in one paper

  1. Main effect: intervene_effect for an observed outcome (depression, ψ = −0.034), or intervene_latent_outcome when the outcome is itself a latent class.
  2. Heterogeneity: intervene_within — the benefit is concentrated in the high-adversity class, which suggests targeting.
  3. Robustness: intervene_latent_sensitivity — how strong a direct effect of the family context would have to be; in the appendix, adjust = :classes / :both to show the result does not depend on extreme weights.
  4. Connection to the LCA literature: intervene_shares — how the intervention would change the classification of adversity profiles (descriptive).

The exposure class model

intervene_within, intervene_shares and intervene_latent_sensitivity use a latent class model of all exposures in which the confounders predict class membership (one-step, lca(A, K; covariates = X)):

\[P(A = a, C = k \mid X) = \pi_k(X) \prod_{j=1}^{J} \rho_{jk}^{a_j} (1-\rho_{jk})^{1-a_j}, \qquad \pi_k(X) = \operatorname{softmax}_k(X'\beta).\]

The class C generates the exposures (C → A); it is a pre-exposure characteristic (for example a family context) and an intervention on A does not change it. The posterior at any profile, P(C = k | A = a, X) ∝ π_k(X) Π_j ρ_{jk}^{a_j}(1 − ρ_{jk})^{1−a_j}, can be evaluated at counterfactual profiles; at the observed profiles it is τᵢₖ = P(C = k | Aᵢ, Xᵢ). Pass K (the model is fitted inside, starts = (100, 20) by default, and its convergence check is reported) or a fitted model (its class labels are used throughout). The model must be right: local independence, covariates acting on class membership only (no direct X → A effects) and the right K.

Class-specific effects

\[\psi_k = E[Y^{g_1} - Y^{g_0} \mid C = k].\]

Identification. In addition to the assumptions of intervene_effect (consistency, Y^s ⫫ A_S | H, positivity, A_rest not affected by A_S), assume

\[Y^{g} \perp\!\!\!\perp C \mid A, X ,\]

the class carries no information about the potential outcomes beyond the exposures and the confounders (in particular, no direct effect of C on Y). Then

\[E[Y^g \mid C = k] = \frac{E\{1(C = k)\, E[Y^g \mid A, X, C]\}}{P(C = k)} = \frac{E\{\tau_k(A, X)\, E[Y^g \mid A, X]\}}{E\{\tau_k(A, X)\}}, \qquad E[Y^g \mid A, X] = \sum_s q_g(s \mid A_S)\,\mu(s, H),\]

the last step by Y^s ⫫ A_S | H. The estimator replaces E[Y^g | A, X] by the contributions φ:

\[\hat\psi_k = \frac{\sum_i \tau_{ik}(\phi_{1i} - \phi_{0i})}{\sum_i \tau_{ik}}, \qquad \text{IF}_{ik} = \frac{\tau_{ik}(\phi_{1i} - \phi_{0i} - \hat\psi_k)}{\bar\tau_k}.\]

Since Σ_k τᵢₖ = 1, the class-size weighted average Σ_k τ̄_k ψ̂_k is exactly the population effect of intervene_effect. Two caveats:

  • The estimator is not doubly robust: the residual term w(Y − μ̂) of AIPW/TMLE has mean zero against τ_k(A, X) only when the outcome model is correct (with a correct propensity but a wrong outcome model, the weights reproduce the post-intervention density, which evaluates τ at the wrong profile). Use a flexible outcome model (outcome = :quadratic). :ipw is not available for the same reason; :gformula has no influence-function SE.
  • Standard errors: by default (lca_uncertainty = :bootstrap, B = 200) the class model (classes aligned by align_classes) and the nuisance models are refitted on B resamples, in parallel over threads (the first replicate runs alone so that code is compiled before the threaded loop). lca_uncertainty = :none gives the influence-function SE above, which holds the class model and the nuisances fixed; in the simulation its median coverage was 0.91 (worst 0.64), against 0.97 for the bootstrap, and printing says so. The cost is dominated by the refits of the class model. By default (boot_starts = (30, 6)) each refit uses random starts, as in the simulation. Run time with B = 200, 8 threads, ace_study (n = 2500, 8 exposures, K = 3; Nibi cluster node): intervene_shares / intervene_within / intervene_latent_sensitivity take about 380 / 390 / 390 s; the cost grows roughly linearly with n, and B = 50 gives a quick look. boot_starts = :warm (one EM run from the full-sample estimates) takes about 75–80 s but understates the standard errors when classes are weakly separated (coverage as low as 0.71; see the Latent classes: simulation page), so use it only for exploration.

Post-intervention classification shares

Because C → A, "the effect of the intervention on class membership" is zero by construction. What the intervention changes is how the class model classifies the exposure profiles:

\[\pi_k^{g} = E\Big[\sum_s q_g(s \mid A_S)\, P(C = k \mid A_S = s, A_{rest}, X)\Big], \qquad \Delta_k = \pi_k^{g_1} - \pi_k^{g_0}.\]

Under the natural course π_k = E[P(C = k | A, X)] = P(C = k), the class sizes. intervene_shares reports π_k^{g1}, π_k^{g0} and Δ_k with δᵢₖ = Σ_s q(s | A_S,i, i) P(C = k | s, A_rest,i, Xᵢ) as per-person contributions. Its standard errors come from a bootstrap refitting the class model by default; with lca_uncertainty = :none they are the influence function of a mean with the class model held fixed, which covered only about half the time in the simulation, and the printout says "conditional on the LCA estimates; SEs too small". No outcome is needed. The labels in the output say what it is: the distribution of the model's classification of post-intervention profiles, not a causal effect on C. Δ_k is the input of the sensitivity analysis below.

Class-based adjustment

intervene_effect(Y, A, X, S, g; adjust = :classes, adjust_K = K) (or adjust_model = m) replaces A_rest in H by the posterior class probabilities of a latent class model of the non-intervened exposures only, with covariates X, entered as the probabilities τ_1, …, τ_{K−1} in both nuisance models (cross-fitting unchanged). adjust = :both keeps A_rest and adds the probabilities. (Probabilities rather than log-ratios: for binary items and linear covariate effects, log(τ_k/τ_K) = const + Σ_j a_j log-odds-ratio terms + X'β is exactly linear in (A_rest, X), so log-ratios would only restrict the linear index under :classes and be collinear with A_rest under :both.) The default adjust = :exposures is the original estimator and gives bit-identical results.

  • The class model must not include the intervened exposures: their posterior would be a function of the treatment, and adjusting for it would adjust away part of the effect.
  • Assumption: the classes carry the confounding information of A_rest, Y^s ⫫ A_S | τ(A_rest, X), X. This holds when A_rest confounds only through C (e.g. no non-intervened exposure affects Y directly). If some A_j affects Y directly, :classes can be biased and :both (or :exposures) is safer (in the simulation the bias of :classes was negligible in that case).
  • Motivation: positivity. With many binary exposures, P(A_S = s | A_rest, X) can be close to 0 for some profiles; K − 1 smooth summaries usually give larger minimum propensities. Compare min_pi and max_weight of the three choices.
  • Standard errors treat the class model as fixed; the g-formula bootstrap resamples the transformed covariates (the class model is not refitted).

Sensitivity to a direct class effect

If the class that generates the exposures also affects the outcome, H is only a proxy for the confounder C and the estimand of intervene_effect is biased. Model

\[E[Y \mid A_S, H, C] = \mu^*(A_S, H) + \gamma_C, \qquad \gamma_{\mathrm{ref}} = 0,\]

an additive class effect with no interaction, and assume exchangeability given the class, Y^s ⫫ A_S | H, C. Derivation of the bias. By consistency and exchangeability given C, E[Y^s | A_S, H, C] = E[Y | A_S = s, H, C] = μ*(s, H) + γ_C, so with Σ_s q_g(s | A_S) = 1

\[E[Y^g] = E\Big[\sum_s q_g(s\mid A_S)\{\mu^*(s,H) + \gamma_C\}\Big] = E\Big[\sum_s q_g(s\mid A_S)\mu^*(s,H)\Big] + \sum_k \gamma_k P(C = k).\]

The observed regression averages the class effect over the classes of people with profile (s, H): μ(s, H) = E[Y | A_S = s, H] = μ*(s, H) + Σ_k γ_k P(C = k | A_S = s, H). The observed-data functional ψ_obs(g) = E[Σ_s q_g(s | A_S) μ(s, H)] therefore equals

\[\psi_{obs}(g) = E[Y^g] + \sum_k \gamma_k\Big\{E\Big[\sum_s q_g(s\mid A_S) P(C=k \mid A_S = s, H)\Big] - P(C = k)\Big\} = E[Y^g] + \sum_k \gamma_k (\pi_k^{g} - \pi_k^{nat}),\]

and for the contrast (the P(C = k) terms cancel)

\[\operatorname{bias}(\psi) = \sum_k \gamma_k \Delta_k, \qquad \Delta_k = \pi_k^{g_1} - \pi_k^{g_0}.\]

Since Σ_k Δ_k = 0, the choice of reference class does not matter. P(C = k | s, H) is the posterior of the all-exposure class model with covariates at the counterfactual profile, exactly the quantity of intervene_shares.

intervene_latent_sensitivity returns ψ(γ) = ψ̂ − Σ_k γ_k Δ̂_k with its confidence interval over a grid of a scalar γ for one target class versus the rest (or multiples tγ of a vector); and the tipping points: γ* = ψ̂/Δ̂_target where the corrected effect is zero and the γ closest to 0 at which the confidence interval first includes zero (the root of (ψ̂ − γΔ̂)² = z²·se(γ)², a quadratic in γ). γ is on the outcome scale (points of Y; a risk difference for family = :binomial, where the additive model is an approximation). The variance of ψ̂ − tΔ̂_v (Δ̂_v = Σ_k v_k Δ̂_k for the direction v of γ) is Var(ψ̂) − 2t Cov(ψ̂, Δ̂_v) + t² Var(Δ̂_v), so the interval limits and tipping_ci solve a quadratic. Three ways to get the moments, reported as se_method:

  • intervene_latent_sensitivity(Y, A, X, S, g1; K | model, …) (the data method, default lca_uncertainty = :bootstrap): a joint bootstrap of ψ̂ and Δ̂ — each resample refits the class model and the nuisance models and recomputes both — so all three moments include the class-model uncertainty (:bootstrap).
  • intervene_latent_sensitivity(result, shares) with bootstrapped shares (the default of intervene_shares): Var(Δ̂_v) from the bootstrap draws, Var(ψ̂) and Cov(ψ̂, Δ̂_v) from the influence functions (φ1ᵢ − φ0ᵢ − ψ̂ and δ1ᵢₖ − δ0ᵢₖ − Δ̂_k) (:hybrid). The covariance ignores how the class-model estimates co-vary with ψ̂; use the data method when that matters.
  • intervene_latent_sensitivity(result, shares) with lca_uncertainty = :none shares: influence functions only (:conditional). Because the conditional SE of Δ̂ is far too small and enters multiplied by γ, intervals and tipping_ci are then optimistic, increasingly so at large |γ| (ACE example: 0.29 instead of 0.24).

tipping_zero does not depend on the SE. result must come from :aipw, :tmle or :ipw (influence-function contributions).

Latent class outcome

intervene_latent_outcome(m, A, X, S, g1; g0) estimates Δ_k = P(C^{g1} = k) − P(C^{g0} = k) for a class C measured by a separate model m (fitted without covariates; e.g. adult health-behaviour classes). As in intervene_membership, each class indicator is replaced by its BCH pseudo-outcome Zᵢₖ = (D⁻¹)[ĉᵢ, k], with D the classification-error matrix and ĉ the modal class, and the intervention estimator is applied to every column. Because the Gaussian working models are least squares, the contributions are linear in Z, so the contributions for the pseudo-outcomes are those of the modal indicators 1(ĉ = j) times D⁻¹; the derivative of ū'D⁻¹ with respect to D and the influence function of vec(D) (sampling of D and its dependence on the measurement parameters through the posteriors) give the standard errors, as in intervene_membership. With one exposure, :ipw and setto(1) versus setto(0) it reproduces intervene_membership(m, A, X; estimator = :ipw_bch) exactly (a test checks this).

Assumptions: those of intervene_effect for the class indicator as outcome, and a correctly specified, identified and measurement-invariant outcome model: the item-response probabilities given C do not depend on the exposures or the confounders (no differential item functioning, DIF). Under DIF the pseudo-outcomes are biased.

Extensions of intervene_membership

Subgroups. intervene_subgroup(m, A, X, mask) estimates Δ_k(G) = P(C(1) = k | G) − P(C(0) = k | G) by weighting the AIPW contributions with 1(i ∈ G) (Hájek weights within G for :ipw_bch); the nuisance models use the whole sample and the measurement-model terms are included in the standard error. mask must be defined by pre-treatment variables. An all-true mask reproduces intervene_membership.

Unmeasured confounding. intervene_membership_sensitivity(r; bias, target) uses the additive bias model Δ̂_k → Δ_k + b_k with Σ_k b_k = 0 (both the observed-data functional and the causal effects sum to zero over classes), in probability units: corrected Δ_k − b_k with the same standard error, the tipping bias b_k = Δ̂_k and the bias at which the interval first includes zero, Δ̂_k ∓ z·SE_k, and a curve over b for one class. It also reports E-values (VanderWeele & Ding 2017) for RR_k = P(C(1) = k)/P(C(0) = k): 1(C = k) is a binary outcome with these risks, so the bounding factor argument applies to its causal risk ratio given X (provided measurement is invariant). E = RR + √(RR(RR − 1)) (RR → 1/RR if below 1); for the confidence limit closer to 1, with the log-RR interval from the delta method and Cov(ψ̂1, ψ̂0) = (SE₁² + SE₀² − SE_Δ²)/2.

Differential item functioning. intervene_dif(m, Y, A, X) fits two multigroup models with group = A: full invariance and no (or partial, invariance = [...]) invariance, tests them with the scaled χ² difference test of compare_models, and recomputes Δ_k with treatment-specific measurement: BCH pseudo-outcomes Zᵢ = (D_{Aᵢ}⁻¹)[ĉᵢ, :] with modal classes and classification-error matrices computed within each treatment group of the non-invariant model (classes aligned to m by the untreated group's profiles), plugged into the same estimator (:aipw with arm-wise linear regressions of Z on X as outcome model, or :ipw_bch; fixed-Z standard errors). Printing warns when DIF is significant; without significant DIF the change is noise (e.g. −0.06 with p = 0.53 for programme).

Example

using LatentClassCausal
a = dataset("ace_study")          # 8 childhood adversities, confounders, adult health
A = Matrix{Int}(a[:, r"^ace"])
X = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
health = Float64.(a.health)
g = setto([0, 0])                 # prevent abuse (ace1) and neglect (ace2)

sh = intervene_shares(A, X, [1, 2], g; K = 3)                    # fit the 3-class model once
ce = intervene_within(health, A, X, [1, 2], g; model = sh.model, outcome = :quadratic)
ce.effect                         # effect within each adversity class
r  = intervene_effect(health, A, X, [1, 2], g)
s  = intervene_latent_sensitivity(r, sh; target = argmax(sh.pi0 .- sh.pi1))
s.tipping_zero, s.tipping_ci      # direct class effect needed to explain ψ away
rc = intervene_effect(health, A, X, [1, 2], g; adjust = :both, adjust_K = 3)
(r.min_pi, rc.min_pi)             # overlap with exposure vs exposure + class adjustment
