Datasets

Two simulated example datasets ship with the package (folder datasets/); the full codebook, including every parameter of the data-generating processes and the true effects, is datasets/README.md, and the generating script is datasets/generate.jl. Both are dedicated to the public domain (CC0 1.0); no real person is described. The R package latentclasscausal ships the same data (data(programme), data(ace_study)).

dataset(name) (re-exported from LatentMixtures.jl) returns a small Tables.jl column table: d.age is a column, d[:, [:age, :female]] a sub-table, Matrix{Float64}(...) a matrix, DataFrame(d) works with DataFrames.jl.

programme

2,000 students. Outcome: eight binary wellbeing items six months after a school-based mental-health promotion programme — low_mood, worry, sleep (trouble sleeping), lonely, hopeless, enjoy (enjoyed everyday activities), confident (able to handle problems), friends (has someone to talk to) — generated by three latent classes (Flourishing, Moderate, Distressed). Treatment: programme (0/1, 41% took part; participation targeted at distressed students). Confounders: female, age (13–16), low_ses, distress (baseline distress, z-score), belonging (school belonging).

True effects of the programme on the class probabilities (sample averages): Δ = +0.179 (Flourishing), −0.059 (Moderate), −0.120 (Distressed); the naive comparison of participants and non-participants is close to zero.

ace_study

2,500 adults. Exposures: eight adverse childhood experiences ace1 (abuse), ace2 (neglect), ace3 (sexual abuse), ace4 (domestic violence), ace5 (household substance misuse), ace6 (household mental illness), ace7 (parental separation), ace8 (incarcerated household member), generated by a latent family context. Confounders: age (25–64), female, parent_edu (parents' years of education). Outcomes: health (self-rated health today, 0–100) and depressed (past year, 0/1), which depend on ace1, ace2 (with an interaction), ace6 and the confounders.

Raw files often code missing values as -999; the estimators need complete data, so convert such codes to missing (e.g. [x == -999 ? missing : x for x in A]) and decide on complete cases or imputation before estimation.

dataset(name) and datasets() are documented in LatentMixtures.jl (its API reference, "Example datasets"); this package registers its data with them when it is loaded.
