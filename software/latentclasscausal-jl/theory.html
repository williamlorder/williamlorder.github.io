Doubly robust estimation of treatment effects on latent class membership

Working notes for the method implemented in LatentClassCausal.jl. Status: derivations are complete at the level of proof sketches; the simulation study in validation/ checks the claims numerically. Claims of novelty are "to our knowledge" and based on the literature check listed in §8.

1. Setting and estimand

For individual i we observe confounders Xᵢ, a binary treatment Aᵢ ∈ {0, 1} (e.g. a schooling intervention) and indicators Yᵢ = (Yᵢ₁, …, Y_iJ) of a latent class variable Cᵢ ∈ {1, …, K} (e.g. adult mental-health profiles). Potential classes Cᵢ(a) are the classes the person would have under treatment a. The estimand is the effect of the treatment on the class distribution,

Δₖ = P(C(1) = k) − P(C(0) = k), k = 1, …, K, with Σₖ Δₖ = 0.

Write ψₖ(a) = P(C(a) = k), e(x) = P(A = 1 | X = x), and μₖ(a, x) = P(C = k | A = a, X = x).

2. Assumptions

  • A1 (consistency). C = C(A).
  • A2 (positivity). 0 < e(x) < 1 for all x in the support of X.
  • A3 (conditional exchangeability). C(a) ⫫ A | X for a = 0, 1.
  • A4 (measurement model and invariance). The indicators follow a latent class model f(y | c; θ) with local independence (or the covariance structure that was fitted), and the measurement model is invariant with respect to the treatment and confounders: Y ⫫ (A, X) | C. Equivalently, there is no differential item functioning (DIF) with respect to A or X.
  • A5 (identifiability of the measurement model). θ and the class proportions are identified, and the classification-error matrix D (below) is invertible.

A1–A3 are the usual assumptions for the effect of A on any outcome; they would identify Δₖ if C were observed. A4–A5 are what makes a latent outcome usable.

3. Pseudo-outcomes that correct for classification error

Let ĉ(y) be the modal assignment rule of the fitted measurement model (the class with the largest posterior probability given y; any fixed rule works). Define

D_kj = P(ĉ(Y) = j | C = k),

the classification-error matrix. Under A4, ĉ(Y) depends on (A, X) only through C, so P(ĉ = j | C = k, A, X) = D_kj for all (A, X). The BCH pseudo-outcome is

Zₖ = (D⁻¹)[ĉ(Y), k].

Lemma 1 (unbiased proxy). Under A4–A5, E[Zₖ | C = c, A, X] = 1(c = k), hence E[Zₖ | A, X] = μₖ(A, X).

Proof. E[Zₖ | C = c, A, X] = Σⱼ P(ĉ = j | C = c, A, X) (D⁻¹)_jk = Σⱼ D_cj (D⁻¹)_jk = (D D⁻¹)_ck = 1(c = k). Average over C given (A, X). ∎

Zₖ can be negative or exceed one; only its conditional mean is a probability. Rows of D sum to one, so rows of D⁻¹ do too and Σₖ Zₖ = 1.

D is estimated from the fitted model by D̂_kj = Σᵢ p̂ᵢₖ 1(ĉᵢ = j) / Σᵢ p̂ᵢₖ, with p̂ᵢₖ the posterior class probabilities. This is consistent under A4–A5 because E[p_k(Y) 1(ĉ(Y) = j)] = P(C = k, ĉ = j) when the posterior is computed from the true model.

4. Identification

Proposition 1. Under A1–A5,

ψₖ(a) = E[μₖ(a, X)] = E[ 1(A = a) Zₖ / P(A = a | X) ].

Proof. By A3 and A1, P(C(a) = k | X) = P(C(a) = k | A = a, X) = P(C = k | A = a, X) = μₖ(a, X); average over X. By Lemma 1, μₖ(a, X) = E[Zₖ | A = a, X], so the usual IPW identity applies with Zₖ in place of an observed outcome (A2). ∎

The first form underlies outcome regression (g-computation) with the latent class regression μₖ(a, x) estimated by the three-step ML method (Vermunt 2010), the second the BCH-weighted IPW estimator (cf. Clouth et al. 2022 for IPW in the three-step approach).

5. The AIPW estimator and double robustness

With working models ẽ(x) for the propensity and μ̃ₖ(a, x) for the latent class regression, define for a = 1 (a = 0 analogous)

φₖ¹(O; ẽ, μ̃, D) = μ̃ₖ(1, X) + A (Zₖ − μ̃ₖ(1, X)) / ẽ(X),

and ψ̂ₖ(1) = Pₙ φₖ¹, Δ̂ₖ = ψ̂ₖ(1) − ψ̂ₖ(0). Nuisances are fitted by K-fold cross-fitting.

Proposition 2 (double robustness). Under A1–A5 with D known (or consistently estimated), E[φₖ¹(O; ẽ, μ̃, D)] = ψₖ(1) if either ẽ = e or μ̃ₖ(1, ·) = μₖ(1, ·).

Proof. E[φₖ¹] − ψₖ(1) = E[ (e(X)/ẽ(X) − 1)(μₖ(1, X) − μ̃ₖ(1, X)) ], using E[A Zₖ | X] = e(X) μₖ(1, X) (Lemma 1 and A1–A3). The product vanishes if either factor does. ∎

With cross-fitting, √n(Δ̂ₖ − Δₖ) is asymptotically normal when ‖ẽ − e‖ ‖μ̃ − μ‖ = oₚ(n^{-1/2}) (the standard rate condition; Chernozhukov et al. 2018), provided D and θ are estimated at √n rate (they are, by parametric ML).

What double robustness does not cover. Proposition 2 protects against misspecification of ẽ or μ̃, not of the measurement model. If A4 fails, Lemma 1 fails and no choice of nuisance models restores consistency (§6).

6. Measurement non-invariance (DIF)

Suppose instead P(ĉ = j | C = c, A, X) = D_cj(A, X), while the estimator uses a pooled matrix D (the probability limit of D̂). Then

E[Zₖ | A, X] = Σ_c μ_c(A, X) [D(A, X) D⁻¹]_ck =: μ*ₖ(A, X),

and with either nuisance correctly specified for the observed-data regression E[Zₖ | A, X], the AIPW estimator converges to

Δ*ₖ = E[μ*ₖ(1, X)] − E[μ*ₖ(0, X)].

Bias. Δ*ₖ − Δₖ = E[ Σ_c μ_c(1, X) ([D(1, X) D⁻¹]_ck − 1(c = k)) ] − E[ Σ_c μ_c(0, X) ([D(0, X) D⁻¹]_ck − 1(c = k)) ].

It is zero when D(a, x) = D for all (a, x) (A4) and generally non-zero otherwise.

Counterexample (bias with a null effect). Let K = 2, no confounding, μ_c(a, x) = 1/2 for both arms (Δ₁ = 0), and let treatment shift the misclassification: D(1) = [[0.9, 0.1], [0.3, 0.7]], D(0) = [[0.7, 0.3], [0.1, 0.9]]. The pooled D is the average [[0.8, 0.2], [0.2, 0.8]]. Then E[Z₁ | A = 1] = ½(0.9 + 0.3)·(4/3) − ½(0.1+0.7)·(1/3) = 0.8 − 0.133 = 0.667 and E[Z₁ | A = 0] = ½(0.7 + 0.1)·(4/3) − ½(0.3 + 0.9)·(1/3) = 0.533 − 0.2 = 0.333, so Δ*₁ = 0.333 ≠ 0 although both nuisance models are correct. (D⁻¹ = (1/0.6)[[0.8, −0.2], [−0.2, 0.8]].)

Invariance is needed with respect to X as well as A: if D depends on X and X affects A, E[Zₖ | A, X] is again distorted. Remedies (not implemented): measurement models with DIF terms (A or X as direct effects on items), multi-group measurement models with partial invariance, or sensitivity analysis over D(a, x).

7. Influence function and variance

Write the estimating equations stacked as (θ, D, ψ):

  1. measurement model: Σᵢ s(Yᵢ; θ) = 0 (scores of the LCA/LPA likelihood);
  2. classification error: Σᵢ pₖ(Yᵢ; θ) [1(ĉᵢ = j) − D_kj] = 0, with the assignment rule ĉ held fixed (it is a step function of θ, so it does not contribute to first order);
  3. AIPW: Σᵢ [φₖᵃ(Oᵢ; ẽ, μ̃, D) − ψₖ(a)] = 0.

The nuisance estimating equations need not be stacked: under cross-fitting and the rate condition, φ is Neyman-orthogonal with respect to (e, μ). The influence function of Δ̂ₖ is therefore

IFᵢ = φᵢ(Δ) + G_D · IF_D,ᵢ,

with G_D = ∂Pₙφ/∂vec(D) (computed by automatic differentiation through Z = D⁻¹[ĉ, ·]),

IF_D,ᵢ(k, j) = pᵢₖ (1(ĉᵢ = j) − D_kj) / π̄ₖ + (∂D/∂θ) IF_θ,ᵢ, IF_θ,ᵢ = n · I(θ)⁻¹ s(Yᵢ; θ),

π̄ₖ = Pₙ pₖ and I(θ) the observed information. The variance estimate is Pₙ IF² / n. The implementation also reports se_fixed, which omits the second term (θ and D treated as known), to show how much the measurement step contributes.

8. Relation to existing work

  • Lanza, Coffman & Xu (2013, SEM) — causal inference with a latent class outcome via propensity-score matching and inverse propensity weighting in a one-step LCA.
  • Clouth, Pauws, Mols & Vermunt (2022, Advances in Data Analysis and Classification) — IPW combined with bias-adjusted three-step LCA for a latent class outcome.
  • Bray, Dziak, Patrick & Lanza (2019, Prevention Science); Lê, Clouth & Vermunt (2025, MBR; online 2024) — latent class exposures (a different estimand).
  • Bakk & Vermunt (2016); Vermunt (2010) — BCH and ML three-step corrections.

To our knowledge (Semantic Scholar searches, November 2026), an augmented, cross-fitted doubly robust estimator with an influence function that includes the measurement step, together with the invariance condition under which double robustness holds, has not been published for latent class outcomes. This should be re-checked before submission.

9. Open questions

  • Efficiency: AIPW with BCH pseudo-outcomes is not the efficient influence function for the latent-outcome model (which would use the full likelihood of Y given A, X). The efficiency loss relative to a correctly specified one-step model is an open question.
  • Low entropy: D close to singular inflates Zₖ and the variance (reported as the pseudo-outcome range).
  • Partial invariance and continuous treatments.

10. Simulation evidence (Nibi, 500 replications per cell)

Full tables: validation/results/summary.md (round 1) and summary2.md (double robustness design). Class 1, Δ₁ ≈ 0.22.

Classification-error correction matters. With correct nuisance models (entropy 0.74, n = 4000), AIPW, IPW-BCH and OR are unbiased (|bias| ≤ 0.001, coverage 0.94–0.96), while IPW of modal classes is biased by −0.034 (coverage 0.51) and AIPW with posterior probabilities by −0.055 (coverage 0.04). At low entropy (0.41) the uncorrected estimators are biased by −0.10 to −0.13; the corrected ones show finite-sample bias at n = 1000 (−0.029, coverage 0.91) that vanishes by n = 4000 (−0.008, coverage 0.95).

The flexible propensity model produces extreme weights: at n = 1000 with a wrong class regression the AIPW estimates are heavy-tailed (SD 0.30 against a mean SE of 0.084), so weight truncation (trim) or larger samples are advisable when propensities approach 0 or 1.

Measurement non-invariance (DIF) biases every corrected estimator (+0.04; coverage 0.42 at n = 4000), as Proposition 2 does not cover the measurement model (§6). (Modal-class IPW happens to be nearly unbiased in this design because two errors cancel.)

Variance. The influence-function SE agrees with the full-refit bootstrap SE (0.0396 vs 0.0403; 0.0364 vs 0.0366; 0.0375 vs 0.0380 for the three classes at n = 1000). In these designs the measurement-step correction changes the SE only in the third decimal (se vs se_fixed); it matters more at low entropy (coverage 0.91 vs 0.88 at n = 1000).
