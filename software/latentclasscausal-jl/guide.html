Function guide

This page explains how to use each of the nine intervene_* functions: what question it answers, when it is the right tool, what data it needs, which arguments matter, a complete example on the shipped data, how to read and report every number it prints, and which assumption each sensitivity tool addresses. The theory behind the estimators is on the pages Latent classes and interventions, Treatment effects on latent classes and Intervention estimators.

All outputs are real: they come from docs/guide_outputs/guide_examples.jl, run on the Nibi cluster (Julia 1.12.5, 16 threads); the raw log is docs/guide_outputs/out/guide_examples.txt (bootstrap progress lines are omitted here). The code is meant for the REPL, which displays the value of each call; in a script wrap it in display(...). Bootstrap run times quoted below are from that run; they vary with the cluster node (an earlier run of the same code took 200–225 s). The two simulated datasets have known effects (see Datasets): programme (true effects of the programme on the three wellbeing classes +0.179, −0.059, −0.120) and ace_study (preventing abuse and neglect: true effect on depression −0.038, on self-rated health +2.00).

Which function answers my question?

First ask where the latent classes are: are they the outcome (people are classified after the treatment, from outcome indicators), or are they formed by the exposures (the classes summarise co-occurring exposures, such as childhood adversities, and the outcome is an observed variable)?

Your questionLatent classes areFunction
Does a binary treatment change the probability of belonging to each class?the outcomeintervene_membership
... within a subgroup defined before treatment?the outcomeintervene_subgroup
How strong would unmeasured confounding have to be to explain that effect away?the outcomeintervene_membership_sensitivity
Does the measurement of the classes differ between treated and untreated (DIF)?the outcomeintervene_dif
Would an intervention on one or several binary exposures (set, halve, target) change membership in a latent class outcome?the outcomeintervene_latent_outcome
What is the effect of intervening on some exposures on an observed outcome?(none needed)intervene_effect
... adjusting for the latent pattern of the other exposures instead of each one?formed by the other exposuresintervene_effect(...; adjust = :classes)
For whom? How large is that effect within each latent class of the exposures?formed by the exposuresintervene_within
How would the class model classify the post-intervention exposure profiles? (descriptive)formed by the exposuresintervene_shares
Could the latent class of the exposures affect the outcome directly and confound the effect?formed by the exposuresintervene_latent_sensitivity

The same decision as a sequence of questions:

  1. Is the outcome a latent class?
    • Yes, and the treatment is one binary variable → intervene_membership; then intervene_membership_sensitivity and intervene_dif for the assumptions, intervene_subgroup for heterogeneity.
    • Yes, and the "treatment" is an intervention on one or more binary exposures (static, stochastic or targeted) → intervene_latent_outcome.
  2. Is the outcome observed and the exposures binary? → intervene_effect for the population effect. If the exposures form latent classes:
    • effect within each class → intervene_within;
    • could the class confound the effect → intervene_latent_sensitivity;
    • extreme weights from rare exposure profiles → adjust = :classes or :both;
    • what the intervention implies for the class sizes reported in an LCA paper → intervene_shares (a statement about classification, not a causal effect).

The status of each estimator (Established, Established-with-adaptation, Experimental) is in the Method status table on the home page; it is repeated in each section below.

1. Treatment effect on class membership: intervene_membership

Question it answers. Does a binary treatment change which latent class people belong to? For each class $k$ it estimates $\Delta_k = P\{C(1) = k\} - P\{C(0) = k\}$, the difference between the share of class $k$ if everyone were treated and if no one were. Example: does taking part in a school mental-health programme raise the probability of being in the Flourishing wellbeing class six months later?

When to use it. The treatment is a single 0/1 variable that precedes the indicators; the classes are measured after treatment by their own indicators; the confounders are observed. When not. If the "treatment" is an intervention on several exposures, or a stochastic or targeted policy, use intervene_latent_outcome. If the classes are formed by the exposures themselves (the classes precede the treatment), the question is about intervene_within or intervene_shares. The default estimator is only valid if the measurement model is invariant across treatment groups and confounders (no differential item functioning, DIF).

Data you need.

  • m: a LatentMixtureModel from lca or lpa fitted to the outcome indicators only, without covariates and without sampling weights, K ≥ 2.
  • A: a 0/1 vector, one entry per row of the data m was fitted to (m.ninput rows, same order), observed on every analysed row.
  • X: a numeric vector or m.ninput × p matrix of confounders (no intercept column), complete on the analysed rows.

Key arguments.

argumentdefaultwhen to change it
estimator:aipw:ipw_bch as a robustness check (needs a correct propensity model); :or (no standard error); :ipw_modal, :aipw_posterior, :naive only as deliberately biased comparators
propensity:linear:quadratic, or a learner (:lasso, :forest, :boost, :superlearner, ...) when the treatment may depend non-linearly on the confounders
outcome:linearthe latent class regression; :quadratic or a learner, as for propensity

  • Convergence check: the best log-likelihood was replicated by all 20 stage-2 starts and Newton steps found no better solution, so the 3-class solution is a stable maximum.   • propensity range [0.019, 0.923]: the smallest and largest estimated P(A = 1 | X). Values near 0 or 1 mean extreme weights (consider trim).

2. Interventions on exposures, latent class outcome: intervene_latent_outcome

Question it answers. Would an intervention on one or more binary exposures change membership in a latent class outcome? $\Delta_k = P(C^{g_1} = k) - P(C^{g_0} = k)$, where $C$ is measured by a separate measurement model. Example: if every student took part in the programme, how would the shares of the wellbeing classes change, compared with no one taking part, or with current take-up?

When to use it. The outcome is a pattern across several indicators (a latent class), and the intervention acts on observed binary exposures: setting them (setto), reducing their prevalence (shift) or targeting a subgroup (subgroup). Modal class assignment would attenuate the effect; the BCH pseudo-outcomes correct for classification error. When not. If the outcome is an observed variable, use intervene_effect. The measurement model of the outcome classes must not depend on the exposures or confounders.

Data you need.

  • m: the outcome measurement model, fitted without covariates (and without weights) to the m.ninput rows.
  • A: an m.ninput × J integer 0/1 matrix of exposures (a single exposure as reshape(a, :, 1)).
  • X: confounders, m.ninput rows.
  • S: the intervened columns of A; g1 (and g0): the interventions.

Key arguments.

argumentdefaultwhen to change it
g0natural()setto(0) for "everyone vs no one"; the default gives "intervention vs the observed course"
estimator:aipw:tmle; :ipw; :gformula (no standard errors here)
outcome, propensity:linear:quadratic or a learner
folds, seed5, 1as in intervene_effect
learners, boundnothing, 0.01as in intervene_effect

  • entropy, pseudo-outcome range: as in intervene_membership.
  • overlap: min π = 0.0190, max weight = 25.6: the smallest probability of the exposure value an intervention requires, and the largest weight; a weight of 25.6 means one student stands in for about 26 others.

Assumptions and checks. Those of intervene_effect with the class indicator as outcome (consistency, exchangeability given the other exposures and X, positivity), plus a correctly specified, identified and measurement-invariant outcome model: the item-response probabilities given the class must not depend on the exposures or the confounders. With a single binary exposure, intervene_dif tests invariance by exposure. Status: Experimental.

Related functions. intervene_membership (single binary treatment, with its sensitivity tools), intervene_effect (observed outcome).

3. Effects within each exposure class: intervene_within

Question it answers. For whom does an intervention matter? It estimates $\psi_k = E[Y^{g_1} - Y^{g_0} \mid C = k]$, the effect within each latent class $C$ of a class model of all the exposures. Example: is preventing abuse and neglect worth more for adults who grew up in a high-adversity family context?

When to use it. The exposures co-occur in latent patterns (classes), the intervention targets specific exposures, and you want the effect by pattern. The class is a pre-exposure characteristic that the intervention does not change. When not. If the class could affect the outcome directly (over and above the exposures and confounders), $\psi_k$ is biased: check with intervene_latent_sensitivity. For a latent class outcome, use intervene_latent_outcome.

Data you need.

  • Y: outcome vector (continuous, or 0/1 with family = :binomial), complete.
  • A: n × J 0/1 exposure matrix (all exposures, including the intervened ones), complete.
  • X: confounders; they are covariates of class membership in the class model.
  • S, g1, g0: as in intervene_effect.
  • model (or K): the class model lca(A, K; covariates = X) of all columns of A, fitted to the same rows.

Key arguments.

argumentdefaultwhen to change it
model / K—pass a fitted model to fix the class labels and reuse it across functions
estimator:aipw:tmle or :gformula (:ipw is not available)
outcome:linear:quadratic or a learner: ψₖ is not doubly robust, so check it
propensity, folds, seed, learners, boundas intervene_effect
family:gaussian:binomial for a 0/1 outcome (ψₖ is a risk difference)

4. Post-intervention classification shares: intervene_shares

Question it answers. How would the latent class model of the exposures classify the exposure profiles an intervention produces? $\pi_k^{g} = E[\sum_s q_g(s \mid A_S)\, P(C = k \mid A_S = s, A_{rest}, X)]$ and $\Delta_k = \pi_k^{g_1} - \pi_k^{g_0}$. Example: LCA studies of childhood adversity report class sizes; after preventing abuse and neglect, how many profiles would still look like the high-adversity pattern?

When to use it. To connect an intervention to the class sizes reported in the LCA literature, and to obtain the Δₖ that drive the bias in intervene_latent_sensitivity. No outcome is needed. When not. As a causal effect on class membership: in the class model the class generates the exposures ($C \to A$), so preventing abuse does not change anybody's class. The result is a descriptive statement about classification.

Data you need. A, X, S, g1 (and g0) as in intervene_within; the class model model (or K). No Y.

Key arguments.

argumentdefaultwhen to change it
model / K—pass the same fitted model as for intervene_within

lca_uncertainty:bootstrap:none only for exploration (SEs far too small)
B, seed200, 1B = 50 for a quick look
starts, boot_starts(100, 20), (30, 6)as in intervene_within

5. The intervention estimators: intervene_effect

Question it answers. What would the mean outcome be under a hypothetical intervention on some binary exposures, compared with another intervention or the observed course? $\psi = E[Y^{g_1}] - E[Y^{g_0}]$, adjusting for the other exposures and the confounders. Example: how much lower would past-year depression be if childhood abuse and neglect were prevented?

When to use it. For the population effect of an intervention on observed binary exposures, static (setto), stochastic (shift), targeted (subgroup) or user-defined (Intervention). It is also the engine of intervene_within, intervene_latent_sensitivity and intervene_latent_outcome. When not. If the outcome is a latent class, use intervene_latent_outcome (several exposures) or intervene_membership (one binary treatment). If some non-intervened exposures are affected by the intervened ones, they are mediators and adjusting for them changes the estimand.

Data you need.

  • Y: outcome (continuous, or 0/1 with family = :binomial), complete.
  • A: n × J 0/1 exposure matrix, complete. S: the 1 to 6 columns to intervene on; the others are adjusted for.
  • X: confounders (vector or n × p matrix), complete, no intercept.
  • g1 (and g0): Interventions.

6. Sensitivity to a direct class effect: intervene_latent_sensitivity

Question it answers. The other exposures are only proxies for the latent context that generates them (the family context). If that context raised the outcome directly, part of the "effect" of the intervened exposures would be confounding. How strong would that direct effect $\gamma$ have to be to explain the effect away? Under an additive class effect the bias is $\sum_k \gamma_k \Delta_k$ with the Δₖ of intervene_shares, and the corrected effect is $\psi(\gamma) = \hat\psi - \sum_k \gamma_k \hat\Delta_k$.

When to use it. After intervene_effect or intervene_within whenever the exposures form latent classes that might also act on the outcome. When not. For unmeasured confounding of a single treatment and a latent class outcome, use intervene_membership_sensitivity.

Data you need. The data of intervene_effect (Y, A, X, S, g1, g0) and the class model of all exposures (model or K). The two-argument form takes an InterventionResult (:aipw, :tmle or :ipw) and the ClassSharesResult for the same data and interventions.

Key arguments.

argumentdefaultwhen to change it
target1the class whose direct effect is the worry; e.g. argmax(sh.pi0 .- sh.pi1)
gammanothinga vector of K class effects (outcome scale; reference class 0) for a specific scenario; the grid is then over multiples tγ
gridnothingvalues of γ (or t); the default covers both tipping points
level0.95confidence level
lca_uncertainty, B:bootstrap, 200data method: joint bootstrap of ψ̂ and Δ̂; :none holds the class model fixed (optimistic)
estimator, outcome, propensity, family, folds, seed, starts, boot_startsas intervene_effect / intervene_shares

7. Unmeasured confounding of intervene_membership: intervene_membership_sensitivity

When to use it. After every intervene_membership analysis of observational data. When not. For interventions on exposures that form classes, use intervene_latent_sensitivity.

8. Measurement non-invariance by treatment: intervene_dif

Question it answers. Is the measurement of the latent classes the same for treated and untreated? The BCH correction of intervene_membership assumes it is (no differential item functioning). The function fits two multigroup latent class models with group = A, full invariance and no (or partial) invariance, compares them with the scaled χ² difference test, and recomputes Δₖ with treatment-specific classification errors.

When to use it. With every intervene_membership analysis, and whenever the treatment could change how people answer the items rather than (or as well as) which class they are in. When not. It is a diagnostic, not a correction to report by default: the non-invariant Δₖ is noisy and meaningful only when the classes keep the same substantive meaning in both groups.

Data you need. m (the measurement model of intervene_membership); Y (the indicator data m was fitted to, same rows and columns); A (0/1 vector) and X.
