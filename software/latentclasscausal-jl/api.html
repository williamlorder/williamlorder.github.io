Treatment effects on latent class membership

LatentClassCausal.intervene_membership — Function
intervene_membership(m, A, X; estimator = :aipw, propensity = :linear, outcome = :linear,
           folds = 5, trim = 0.0, seed = 1, learners = nothing, bound = 0.01) -> LCCResult

Estimate the causal effect of a binary treatment A on latent class membership, Δₖ = P(C(1) = k) − P(C(0) = k) for k = 1, …, K, adjusting for confounders X, with the latent class variable C measured by the fitted mixture model m. The default estimator is augmented inverse probability weighting (AIPW) of bias-corrected (BCH) pseudo-outcomes Zᵢₖ = (D⁻¹)[ĉᵢ, k], where ĉᵢ is the modal class of row i and D[k, j] = P(ĉ = j | C = k) the classification-error matrix of m. It is doubly robust: consistent if either the propensity score P(A = 1 | X) or the latent class regression P(C = k | A, X) is correctly specified, provided the measurement model holds and is invariant across A and X. Nuisance models are cross-fitted and standard errors come from an influence function that also propagates the estimation error of the measurement model.

How to use

  1. Fit the measurement model to the outcome indicators only, without covariates (m = lca(items, K) or lpa), choose K and check convergence(m) before any causal step.
  2. Give the treatment as a 0/1 vector and the confounders as a numeric matrix (no intercept), in the row order of the data m was fitted to.
  3. Run r = intervene_membership(m, A, X) (AIPW, 5-fold cross-fitting) and read Δₖ, its standard error and the diagnostics in the printout (entropy, pseudo-outcome range, propensity range).
  4. Check the nuisance models: propensity = :quadratic, outcome = :quadratic, a learner, trim = 0.01, or estimator = :ipw_bch.
  5. Probe what the data cannot check: intervene_membership_sensitivity (unmeasured confounding) and intervene_dif (non-invariant measurement); for heterogeneity, intervene_subgroup. See the Function guide page.

Arguments

  • m::LatentMixtureModel: a latent class (lca) or latent profile (lpa) model fitted with LatentMixtures without covariates (m.regression === nothing) and without sampling weights, with K ≥ 2 classes. Fit it to the outcome indicators only; A and X must not enter the measurement model.
  • A::AbstractVector: binary treatment (0/1), one entry per row of the data m was fitted to (m.ninput rows, in the same order). Rows dropped by the measurement model are ignored; A must be observed on every analysed row.
  • X::AbstractVecOrMat: confounders, a vector or an m.ninput × p matrix in the same row order, numeric and observed on every analysed row. No intercept column (one is added).

Keywords

  • estimator::Symbol = :aipw: one of
    • :aipw: AIPW with BCH pseudo-outcomes (doubly robust; recommended).
    • :ipw_bch: Hájek-normalised inverse probability weighting of the BCH pseudo-outcomes (the weighting analogue of Clouth et al. 2022); needs a correct propensity model.
    • :or: outcome regression (g-computation) with P(C = k | A, X) estimated by the ML three-step method with D fixed (Vermunt 2010); needs a correct class regression. No standard errors (se is NaN; bootstrap if needed).
    • :ipw_modal: IPW of modal-class indicators. Ignores classification error and is biased towards zero; reported for comparison (se_fixed only).
    • :aipw_posterior: AIPW with posterior probabilities as pseudo-outcomes; no classification-error correction (biased); reported for comparison.
    • :naive: unadjusted difference in modal-class proportions (no SE).
  • propensity = :linear: propensity model. :linear is a logistic regression on the main effects of X; :quadratic adds squares and pairwise products. Any other value is a machine-learning learner, given by name (:lasso, :lasso_quadratic, :elasticnet, :forest, :boost, :superlearner, …; see learner) or as a NuisanceLearner object, fitted within the training folds.
  • outcome = :linear: latent class regression. :linear is [1, A, X]; :quadratic is [1, A, X, X², pairwise products, A·(X, X², products)] (both ML three-step fits with D fixed). A learner instead estimates P(ĉ = j | A = a, X) separately in each arm (K one-vs-rest probability fits, normalised) and converts it to P(C = k | A = a, X) = Σⱼ P(ĉ = j | a, X) (D⁻¹)[j, k] (negative values set to zero, rows renormalised). Used by :aipw, :or and :aipw_posterior only.
  • learners = nothing: library of :superlearner (a vector of names or learners; nothing = default_library).
  • bound::Real = 0.01: propensity scores from a learner are bounded to [bound, 1 − bound] (forests can predict exactly 0 or 1). Not applied to :linear / :quadratic; trim applies to both.
  • folds::Integer = 5: number of cross-fitting folds. folds ≤ 1 fits and predicts the nuisance models on all rows (no cross-fitting).
  • trim::Real = 0.0: if positive, propensity scores are truncated to [trim, 1 - trim] after fitting (e.g. 0.01). Truncation changes the estimand slightly but stabilises weights under poor overlap.
  • seed::Integer = 1: seed of the Xoshiro generator that assigns cross-fitting folds (learners draw from separate generators derived from seed and the fold).

Returns

An LCCResult with psi1, psi0, delta, standard errors se, se_fixed, se_psi1, se_psi0 and overlap and classification diagnostics.

Throws

  • ArgumentError for an unknown estimator, a measurement model with covariates or sampling weights, K < 2, missing A/X on analysed rows, or A not 0/1.
  • DimensionMismatch if A or X does not have m.ninput rows.

Examples

using LatentMixtures, LatentClassCausal
# programme: 8 binary wellbeing items six months after a school mental-health programme,
# participation `programme` (targeted at distressed students) and baseline confounders.
# Question: does taking part change the probability of each latent wellbeing class?
p = dataset("programme")
items = p[:, [:low_mood, :worry, :sleep, :lonely, :hopeless, :enjoy, :confident, :friends]]
m = lca(items, 3)          # measurement model of the outcome items only (no A, no X)
itemprobs(m)               # classes 1-3: Flourishing, Moderate, Distressed (largest first)
X = Matrix{Float64}(p[:, [:female, :age, :low_ses, :distress, :belonging]])
r = intervene_membership(m, p.programme, X)      # AIPW with BCH pseudo-outcomes, 5-fold cross-fitting
# Δ ≈ (+0.196, −0.055, −0.141): the programme raises P(Flourishing) by about 20 points and
# lowers P(Distressed) by 14 (true values +0.18, −0.06, −0.12; see the codebook)
intervene_membership(m, p.programme, X; estimator = :naive).delta   # ≈ (+0.022, −0.020, −0.003): confounding by indication
intervene_membership(m, p.programme, X; propensity = :quadratic, outcome = :quadratic, trim = 0.01)

See the tutorial for the full analysis.

Notes

  • Identification requires consistency, positivity, conditional exchangeability of A given X, and a measurement model that is correctly specified, identified (D invertible) and invariant with respect to A and X (no differential item functioning). Double robustness covers the two nuisance models, not the measurement model: under DIF every estimator here is biased.
  • The BCH pseudo-outcomes can be negative or exceed one; only their conditional means are probabilities. With low entropy D is near singular, the pseudo-outcomes become large (see pseudo_range) and finite-sample bias and variance increase.
  • Classes are labelled as in m; the labels are arbitrary (label switching).

  • Bakk, Z., & Vermunt, J. K. (2016). Robustness of stepwise latent class modeling with continuous distal outcomes. Structural Equation Modeling, 23, 20–31.
  • Bolck, A., Croon, M., & Hagenaars, J. (2004). Estimating latent structure models with categorical variables: One-step versus three-step estimators. Political Analysis, 12(1), 3–27. https://doi.org/10.1093/pan/mph001

LatentClassCausal.LCCResult — Type
LCCResult

Result of intervene_membership: estimates of the counterfactual class distributions ψₖ(a) = P(C(a) = k) and of the effects Δₖ = ψₖ(1) − ψₖ(0), k = 1, …, K, with influence-function standard errors. Vectors are indexed by the classes of the measurement model (use align_classes to map them to reference classes). Printing an LCCResult shows a table with Wald 95% intervals and two-sided normal p-values.

Fields

  • estimator::Symbol: the estimator used (see intervene_membership).
  • K::Int: number of latent classes.
  • n::Int: number of analysed rows (the rows the measurement model used).
  • psi1::Vector{Float64}: ψ̂ₖ(1) = P̂(C(1) = k); sums to one.
  • psi0::Vector{Float64}: ψ̂ₖ(0) = P̂(C(0) = k); sums to one.
  • delta::Vector{Float64}: Δ̂ₖ = psi1 - psi0; sums to zero.
  • se::Vector{Float64}: robust standard errors of delta from the influence function including the estimation of the measurement model θ and of the classification-error matrix D (posterior probabilities for :aipw_posterior). NaN for :or, :ipw_modal and :naive.
  • se_fixed::Vector{Float64}: standard errors of delta that treat θ and D as known (the first term of the influence function only). NaN for :or and :naive. Comparing se and se_fixed shows how much the measurement step adds.
  • se_psi1::Vector{Float64}, se_psi0::Vector{Float64}: robust standard errors of psi1 and psi0 (same availability as se).
  • folds::Int: number of cross-fitting folds actually used (1 = no cross-fitting).
  • propensity_range::Tuple{Float64,Float64}: minimum and maximum of the fitted (and, with trim > 0, truncated) propensity scores; values near 0 or 1 signal limited overlap.
  • pseudo_range::Tuple{Float64,Float64}: minimum and maximum entry of the pseudo-outcome matrix used (BCH pseudo-outcomes can leave [0, 1]; a wide range signals a near-singular D, i.e. low entropy).
  • entropy::Float64: relative entropy of the measurement model (1 = perfect classification).

Examples

using LatentMixtures, LatentClassCausal
# 2,000 students: 8 wellbeing items at follow-up, programme participation (treatment) and
# five baseline confounders. Did the programme change the shares of the wellbeing classes?
p = dataset("programme")
m = lca(p[:, [:low_mood, :worry, :sleep, :lonely, :hopeless, :enjoy, :confident, :friends]], 3)
X = Matrix{Float64}(p[:, [:female, :age, :low_ses, :distress, :belonging]])
r = intervene_membership(m, p.programme, X)
[r.delta .- 1.96r.se r.delta .+ 1.96r.se]   # Wald 95% intervals, one row per class
r.se ./ r.se_fixed     # > 1: how much the measurement step inflates the standard errors

See also intervene_membership.

LatentClassCausal.align_classes — Function
align_classes(est, truth) -> Vector{Int}

Find the permutation of the estimated latent classes that best matches a set of reference classes (for example the classes of a simulation's data-generating model), to undo label switching. Columns of both matrices are classes and rows are parameters (for example stacked item-response probabilities); the permutation perm minimises sum(abs, est[:, perm] .- truth), so estimated class perm[k] corresponds to reference class k and r.delta[perm] lines up with the reference ordering.

Arguments

  • est::AbstractMatrix: P × K parameters of the estimated classes.
  • truth::AbstractMatrix: P × K parameters of the reference classes (same rows).

Returns

perm::Vector{Int}, a permutation of 1:K.

Examples

julia> using LatentClassCausal

julia> est = [0.1 0.5 0.9];   # estimated class 3 looks like reference class 1, ...

julia> perm = align_classes(est, [0.9 0.1 0.5])
3-element Vector{Int64}:
 3
 1
 2

julia> est[:, perm]
1×3 Matrix{Float64}:
 0.9  0.1  0.5

Notes

Brute force over all K! permutations, so practical for K ≤ 7 or so.

Interventions on exposures

LatentClassCausal.intervene_effect — Function
intervene_effect(Y, A, X, S, g1; g0 = natural(), estimator = :aipw,
                    outcome = :linear, propensity = :linear, family = :gaussian,
                    folds = 5, seed = 1, B = 200, learners = nothing,
                    bound = 0.01) -> InterventionResult

Estimate the population effect of a hypothetical intervention on the binary exposures A[:, S] (for example selected childhood adversities, or the indicators of a latent class model), ψ = E[Y^{g1}] − E[Y^{g0}], adjusting for H = (the other columns of A, X). g1 and g0 are Interventions: static (setto), stochastic and dependent on the natural value (shift), or the natural course (natural, the default comparison). The intervention is defined on the observed indicators, never by assigning people to latent classes.

The identifying functional is E[Y^g] = E[Σₛ q(s | A_S) μ(s, H)] with μ(s, H) = E[Y | A_S = s, H]; it is estimated by the parametric g-formula, Hájek IPTW, AIPW or TMLE, with cross-fitted nuisance models.

How to use

  1. Put the binary exposures in an n × J matrix A and choose the columns S to intervene on (1 to 6); the other columns of A and the confounders X are adjusted for.
  2. Choose g1 (setto, shift, subgroup or a user Intervention) and g0 (default natural, the observed course).
  3. Set family = :binomial for a 0/1 outcome (ψ is then a risk difference); keep estimator = :aipw or use :tmle.
  4. Check overlap (min_pi, max_weight in the printout); with rare exposure profiles, compare adjust = :classes and adjust = :both.
  5. Vary the nuisance models (outcome = :quadratic, learners) and probe latent confounding by the exposure classes with intervene_latent_sensitivity. See the Function guide page.

Arguments

  • Y::AbstractVector: outcome, continuous (family = :gaussian) or 0/1 (family = :binomial); no missing values.
  • A::AbstractMatrix: n × J matrix of binary (0/1) exposures, complete.
  • X::AbstractVecOrMat: confounders (vector or n × p matrix), complete; no intercept.
  • S::AbstractVector{<:Integer}: columns of A to intervene on (1 to 6 of them; the propensity and outcome models enumerate all 2^|S| patterns).
  • g1::Intervention: the intervention of interest.

Keywords

  • g0::Intervention = natural(): the comparison intervention.

  • estimator::Symbol = :aipw:

    • :aipw: augmented IPW, Pₙ[Σₛ q μ̂(s, H) + w (Y − μ̂(A_S, H))] (doubly robust).
    • :tmle: targeted maximum likelihood: the outcome model is fluctuated along the clever covariate g*(s | H)/π(s | H) (linear fluctuation for :gaussian, logistic for :binomial, so binary-outcome estimates stay in [0, 1]) and then plugged in (doubly robust).
    • :gformula: parametric g-formula (plug-in of the outcome model), with the outcome model cross-fitted over folds like the other estimators. Standard errors come from a nonparametric bootstrap with B replications that applies the same estimator to each resample (outcome model cross-fitted over the same folds, new fold assignment per replicate), so the SE belongs to the reported estimate. folds = 1 gives the plain plug-in g-formula and its usual bootstrap.
    • :ipw: Hájek-normalised IPTW, Σ w Y / Σ w.

  • outcome = :linear: outcome design. :linear is [1, A_S, H]; :quadratic is saturated in A_S and adds squares and pairwise products of H and A_S × H interactions. Any other value is a machine-learning learner, by name (:lasso, :lasso_quadratic, :forest, :boost, :superlearner, …; see learner) or as a NuisanceLearner, fitted within the training folds: separately within each pattern of A_S when every pattern has at least 20 training rows, otherwise once on [A_S, H] (A_S unpenalised in penalised learners) and evaluated at every pattern.

  • propensity = :linear: design of each logistic regression in the propensity chain P(A_j | A_{S,<j}, H): :linear (main effects of H) or :quadratic (adds squares and pairwise products), or a learner (name or object) fitted to each link of the chain.

  • learners = nothing: library of :superlearner (vector of names or learners; nothing = default_library).

  • bound::Real = 0.01: with a learner, each conditional probability of the propensity chain is bounded to [bound, 1 − bound] (so the joint probabilities still sum to one). Not applied to :linear / :quadratic.

  • family::Symbol = :gaussian: :gaussian (linear regression; ψ is a mean difference) or :binomial (logistic regression; ψ is a risk difference).

  • folds::Integer = 5: cross-fitting folds (≤ 1: no cross-fitting).

  • seed::Integer = 1: seed for the fold assignment and the bootstrap resamples.

  • B::Integer = 200: bootstrap replications for :gformula (0 skips the bootstrap and returns NaN standard errors). Replications run on multiple threads when Julia is started with -t N.

  • adjust::Symbol = :exposures: what H contains. :exposures (default): the non-intervened exposures and X. :classes: the posterior probabilities of classes 1, …, K − 1 of a latent class model of the non-intervened exposures only, with covariates X, plus X, instead of the exposures themselves. :both: exposures, X and the class probabilities. See the Latent classes and interventions page.

  • adjust_K = nothing, adjust_model = nothing: number of classes of that model (fitted with lca(A[:, rest], K; covariates = X)), or the fitted model itself.

(_fit_propensity is an internal keyword used by the bootstrap; leave it at its default.)

Returns

An InterventionResult with psi1, psi0, effect, their standard errors, overlap diagnostics min_pi and max_weight, and the influence-function contributions phi1, phi0.

Throws

  • ArgumentError for an unknown estimator or family, missing values, non-binary A, or length(S) outside 1–6.
  • DimensionMismatch if A or X does not have one row per element of Y.

Examples

using LatentClassCausal
# ace_study: 2,500 adults; exposures ace1-ace8 (ace1 = childhood abuse, ace2 = neglect),
# confounders age, female, parent_edu; outcomes self-rated health (0-100) and depression.
# Question: how much better would adult health be if abuse and neglect were prevented?
a = dataset("ace_study")
A = Matrix{Int}(a[:, r"^ace"])                     # the other ACEs are adjusted for
X = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
health = Float64.(a.health)

# prevent both for everyone, compared with the natural course
r = intervene_effect(health, A, X, [1, 2], setto([0, 0]))
# ψ ≈ +2.26: mean self-rated health would be about 2 points higher (true value +2.00)

# halve their prevalence (each present exposure removed with probability 0.5), TMLE
intervene_effect(health, A, X, [1, 2], shift(0.5); estimator = :tmle)
# ψ ≈ +1.16: about half the effect of full prevention (true value +1.04)

# binary outcome: risk difference for past-year depression
d = intervene_effect(Float64.(a.depressed), A, X, [1, 2], setto([0, 0]); family = :binomial,
                        estimator = :tmle)
d.psi0, d.psi1     # ≈ 0.163 under the natural course, ≈ 0.129 if abuse and neglect were prevented

# parametric g-formula with 200 bootstrap replications for the standard error
intervene_effect(health, A, X, [1, 2], setto([0, 0]); estimator = :gformula, B = 200)

Notes

Identification requires (see the Interventions on exposures page):

  1. consistency;
  2. conditional exchangeability, Y^s ⫫ A_S | H;
  3. positivity, π(s | H) > 0 wherever the intervention puts mass on s (check min_pi and max_weight);
  4. the non-intervened exposures in H are not affected by A_S (otherwise they are mediators and adjusting for them changes the estimand).

If a latent variable that generates the indicators (e.g. a family context underlying adversity classes) also affects Y directly, adjusting for the other indicators is only proxy adjustment and ψ̂ is biased. AIPW and TMLE are consistent if either the outcome model or the propensity chain is correctly specified, and efficient when both are.

LatentClassCausal.InterventionResult — Type
InterventionResult

Result of intervene_effect. Printing it shows both counterfactual means, the contrast with a Wald 95% interval and two-sided normal p-value, and the overlap diagnostics.

Fields

  • estimator::Symbol: :aipw, :tmle, :gformula or :ipw.
  • g1::String, g0::String: names of the compared interventions.
  • psi1::Float64: estimate of E[Y^{g1}].
  • psi0::Float64: estimate of E[Y^{g0}].
  • effect::Float64: ψ̂ = psi1 - psi0 (a mean difference, or a risk difference for family = :binomial).
  • se::Float64: standard error of effect: influence-function based for :aipw, :tmle and :ipw; nonparametric bootstrap for :gformula (NaN when B = 0).
  • se_psi1::Float64, se_psi0::Float64: standard errors of psi1 and psi0 (same method).
  • n::Int: number of observations.
  • min_pi::Float64: smallest fitted propensity π(s | Hᵢ) over all rows and patterns s to which either intervention gives positive probability (positivity check).
  • max_weight::Float64: largest weight g*(A_S | H) / π(A_S | H) under either intervention (large values mean influential observations and unstable IPW/AIPW).
  • folds::Int: number of cross-fitting folds used.
  • phi1::Vector{Float64}, phi0::Vector{Float64}: per-observation contributions whose means are psi1 and psi0; centred, they are the (estimated) influence-function values, so std(phi1 .- phi0) / sqrt(n) reproduces se (except for :gformula). Use them for joint inference on several contrasts estimated on the same data.

Examples

using LatentClassCausal
# ace_study: 8 childhood adversities (ace1 = abuse, ace2 = neglect, …), confounders and
# adult self-rated health (0-100). What if abuse and neglect were prevented?
a = dataset("ace_study")
A = Matrix{Int}(a[:, r"^ace"])
X = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
r = intervene_effect(Float64.(a.health), A, X, [1, 2], setto([0, 0]))
r.effect, r.se                               # ψ ≈ +2.26 points, SE ≈ 0.21 (true value +2.00)
(r.effect - 1.96r.se, r.effect + 1.96r.se)   # Wald 95% interval
r.min_pi, r.max_weight                       # positivity diagnostics: no extreme weights
LatentClassCausal.Intervention — Type
Intervention(name, q)

A (possibly stochastic) intervention on the |S| intervened binary indicators, defined by its conditional distribution: q(s, a) is the probability that the intervened values are s when the natural (observed) values are a, both 0/1 vectors of length |S|, and Σₛ q(s, a) = 1 for every a. Interventions whose q depends on a are modified treatment policies (Haneuse & Rotnitzky 2013).

Usually constructed with natural, setto or shift; a custom intervention is any function with this signature, for example Intervention("remove item 1", (s, a) -> Float64(s == [0, a[2]])) on S = [1, 2].

Fields

  • name::String: label used when printing an InterventionResult.
  • q::Function: (s, a) -> probability, with s, a vectors of 0/1 integers in the order of S.

Examples

julia> using LatentClassCausal

julia> g = shift(0.5);

julia> g.q([0, 0], [1, 1])    # both exposures present; each removed with probability 0.5
0.25

julia> g.q([0, 0], [0, 0])    # nothing to remove
1.0

See also intervene_effect.

LatentClassCausal.natural — Function
natural() -> Intervention

The natural course: the intervened indicators keep their observed values, q(s, a) = 1(s = a). It is the default comparison g0 of intervene_effect. Under the natural course all weights equal one, so the AIPW, TMLE and IPW estimates of E[Y^{g0}] equal the sample mean of the outcome exactly; the g-formula estimate is the mean of the cross-fitted predictions.

Returns

An Intervention named "natural course".

Examples

julia> using LatentClassCausal

julia> natural().q([1, 0], [1, 0]), natural().q([0, 0], [1, 0])
(1.0, 0.0)
LatentClassCausal.setto — Function
setto(values::AbstractVector{<:Integer}) -> Intervention
setto(v::Integer) -> Intervention

Static (deterministic) intervention that sets the intervened indicators to values for everyone, whatever their natural values: q(s, a) = 1(s = values). values must have one 0/1 entry per intervened indicator, in the order of S in intervene_effect; the scalar form is setto([v]) for a single indicator.

Arguments

  • values: the 0/1 values assigned to the intervened indicators.

Returns

An Intervention named "set to [values...]".

Examples

julia> using LatentClassCausal

julia> g = setto([0, 0]);    # remove both exposures

julia> g.name
"set to [0, 0]"

julia> g.q([0, 0], [1, 0]), g.q([1, 0], [1, 0])
(1.0, 0.0)

Notes

The length of values is not checked against S: a vector of the wrong length puts probability zero on every pattern and silently returns a meaningless estimate.

LatentClassCausal.shift — Function
shift(δ; from = 1, to = 0) -> Intervention

Stochastic intervention that depends on the natural exposure value (a modified treatment policy): each intervened indicator whose natural value is from is moved to to with probability δ, independently across indicators; indicators at any other value are left unchanged. With the defaults, shift(1.0) removes the exposures entirely (equivalent to setto all zeros) and shift(0.5) halves their prevalence among the exposed.

Arguments

  • δ::Real: probability in [0, 1] that an indicator at from is moved.

Keywords

  • from::Integer = 1: the value that is changed (e.g. 1 = adversity present).
  • to::Integer = 0: the value it is changed to.

Returns

An Intervention with q(s, a) = Πⱼ qⱼ(sⱼ, aⱼ), where for aⱼ = from qⱼ(to, aⱼ) = δ and qⱼ(from, aⱼ) = 1 − δ, and otherwise qⱼ(sⱼ, aⱼ) = 1(sⱼ = aⱼ).

Throws

ArgumentError if δ is outside [0, 1].

Examples

julia> using LatentClassCausal

julia> g = shift(0.25);

julia> g.name
"shift 1→0 with probability 0.25"

julia> g.q([0], [1]), g.q([1], [1]), g.q([0], [0])
(0.25, 0.75, 1.0)

References

  • Haneuse, S., & Rotnitzky, A. (2013). Estimation of the effect of interventions that modify the received treatment. Statistics in Medicine, 32(30), 5260–5277. https://doi.org/10.1002/sim.5907
  • Díaz, I., Williams, N., Hoffman, K. L., & Schenck, E. J. (2023; online 2021). Nonparametric causal effects based on longitudinal modified treatment policies. Journal of the American Statistical Association, 118, 846–857.
LatentClassCausal.subgroup — Function
subgroup(g::Intervention, mask; name) -> Intervention

Apply intervention g only to the rows where mask is true; everyone else keeps their natural exposures. mask is a Bool vector with one entry per row of the analysis data.

Examples

using LatentClassCausal
# ace_study: would preventing abuse and neglect (ace1, ace2) only in families where the
# parents had at most 10 years of education (28% of the sample) improve adult health?
a = dataset("ace_study")
A = Matrix{Int}(a[:, r"^ace"])
X = Matrix{Float64}(a[:, [:age, :female, :parent_edu]])
g = subgroup(setto([0, 0]), a.parent_edu .<= 10; name = "prevent abuse and neglect, parent_edu ≤ 10")
r = intervene_effect(Float64.(a.health), A, X, [1, 2], g)
# ψ ≈ +0.86 points in the whole population (true value +0.81), about 40% of the effect of
# universal prevention (+2.00) from intervening on 28% of the sample

LatentClassCausal.NuisanceLearner — Type
NuisanceLearner

Abstract supertype of the nuisance learners accepted by the propensity and outcome keywords of intervene_membership and intervene_effect: MeanLearner, GLMLearner, LassoLearner, ForestLearner, BoostLearner and SuperLearner. Fit one directly with fit_learner and predict with predict_learner.

LatentClassCausal.MeanLearner — Type
MeanLearner()

Intercept-only learner: predicts the training mean of y (a proportion for family = :binomial). Useful as a baseline in a SuperLearner library.

LatentClassCausal.GLMLearner — Type
GLMLearner(; design = :linear)

Unpenalised generalised linear model: least squares (:gaussian) or maximum-likelihood logistic regression (:binomial) on an intercept and expand(X, design), i.e. main effects (design = :linear) or main effects, squares and pairwise products (:quadratic). The same fits as the :linear / :quadratic designs of the estimators.

LatentClassCausal.LassoLearner — Type
LassoLearner(; alpha = 1.0, design = :linear, nfolds = 10, nlambda = 100,
             lambda_min_ratio = nothing, rule = :min)

Penalised GLM (:gaussian least squares or :binomial logistic regression) with the elastic-net penalty λ Σⱼ [α |βⱼ| + (1 − α) βⱼ² / 2] on standardised columns (intercept unpenalised), fitted by cyclic coordinate descent along a path of nlambda values of λ from λmax (all coefficients zero) down to `lambdaminratio · λmax(default1e-4if n > p, else0.01), with warm starts and, for:binomial, iteratively reweighted least squares (Friedman, Hastie & Tibshirani 2010). λ is chosen bynfolds-fold cross-validation of the deviance:rule = :mintakes the minimiser,:one_sethe largest λ within one standard error of it.alpha = 1is the lasso,0 < alpha < 1the elastic net,alpha = 0ridge.design = :quadratic` adds squares and pairwise products before penalisation. Columns that the estimators flag as treatment columns are left unpenalised.

LatentClassCausal.ForestLearner — Type
ForestLearner(; ntrees = 500, mtry = 0, min_leaf = 0, sample = 0.7, max_depth = -1)

Random forest of regression trees (DecisionTree.jl). For family = :binomial the trees are grown on the 0/1 response, so the forest average is a probability (a "probability forest"). mtry features are tried at each split (0: ⌈p/3⌉ for :gaussian, ⌈√p⌉ for :binomial); min_leaf is the minimum leaf size (0: 5 for :gaussian, 10 for :binomial); each tree is grown on sample · n rows drawn with replacement. Deterministic given the rng (whatever the number of threads).

LatentClassCausal.BoostLearner — Type
BoostLearner(; nrounds = 500, eta = 0.1, max_depth = 3, min_weight = 10.0,
             rowsample = 0.8, colsample = 1.0, L2 = 1.0, early_stopping = 20,
             valid = 0.2)

Gradient-boosted regression trees (EvoTrees.jl; squared-error loss for :gaussian, log loss for :binomial). Requires using EvoTrees (a weak dependency loaded as the package extension LatentClassCausalEvoTreesExt). The number of rounds is chosen by early stopping: a random fraction valid of the training rows is held out, boosting stops after early_stopping rounds without improvement of the held-out loss (at most nrounds), and the model is refitted on all training rows with the best number of rounds (early_stopping = 0 uses nrounds directly). max_depth counts levels as in EvoTrees (depth 3 = up to 4 leaves).

LatentClassCausal.SuperLearner — Type
SuperLearner(library = default_library(); nfolds = 5, meta = :nnls)

Stacked ensemble (super learner; van der Laan, Polley & Hubbard 2007; Polley & van der Laan 2010). Each learner of library (a vector of NuisanceLearners or names accepted by learner) is fitted on nfolds − 1 folds of the training data and predicts the remaining fold; the meta-learner combines these cross-validated predictions:

  • meta = :nnls: non-negative least squares, weights rescaled to sum to one (a convex combination of the predictions; the default method.NNLS of the R package SuperLearner). For :binomial the combination of probabilities is a probability.
  • meta = :nnloglik (:binomial only): non-negative logistic stacking of the logits of the predictions, weights rescaled to sum to one (method.NNloglik).

Learners with zero weight are not refitted. The fitted object (see fit_learner) reports the weights and the cross-validated risk of every learner (.weights, .cvrisk).

LatentClassCausal.default_library — Function
default_library() -> Vector{NuisanceLearner}

Default SuperLearner library: the mean, main-effects GLM, lasso on main effects, lasso on main effects + squares + pairwise products, and a random forest. It uses only built-in learners, so it does not change with the packages that happen to be loaded; add BoostLearner() (after using EvoTrees) explicitly.

LatentClassCausal.learner — Function
learner(name) -> NuisanceLearner

Learner from a name (Symbol or String): :mean, :glm, :glm_quadratic, :lasso, :lasso_quadratic, :elasticnet (α = 0.5), :ridge, :forest, :boost and :superlearner (with default_library). A NuisanceLearner is returned unchanged.

LatentClassCausal.fit_learner — Function
fit_learner(L, X, y; family = :gaussian, rng = Xoshiro(1), keep = Int[]) -> fitted

Fit learner L (NuisanceLearner or a name accepted by learner) to the response y and the n × p feature matrix X (no intercept column). family = :gaussian minimises squared error; :binomial fits a probability model for y ∈ [0, 1]. keep lists columns of X that penalised learners leave unpenalised (for example treatment indicators). Returns a fitted object for predict_learner; a fitted SuperLearner has fields weights and cvrisk, a fitted LassoLearner has lambda and coef.

Examples

using LatentClassCausal, Random
rng = Xoshiro(1); X = randn(rng, 500, 3)
y = Float64.(rand(rng, 500) .< 1 ./ (1 .+ exp.(-(X[:, 1] .^ 2 .- 1))))
f = fit_learner(SuperLearner(), X, y; family = :binomial)
f.weights                      # weights of mean, glm, lasso, lasso_quadratic, forest
p = predict_learner(f, X)      # probabilities
LatentClassCausal.predict_learner — Function
predict_learner(fitted, X) -> Vector{Float64}

Predictions of a learner fitted by fit_learner at the rows of X (same columns as in fitting): conditional means, or probabilities for family = :binomial.
